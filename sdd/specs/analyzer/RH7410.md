# Analyzer — RH7410 Interface implementation properties should be grouped by interface regions

| | |
|---|---|
| ID prefix | RH7410 |
| Status | Active |
| Category | Organization |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH7410InterfacePropertiesShouldBeGroupedByInterfaceRegionsAnalyzer` |
| Uses | SHARED-REGGROUP-001, SHARED-REGGROUP-002, SHARED-REGGROUP-004, SHARED-REGGROUP-005, SHARED-TYPEREGION-006 |

RH7410 reports a property that implements an interface property, explicitly or implicitly, when it does not lie in a top-level region named after the interface that declares the member. It has no code fix.

## Non-goals

- Interface implementations that are methods, events, or indexers — RH7409, RH7411, RH7412.
- An override that implements an interface property — RH7402.

## Requirements

### RH7410-001 — An interface implementation property outside its interface's region is reported

In every type declaration it checks (SHARED-REGGROUP-001), the analyzer MUST report each property declaration that comes from an interface (SHARED-REGGROUP-004) — an explicit and an implicit implementation alike — and that is not `partial` and lies in no region nested in a top-level region (SHARED-TYPEREGION-006), when the property does not lie in a top-level region whose name matches (SHARED-REGGROUP-002) that interface, whether it lies in a region of another name or in no region. The diagnostic MUST be placed as SHARED-REGGROUP-005 specifies.

Why: Members that implement an interface are easier to scan when they are grouped by the interface they belong to; a generic region name such as `Properties` hides that relationship in a type that implements several interfaces.

Example:

```csharp
interface INamed
{
    string Name { get; }
}

interface ISized
{
    int Size { get; }
}

interface ICounted
{
    int Count { get; }
}

class C : INamed, ISized, ICounted
{
    #region Properties

    public string {|RH7410:Name|} => "";

    int ISized.{|RH7410:Size|} => 0;

    #endregion

    public int {|RH7410:Count|} => 0;
}
```

while implementations in the regions named after their interfaces:

```csharp
interface INamed
{
    string Name { get; }
}

interface ISized
{
    int Size { get; }
}

class C : INamed, ISized
{
    #region INamed

    public string Name => "";

    #endregion

    #region ISized

    int ISized.Size => 0;

    #endregion
}
```

are not reported.

### RH7410-002 — Other members are not reported

The analyzer MUST NOT report a property that implements no interface member, an override property, or an interface implementation that is not a property declaration, such as an indexer.

Why: A property that implements nothing has no interface to be grouped by, an override is grouped by its base type (SHARED-REGGROUP-004), and the other member kinds have rules of their own.

Example:

```csharp
interface IIndexed
{
    int this[int index] { get; }
}

class C : IIndexed
{
    #region Indexers

    public int this[int index] => index;

    #endregion

    #region Properties

    public int P => 0;

    #endregion
}
```

is not reported.
