# Analyzer — RH7407 Non-override events should not be placed in override regions

| | |
|---|---|
| ID prefix | RH7407 |
| Status | Active |
| Category | Organization |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH7407NonOverrideEventsShouldNotBePlacedInOverrideRegionsAnalyzer` |
| Uses | SHARED-DIAG-004, SHARED-DIAG-012, SHARED-REGGROUP-001, SHARED-REGGROUP-005, SHARED-REGGROUP-006, SHARED-TYPEREGION-006 |

RH7407 reports an event that overrides nothing when the innermost region it lies in is named after the type that one of the type's overrides comes from. It has no code fix.

## Non-goals

- Where an override event belongs — RH7403.
- Methods, properties, and indexers that override nothing — RH7405, RH7406, RH7408.

## Requirements

### RH7407-001 — An event that overrides nothing in an override region is reported

In every type declaration it checks (SHARED-REGGROUP-001), the analyzer MUST report each event declaration — each declarator of a field-like event declaration, judged on its own (SHARED-REGGROUP-005), and an event with `add` and `remove` accessors alike — that overrides no event, when the innermost region that encloses it (SHARED-REGGROUP-001, SHARED-TYPEREGION-006) is an override region (SHARED-REGGROUP-006). An override event with `add` and `remove` accessors and any declarator of an override field-like event make a region an override region alike, as does an override of another member kind (SHARED-REGGROUP-006). The diagnostic MUST be placed as SHARED-REGGROUP-005 specifies.

A `partial` event is one event (SHARED-DIAG-004): it is reported at most once, on the part SHARED-DIAG-012 selects. It is reported when any of its parts, judged on its own by the region it lies in, would be reported: no part may lie in an override region.

Why: A region named after a base type groups the members that override that type's members. An event of the type's own placed among them blurs the inheritance boundary. Both forms declare the same kind of member.

Example:

```csharp
using System;

class B
{
    public virtual event EventHandler Changed;
}

class C : B
{
    #region B

    public override event EventHandler Changed;

    public event EventHandler {|RH7407:Saved|};

    public event EventHandler {|RH7407:Closed|}
    {
        add
        {
        }

        remove
        {
        }
    }

    #endregion
}
```

Example — a `partial` event that overrides nothing and whose parts both lie in an override region is reported once, on its defining part:

```csharp
using System;

class B
{
    public virtual event Action Changed;
}

partial class C : B
{
    #region B

    public override event Action Changed;

    public partial event Action {|RH7407:E|};

    public partial event Action E
    {
        add
        {
        }

        remove
        {
        }
    }

    #endregion
}
```

### RH7407-002 — Other members and other regions are not reported

The analyzer MUST NOT report an event that lies in no region, or whose innermost enclosing region (SHARED-REGGROUP-001) is not an override region, also when a region around that one is. It MUST NOT report an override event or a member that is not an event declaration.

Why: Outside an override region an event that overrides nothing is where it belongs, an override in an override region is where RH7403 asks it to be, and the other member kinds have rules of their own.

Example:

```csharp
using System;

class B
{
    public virtual event EventHandler Changed;
}

class C : B
{
    #region B

    public override event EventHandler Changed;

    #endregion

    #region Events

    public event EventHandler Saved;

    #endregion
}
```

is not reported.
