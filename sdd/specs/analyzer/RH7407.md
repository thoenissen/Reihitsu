# Analyzer — RH7407 Non-override events should not be placed in override regions

| | |
|---|---|
| ID prefix | RH7407 |
| Status | Active |
| Category | Organization |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH7407NonOverrideEventsShouldNotBePlacedInOverrideRegionsAnalyzer` |
| Uses | SHARED-DIAG-004, SHARED-DIAG-012, SHARED-REGGROUP-001, SHARED-REGGROUP-005, SHARED-REGGROUP-006, SHARED-TYPEREGION-006 |

RH7407 reports an event that overrides nothing when it lies in a top-level region named after the type that one of the type's override events comes from. It has no code fix.

## Non-goals

- Where an override event belongs — RH7403.
- Methods, properties, and indexers that override nothing — RH7405, RH7406, RH7408.

## Requirements

### RH7407-001 — An event that overrides nothing in an override region is reported

In every type declaration it checks (SHARED-REGGROUP-001), the analyzer MUST report each event declaration — a field-like event with one declarator and an event with `add` and `remove` accessors alike — that overrides no event, when it lies in a top-level region (SHARED-TYPEREGION-006), and in no region nested in it, that is an override region of events (SHARED-REGGROUP-006). An override event with `add` and `remove` accessors and an override field-like event with one declarator make a region an override region alike. The diagnostic MUST be placed as SHARED-REGGROUP-005 specifies.

A `partial` event is one event (SHARED-DIAG-004): it is reported at most once, on the part SHARED-DIAG-012 selects. This requirement covers a `partial` event only when each of its parts, judged on its own, would be reported; whether a `partial` event is reported when only some of its parts would be is not covered.

Why: A region named after a base type groups the members that override that type's members. An event of the type's own placed among them blurs the inheritance boundary. Both forms declare the same kind of member.

Example:

```csharp
using System;

class B
{
    public virtual event EventHandler Changed;
}

class C : B
{
    #region B

    public override event EventHandler Changed;

    public event EventHandler {|RH7407:Saved|};

    public event EventHandler {|RH7407:Closed|}
    {
        add
        {
        }

        remove
        {
        }
    }

    #endregion
}
```

Example — a `partial` event that overrides nothing and whose parts both lie in an override region is reported once, on its defining part:

```csharp
using System;

class B
{
    public virtual event Action Changed;
}

partial class C : B
{
    #region B

    public override event Action Changed;

    public partial event Action {|RH7407:E|};

    public partial event Action E
    {
        add
        {
        }

        remove
        {
        }
    }

    #endregion
}
```

### RH7407-002 — Other members and other regions are not reported

The analyzer MUST NOT report an event that lies in no region, or in a top-level region that is not an override region and in no region nested in it. It MUST NOT report an override event or a member that is not an event declaration.

Why: Outside an override region an event that overrides nothing is where it belongs, an override in an override region is where RH7403 asks it to be, and the other member kinds have rules of their own.

Example:

```csharp
using System;

class B
{
    public virtual event EventHandler Changed;
}

class C : B
{
    #region B

    public override event EventHandler Changed;

    #endregion

    #region Events

    public event EventHandler Saved;

    #endregion
}
```

is not reported.
