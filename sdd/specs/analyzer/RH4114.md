# Analyzer — RH4114 Public property casing

| | |
|---|---|
| ID prefix | RH4114 |
| Status | Active |
| Category | Naming |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH4114PublicPropertyCasingAnalyzer`, `RH4114PublicPropertyCasingCodeFixProvider` |
| Uses | SHARED-CASING-001, SHARED-CASING-004, SHARED-CASING-006, SHARED-CASING-007, SHARED-CASING-008, SHARED-CASING-009, SHARED-CASING-010 |

RH4114 reports a public property whose name is not in PascalCase and offers a code fix that renames the property and every reference to it.

## Non-goals

- Properties of the private, protected, and internal groups — RH4111, RH4112, and RH4113.
- The properties that a record's primary constructor declares — RH4120.
- Names of fields — RH4106 to RH4110.

## Requirements

### RH4114-001 — Public property names are in PascalCase

The analyzer MUST report every property declaration that belongs to the public group of SHARED-CASING-004 and whose name is not in PascalCase as SHARED-CASING-001 defines it. Static, expression-bodied, virtual, and abstract properties, interface properties, and overrides and implicit interface implementations whose original definition is declared in source MUST be checked too. The analyzer MUST report one diagnostic per property declaration, located on its identifier, so each part of a partial property gets its own diagnostic.

This requirement covers a property whose original definition is declared in source: following the properties it overrides, through every level, and the interface properties it implicitly implements never leads to a property declared in a referenced assembly.

Why: A public property is part of the type's surface for every caller, so it is named like the other public members, following the .NET convention.

Example:

```csharp
public interface I
{
    int {|RH4114:value|} { get; }
    static int {|RH4114:shared|} { get; set; }
}

public class C : I
{
    public int {|RH4114:count|} { get; set; }
    public static int {|RH4114:instance_count|} => 0;
    public int Limit { get; set; }
    int I.value => 0;
    int total { get; set; }
}
```

Example — a partial property, reported on each part:

```csharp
public partial class C
{
    public partial int {|RH4114:count|} { get; }
}

public partial class C
{
    public partial int {|RH4114:count|} => 0;
}
```

### RH4114-002 — The fix renames the property to PascalCase

The code fix MUST rename the property and every reference to it (SHARED-CASING-007) to the PascalCase name that SHARED-CASING-006 derives from its old name. Renaming a property also renames, in source, the properties it overrides and the properties that override it, and renaming an interface property or an implicit implementation of it renames the other with it. Renaming an interface property also renames its explicit implementations, which take their name from it. The fix is withheld as SHARED-CASING-008 and SHARED-CASING-009 specify, and its Fix All skips colliding names as SHARED-CASING-010 specifies. This requirement covers the renames that SHARED-CASING-007 covers, for the properties that RH4114-001 covers. It further covers only a property whose name is not also the name of a parameter of its record's primary constructor.

Why: The fix makes exactly the change the diagnostic asks for, and a public property is referenced wherever its type is used.

Example:

```csharp
public interface IResourceSettings
{
    int {|RH4114:resourceCount|} { get; }
}

public class ResourceSettings : IResourceSettings
{
    int IResourceSettings.resourceCount => 42;

    public string {|RH4114:display_name|} { get; set; }

    public int Length => display_name.Length;
}
```

```csharp
public interface IResourceSettings
{
    int ResourceCount { get; }
}

public class ResourceSettings : IResourceSettings
{
    int IResourceSettings.ResourceCount => 42;

    public string DisplayName { get; set; }

    public int Length => DisplayName.Length;
}
```

Example — an implicit implementation and an override in source:

```csharp
public interface I
{
    int {|RH4114:value|} { get; }
}

public class C : I
{
    public int {|RH4114:value|} => 0;
}

public class B
{
    public virtual int {|RH4114:size|} => 0;
}

public class D : B
{
    public override int {|RH4114:size|} => 1;
}
```

```csharp
public interface I
{
    int Value { get; }
}

public class C : I
{
    public int Value => 0;
}

public class B
{
    public virtual int Size => 0;
}

public class D : B
{
    public override int Size => 1;
}
```
