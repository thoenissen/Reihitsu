# Analyzer — RH5043 Comments must not be placed inside a base list

| | |
|---|---|
| ID prefix | RH5043 |
| Status | Active |
| Category | Layout |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH5043CommentsMustNotBePlacedInsideBaseListAnalyzer` |
| Uses | SHARED-COMMENT-001, SHARED-COMMENT-002, SHARED-COMMENT-003, SHARED-COMMENT-004, SHARED-COMMENT-005, SHARED-COMMENT-006, SHARED-COMMENT-008, SHARED-COMMENT-009 |

RH5043 reports a comment placed inside the base list of a type, from the colon to the last base type.

## Non-goals

- A comment between a type's base list and its constraint clauses or its body.
- How a base list is laid out — the line-break rules.

## Requirements

### RH5043-001 — A comment inside a base list is reported

The analyzer MUST report every ordinary comment (SHARED-COMMENT-001, SHARED-COMMENT-002) inside the base list of a class, a struct, an interface, a record, or an enum, as SHARED-COMMENT-003, SHARED-COMMENT-004, SHARED-COMMENT-005, SHARED-COMMENT-006, SHARED-COMMENT-008, and SHARED-COMMENT-009 specify for a region. The region runs from the colon to the last token of the last base type.

Why: A comment inside a base list leaves it unclear which base type it describes, and it splits the list across lines. A comment above the type declaration describes the type as a whole.

Example:

```csharp
class B
{
}

interface I
{
}

class C :
    {|RH5043:// storage|}
    B,
    {|RH5043:// contract|}
    I
{
}

enum E : {|RH5043:/* storage */|} byte
{
    First,
}

class D<T>
    // base
    : B
    // reference types
    where T : class
    // body
{
}
```

The comments around the base list of `D` are not reported.
