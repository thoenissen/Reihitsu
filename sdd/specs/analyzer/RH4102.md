# Analyzer — RH4102 Event name casing

| | |
|---|---|
| ID prefix | RH4102 |
| Status | Active |
| Category | Naming |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH4102EventNameCasingAnalyzer`, `RH4102EventNameCasingCodeFixProvider`, `RH4102CustomEventNameCasingCodeFixProvider` |
| Uses | SHARED-CASING-001, SHARED-CASING-006, SHARED-CASING-007, SHARED-CASING-008, SHARED-CASING-009, SHARED-CASING-010 |

RH4102 reports an event whose name is not in PascalCase and offers a code fix that renames the event and every reference to it.

## Non-goals

- The names of the delegate type of an event — RH4006.
- Fields and properties — RH4106 to RH4114.

## Requirements

### RH4102-001 — Event names are in PascalCase

The analyzer MUST report every event whose name is not in PascalCase as SHARED-CASING-001 defines it: every declarator of a field-like event declaration, and every event declaration with `add` and `remove` accessors. Events in interfaces, static events, and overrides and implicit interface implementations whose original definition is declared in source MUST be checked too. The analyzer MUST report one diagnostic per event, located on its identifier.

This requirement covers an event whose original definition is declared in source: following the events it overrides, through every level, and the interface events it implicitly implements never leads to an event declared in a referenced assembly.

Why: Events are members that other types subscribe to; .NET names them in PascalCase, like properties and methods.

Example:

```csharp
using System;

public interface ISource
{
    event EventHandler {|RH4102:changed|};
}

public class Source
{
    public event EventHandler {|RH4102:opened|}, {|RH4102:closed|};

    public static event EventHandler {|RH4102:instanceCreated|};

    public event EventHandler DataReceived;

    public event EventHandler {|RH4102:saved|}
    {
        add { }
        remove { }
    }
}

public abstract class BaseSource
{
    public abstract event EventHandler {|RH4102:updated|};
}

public class Derived : BaseSource, ISource
{
    public override event EventHandler {|RH4102:updated|};

    public event EventHandler {|RH4102:changed|};
}
```

### RH4102-002 — An explicit interface implementation is not reported

The analyzer MUST NOT report an event declaration that is an explicit interface implementation.

Why: Its name is the name of the interface event, which is reported where it is declared; the fix for that diagnostic renames the implementation with it.

Example:

```csharp
using System;

internal interface ISource
{
    event EventHandler {|RH4102:dataChanged|};
}

internal class Source : ISource
{
    event EventHandler ISource.dataChanged
    {
        add { }
        remove { }
    }
}
```

```csharp
using System;

internal interface ISource
{
    event EventHandler DataChanged;
}

internal class Source : ISource
{
    event EventHandler ISource.DataChanged
    {
        add { }
        remove { }
    }
}
```

### RH4102-003 — The fix renames the event to PascalCase

The code fix MUST rename the event and every reference to it (SHARED-CASING-007) to the PascalCase name that SHARED-CASING-006 derives from its old name, for the events that RH4102-001 covers. It is withheld as SHARED-CASING-008 and SHARED-CASING-009 specify, and its Fix All skips colliding names as SHARED-CASING-010 specifies. This requirement covers the renames that SHARED-CASING-007 covers.

Why: The fix makes exactly the change the diagnostic asks for, and an event is referenced wherever it is subscribed to or raised.

Example — a field-like event:

```csharp
using System;

internal class Source
{
    public event EventHandler {|RH4102:dataChanged|};

    public void Subscribe()
    {
        dataChanged += OnChanged;
        dataChanged?.Invoke(this, EventArgs.Empty);
    }

    private void OnChanged(object sender, EventArgs args)
    {
    }
}
```

```csharp
using System;

internal class Source
{
    public event EventHandler DataChanged;

    public void Subscribe()
    {
        DataChanged += OnChanged;
        DataChanged?.Invoke(this, EventArgs.Empty);
    }

    private void OnChanged(object sender, EventArgs args)
    {
    }
}
```

Example — an event with accessors:

```csharp
using System;

internal class Source
{
    public event EventHandler {|RH4102:saved|}
    {
        add { }
        remove { }
    }

    public void Subscribe()
    {
        saved += OnChanged;
        saved -= OnChanged;
    }

    private void OnChanged(object sender, EventArgs args)
    {
    }
}
```

```csharp
using System;

internal class Source
{
    public event EventHandler Saved
    {
        add { }
        remove { }
    }

    public void Subscribe()
    {
        Saved += OnChanged;
        Saved -= OnChanged;
    }

    private void OnChanged(object sender, EventArgs args)
    {
    }
}
```
