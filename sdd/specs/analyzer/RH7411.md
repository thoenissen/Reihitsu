# Analyzer — RH7411 Interface implementation events should be grouped by interface regions

| | |
|---|---|
| ID prefix | RH7411 |
| Status | Active |
| Category | Organization |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH7411InterfaceEventsShouldBeGroupedByInterfaceRegionsAnalyzer` |
| Uses | SHARED-DIAG-004, SHARED-DIAG-012, SHARED-REGGROUP-001, SHARED-REGGROUP-002, SHARED-REGGROUP-004, SHARED-REGGROUP-005, SHARED-TYPEREGION-006 |

RH7411 reports an event that implements an interface event, explicitly or implicitly, when it does not lie in a region named after an interface that declares the member, judged by the innermost region that encloses it. It has no code fix.

## Non-goals

- Interface implementations that are methods, properties, or indexers — RH7409, RH7410, RH7412.
- An override that implements an interface event — RH7403.

## Requirements

### RH7411-001 — An interface implementation event outside its interface's region is reported

In every type declaration it checks (SHARED-REGGROUP-001), the analyzer MUST report each event declaration that comes from an interface (SHARED-REGGROUP-004) — each declarator of a field-like event declaration, judged on its own (SHARED-REGGROUP-005), and an event with `add` and `remove` accessors alike, an explicit and an implicit implementation alike — when the innermost region that encloses it (SHARED-REGGROUP-001, SHARED-TYPEREGION-006) does not have a name that matches (SHARED-REGGROUP-002) that interface, or one of those interfaces when it implements members of several (SHARED-REGGROUP-004) — whether it lies in a region of another name, in a region of another name nested in a region that matches, or in no region. The diagnostic MUST be placed as SHARED-REGGROUP-005 specifies.

A `partial` event is one event (SHARED-DIAG-004): it is reported at most once, on the part SHARED-DIAG-012 selects. It is reported when any of its parts, judged on its own by the region it lies in, would be reported: every part has to lie in a matching region.

Why: Members that implement an interface are easier to scan when they are grouped by the interface they belong to; a generic region name such as `Events` hides that relationship in a type that implements several interfaces. Both forms declare the same kind of member.

Example:

```csharp
using System;

interface INotifier
{
    event EventHandler Changed;
}

interface ISaver
{
    event EventHandler Saved;
}

interface ICloser
{
    event EventHandler Closed;
}

class C : INotifier, ISaver, ICloser
{
    #region Events

    public event EventHandler {|RH7411:Changed|};

    event EventHandler ISaver.{|RH7411:Saved|}
    {
        add
        {
        }

        remove
        {
        }
    }

    #endregion

    public event EventHandler {|RH7411:Closed|}
    {
        add
        {
        }

        remove
        {
        }
    }
}
```

while implementations in the regions named after their interfaces:

```csharp
using System;

interface INotifier
{
    event EventHandler Changed;
}

interface ISaver
{
    event EventHandler Saved;
}

class C : INotifier, ISaver
{
    #region INotifier

    public event EventHandler Changed;

    #endregion

    #region ISaver

    event EventHandler ISaver.Saved
    {
        add
        {
        }

        remove
        {
        }
    }

    #endregion
}
```

are not reported.

Example — a `partial` event whose parts both lie outside a matching region is reported once, on its defining part:

```csharp
using System;

interface I
{
    event Action E;
}

partial class C : I
{
    #region Events

    public partial event Action {|RH7411:E|};

    public partial event Action E
    {
        add
        {
        }

        remove
        {
        }
    }

    #endregion
}
```

### RH7411-002 — Other members are not reported

The analyzer MUST NOT report an event that implements no interface member, an override event, or an interface implementation that is not an event declaration.

Why: An event that implements nothing has no interface to be grouped by, an override is grouped by its base type (SHARED-REGGROUP-004), and the other member kinds have rules of their own.

Example:

```csharp
using System;

interface INamed
{
    string Name { get; }
}

class C : INamed
{
    #region Properties

    public string Name => "";

    #endregion

    #region Events

    public event EventHandler Changed;

    #endregion
}
```

is not reported.
