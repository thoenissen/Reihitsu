# Analyzer — RH7411 Interface implementation events should be grouped by interface regions

| | |
|---|---|
| ID prefix | RH7411 |
| Status | Active |
| Category | Organization |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH7411InterfaceEventsShouldBeGroupedByInterfaceRegionsAnalyzer` |
| Uses | SHARED-REGGROUP-001, SHARED-REGGROUP-002, SHARED-REGGROUP-004, SHARED-REGGROUP-005, SHARED-TYPEREGION-006 |

RH7411 reports an event that implements an interface event, explicitly or implicitly, when it does not lie in a top-level region named after the interface that declares the member. It has no code fix.

## Non-goals

- Interface implementations that are methods, properties, or indexers — RH7409, RH7410, RH7412.
- An override that implements an interface event — RH7403.

## Requirements

### RH7411-001 — An interface implementation event outside its interface's region is reported

In every type declaration it checks (SHARED-REGGROUP-001), the analyzer MUST report each event declaration that comes from an interface (SHARED-REGGROUP-004) — a field-like event with one declarator and an event with `add` and `remove` accessors alike, an explicit and an implicit implementation alike — and that is not `partial` and lies in no region nested in a top-level region (SHARED-TYPEREGION-006), when the event does not lie in a top-level region whose name matches (SHARED-REGGROUP-002) that interface, whether it lies in a region of another name or in no region. The diagnostic MUST be placed as SHARED-REGGROUP-005 specifies.

Why: Members that implement an interface are easier to scan when they are grouped by the interface they belong to; a generic region name such as `Events` hides that relationship in a type that implements several interfaces. Both forms declare the same kind of member.

Example:

```csharp
using System;

interface INotifier
{
    event EventHandler Changed;
}

interface ISaver
{
    event EventHandler Saved;
}

interface ICloser
{
    event EventHandler Closed;
}

class C : INotifier, ISaver, ICloser
{
    #region Events

    public event EventHandler {|RH7411:Changed|};

    event EventHandler ISaver.{|RH7411:Saved|}
    {
        add
        {
        }

        remove
        {
        }
    }

    #endregion

    public event EventHandler {|RH7411:Closed|}
    {
        add
        {
        }

        remove
        {
        }
    }
}
```

while implementations in the regions named after their interfaces:

```csharp
using System;

interface INotifier
{
    event EventHandler Changed;
}

interface ISaver
{
    event EventHandler Saved;
}

class C : INotifier, ISaver
{
    #region INotifier

    public event EventHandler Changed;

    #endregion

    #region ISaver

    event EventHandler ISaver.Saved
    {
        add
        {
        }

        remove
        {
        }
    }

    #endregion
}
```

are not reported.

### RH7411-002 — Other members are not reported

The analyzer MUST NOT report an event that implements no interface member, an override event, or an interface implementation that is not an event declaration.

Why: An event that implements nothing has no interface to be grouped by, an override is grouped by its base type (SHARED-REGGROUP-004), and the other member kinds have rules of their own.

Example:

```csharp
using System;

interface INamed
{
    string Name { get; }
}

class C : INamed
{
    #region Properties

    public string Name => "";

    #endregion

    #region Events

    public event EventHandler Changed;

    #endregion
}
```

is not reported.
