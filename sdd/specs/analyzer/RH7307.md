# Analyzer — RH7307 Region descriptions should not be Member or Members

| | |
|---|---|
| ID prefix | RH7307 |
| Status | Active |
| Category | Organization |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH7307RegionDescriptionsShouldNotBeMemberOrMembersAnalyzer` |
| Uses | SHARED-REGDESC-001, SHARED-REGDESC-002 |

RH7307 reports a `#region` or `#endregion` whose whole description is `Member` or `Members`. It has no code fix: the better name depends on what the region holds.

## Non-goals

- What the description of a region directive is, and which directives are checked — SHARED-REGDESC-001, SHARED-REGDESC-002.
- Whether a region holds the kind of member its name says — RH7308.

## Requirements

### RH7307-001 — A description that is only `Member` or `Members` is reported

The analyzer MUST report every region directive whose description (SHARED-REGDESC-001) is `Member` or `Members` in any casing. It MUST check and report the directives as SHARED-REGDESC-002 specifies.

Why: Every declaration in a type is a member, so the label tells the reader nothing about whether the region holds fields, properties, or methods.

Example:

```csharp
class C
{
    {|RH7307:#region members|}

    int _a;

    {|RH7307:#endregion //Member|}

    #region Fields

    int _b;

    {|RH7307:#endregion MEMBERS|}
}
```

### RH7307-002 — A longer description is not reported

The analyzer MUST NOT report a description that contains `Member` or `Members` together with other text.

Why: A qualified label such as `Static members` or `Member list` says something about the region; only the bare word is empty.

Example:

```csharp
class C
{
    #region Static members

    static int _a;

    #endregion // Static members

    #region Member list

    int _b;

    #endregion // Member list
}
```

is not reported.
