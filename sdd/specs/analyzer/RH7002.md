# Analyzer — RH7002 File may only contain a single top-level type

| | |
|---|---|
| ID prefix | RH7002 |
| Status | Active |
| Category | Organization |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH7002FileMayOnlyContainASingleTopLevelTypeAnalyzer` |
| Uses | — |

RH7002 reports every top-level type declaration of a file after the first one. It has no code fix.

## Non-goals

- How many namespaces a file declares — RH7001.
- Whether a type may be nested — RH2101 and RH2104 to RH2108.

## Requirements

### RH7002-001 — Every top-level type after the first is reported

The analyzer MUST report every class, struct, interface, enum, record, and record struct declaration that is declared directly in the compilation unit or in a namespace — at any depth of nested namespaces — and follows another such declaration in the same file. The declarations of all namespaces of the file are counted together.

Why: A file named after one type should contain that type. Further top-level types are hard to find from the file name, and moving them to files of their own keeps every type at a predictable place.

Example:

```csharp
namespace N;

public class A
{
}

internal record {|RH7002:B|}(string Name);

internal struct {|RH7002:S|}
{
}

internal interface {|RH7002:I|}
{
}

internal enum {|RH7002:E|}
{
    One,
}
```

and the types of two namespaces of one file:

```csharp
namespace N1
{
    class A
    {
    }
}

namespace N2
{
    namespace Inner
    {
        class {|RH7002:B|}
        {
        }
    }
}
```

### RH7002-002 — Nested types and delegates are not counted

The analyzer MUST NOT count a type declared inside another type, and MUST NOT count a delegate declaration.

Why: A nested type is part of the type that declares it and lives in its file. A delegate is a one-line signature that usually belongs next to the type that uses it, so it does not compete with that type for the file.

Example:

```csharp
delegate void Handler();

class C
{
    private record Nested(string Name);

    private enum Kind
    {
        One,
    }
}
```

is not reported.

### RH7002-003 — The diagnostic is on the type name

The analyzer MUST report one diagnostic per reported type declaration, located on its identifier.

Why: The name is what tells the reader which type to move to its own file.

Example: see RH7002-001.
