# Analyzer — RH4006 Delegate name casing

| | |
|---|---|
| ID prefix | RH4006 |
| Status | Active |
| Category | Naming |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH4006DelegateNameCasingAnalyzer`, `RH4006DelegateNameCasingCodeFixProvider` |
| Uses | SHARED-CASING-001, SHARED-CASING-006, SHARED-CASING-007, SHARED-CASING-008, SHARED-CASING-009, SHARED-CASING-010 |

RH4006 reports a delegate type whose name is not in PascalCase and offers a code fix that renames the delegate and every reference to it.

## Non-goals

- The names of the delegate's parameters — RH4105.
- Class, struct, interface, and enum names — RH4002, RH4003, RH4005, and RH4004.

## Requirements

### RH4006-001 — Delegate names are in PascalCase

The analyzer MUST report every delegate declaration whose name is not in PascalCase as SHARED-CASING-001 defines it, whatever its return type, type parameters, or accessibility. The diagnostic MUST be located on the delegate's identifier.

Why: A delegate declaration declares a type; PascalCase is how .NET spells type names, and a reader recognizes a type by it.

Example:

```csharp
public delegate void MessageHandler(string message);

public delegate int {|RH4006:computeResult|}(int x, int y);

public delegate void {|RH4006:transformAction|}<T>(T item);

internal delegate void {|RH4006:messageCallback|}(string msg);
```

### RH4006-002 — The fix renames the delegate to PascalCase

The code fix MUST rename the delegate and every reference to it (SHARED-CASING-007) to the PascalCase name that SHARED-CASING-006 derives from its old name. It is withheld as SHARED-CASING-008 and SHARED-CASING-009 specify, and its Fix All skips colliding names as SHARED-CASING-010 specifies. This requirement covers the renames that SHARED-CASING-007 covers.

Why: The fix makes exactly the change the diagnostic asks for, and a delegate is referenced wherever its type is used.

Example:

```csharp
public delegate void {|RH4006:orderHandler|}(int orderId);

public class C
{
    public orderHandler Handler;
}
```

```csharp
public delegate void OrderHandler(int orderId);

public class C
{
    public OrderHandler Handler;
}
```
