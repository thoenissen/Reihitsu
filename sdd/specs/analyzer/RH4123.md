# Analyzer — RH4123 Single-letter local function parameter names

| | |
|---|---|
| ID prefix | RH4123 |
| Status | Active |
| Category | Naming |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH4123SingleLetterLocalFunctionParameterNamesAnalyzer` |
| Uses | SHARED-SINGLE-001 |

RH4123 reports a parameter of a local function whose name is a single letter.

## Non-goals

- Parameters of methods and other members — RH4122; of lambdas and anonymous methods — RH4124.
- The casing of parameter names — RH4105.

## Requirements

### RH4123-001 — Single-letter local function parameter names are reported

The analyzer MUST report every parameter of a local function, static or not, whose name is a single-letter name (SHARED-SINGLE-001). The analyzer MUST report one diagnostic per parameter, located on its identifier.

Why: A local function is often short, but its parameters still carry the meaning of the values it works on; a descriptive name makes its purpose and its calculations easier to follow.

Example:

```csharp
class C
{
    void M()
    {
        int Add(int {|RH4123:a|}, int value, int _) => a + value;
        static int Twice(int {|RH4123:x|}) => x * 2;
    }
}
```

### RH4123-002 — Parameters of other members are not checked

The analyzer MUST NOT report a parameter of a method, constructor, or other member, nor a parameter of a lambda or an anonymous method.

Why: Those parameters have rules of their own (RH4122 and RH4124), so each kind can be configured separately.

Example:

```csharp
using System;

class C
{
    void M(int a)
    {
        Func<int, int> f = b => b;
        Action<int> g = delegate (int c) { };
    }
}
```

is not reported.
