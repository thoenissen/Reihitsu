# Analyzer — RH5019 yield-Statement should be preceded by a blank line

| | |
|---|---|
| ID prefix | RH5019 |
| Status | Active |
| Category | Layout |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH5019YieldStatementsShouldBePrecededByABlankLineAnalyzer`, `RH5019YieldStatementsShouldBePrecededByABlankLineCodeFixProvider` |
| Uses | SHARED-STMT-001, SHARED-STMT-002, SHARED-STMT-003, SHARED-STMT-004 |

RH5019 reports a `yield return` or `yield break` statement that follows a statement other than a `yield` statement of the same block or switch section without a blank line between them, and offers a code fix that inserts one as SHARED-STMT-004 specifies.

## Non-goals

- Blank lines before other statement kinds — the other rules that use `shared/statement-blank-lines.md`.

## Requirements

### RH5019-001 — A `yield` statement that follows a statement needs a blank line

The analyzer MUST report a `yield return` or `yield break` statement as SHARED-STMT-001, SHARED-STMT-002, and SHARED-STMT-003 specify, unless RH5019-002 exempts it.

Why: A `yield` statement hands a value, or the end of the sequence, back to the caller; the blank line separates it from the logic that computed it.

Example:

```csharp
class C
{
    System.Collections.Generic.IEnumerable<int> M(int a)
    {
        a++;
        {|RH5019:yield|} return a;

        a++;
        {|RH5019:yield|} break;
    }
}
```

Both `yield` statements follow `a++;` and are reported.

### RH5019-002 — A `yield` statement that follows a `yield` statement is exempt

The analyzer MUST NOT report a `yield` statement whose directly preceding statement in the same block or switch section is a `yield return` or `yield break` statement. A `yield` statement that follows any other statement is reported as RH5019-001 specifies, even when another `yield` statement appears earlier in the list.

Why: Consecutive `yield` statements produce one sequence of values and stay together; the sequence as a whole is separated from the surrounding logic.

Example:

```csharp
class C
{
    System.Collections.Generic.IEnumerable<int> M(int a)
    {
        a++;

        yield return 1;
        yield return 2;
        a++;
        {|RH5019:yield|} return 3;
        yield break;
    }
}
```

`yield return 2;` and `yield break;` follow a `yield` statement and are exempt; `yield return 3;` follows `a++;` and is reported.

### RH5019-003 — The diagnostic is on the `yield` keyword

The analyzer MUST report the diagnostic on the `yield` keyword.

Why: The keyword is where the missing separator becomes visible, for `yield return` and `yield break` alike.

Example: see RH5019-001.
