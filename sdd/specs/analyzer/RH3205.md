# Analyzer — RH3205 Expression style operators should not be used

| | |
|---|---|
| ID prefix | RH3205 |
| Status | Active |
| Category | Clarity |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH3205ExpressionStyleOperatorsShouldNotBeUsedAnalyzer`, `RH3205ExpressionStyleOperatorsShouldNotBeUsedCodeFixProvider` |
| Uses | SHARED-BODY-001, SHARED-BODY-002, SHARED-BODY-003, FMT-STRUCT-005 |

RH3205 reports an expression-bodied operator declaration and offers a code fix that converts it to a block body, as the formatter does under FMT-STRUCT-005. Which operators are left alone, where the diagnostic is, and what the fix produces are SHARED-BODY-001, SHARED-BODY-002, and SHARED-BODY-003.

## Non-goals

- Conversion operators (`implicit` and `explicit`) — RH3206.
- Expression-bodied methods (RH3202), constructors (RH3203), finalizers (RH3207), and local functions (RH3208).

## Requirements

### RH3205-001 — Every expression-bodied operator is reported

The analyzer MUST report every operator declaration that has an expression body — unary, binary, `true` and `false`, and instance compound-assignment operators, in a class, a struct, or an interface — unless SHARED-BODY-001 applies. An operator with a block body or without a body MUST NOT be reported.

Why: The house style uses block bodies for operators, as for methods; the other function kinds have rules of their own, so each kind can be configured separately.

Example:

```csharp
using System;

class C
{
    private int _value;

    public static C operator +(C a, C b) {|RH3205:=> a|};

    public static C operator -(C a) {|RH3205:=> throw new InvalidOperationException()|};

    public void operator +=(int value) {|RH3205:=> _value += value|};

    public static bool operator true(C c) {|RH3205:=> true|};

    public static bool operator false(C c)
    {
        return false;
    }
}

interface I<T> where T : I<T>
{
    static abstract T operator *(T a, T b);

    static virtual T operator /(T a, T b) {|RH3205:=> a|};
}
```
