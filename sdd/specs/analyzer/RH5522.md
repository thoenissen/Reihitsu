# Analyzer — RH5522 Interface attribute lists must use one attribute per list

| | |
|---|---|
| ID prefix | RH5522 |
| Status | Active |
| Category | Layout |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH5522InterfaceAttributeListsMustFollowShapeRulesAnalyzer`, `RH5522InterfaceAttributeListsMustFollowShapeRulesCodeFixProvider` |
| Uses | SHARED-ATTR-001, SHARED-ATTR-013, SHARED-ATTR-016, SHARED-ATTR-017, SHARED-ATTR-019 |

RH5522 reports an attribute list of an interface that holds more than one attribute, and offers a code fix that gives each attribute a list of its own. The rule uses `shared/attribute-targets.md`.

## Non-goals

- Attributes of the members of an interface — the member rules, such as RH5514 and RH5516.
- Where an interface attribute list is placed — RH5521.

## Requirements

### RH5522-001 — Interface attribute lists hold one attribute

The analyzer MUST check every attribute list that resolves to the interface target: the lists of an `interface` declaration without a specifier or with `type:` (SHARED-ATTR-001), and MUST report such a list that holds more than one attribute, as SHARED-ATTR-013 specifies.

Why: Attributes on an interface — interop layout, markers, obsolescence notices — are independent decisions, and each on its own line has room for its arguments and a comment.

Example:

```csharp
{|RH5522:[A, B]|}
interface I
{
}
```

### RH5522-002 — The diagnostic is on the attribute list

The analyzer MUST report the diagnostic on the attribute list, as SHARED-ATTR-016 specifies.

Why: The list is what has the wrong shape; each list of a declaration is reported and fixed on its own.

Example: see RH5522-001.

### RH5522-003 — The fix gives each attribute a list of its own

The code fix MUST replace the list with one list per attribute, each on its own line, as SHARED-ATTR-017 specifies.

Why: The fix makes only the change the diagnostic asks for: the attributes keep their order and their specifier, and each gets a line of its own.

Example:

```csharp
{|RH5522:[A, B]|}
interface I
{
}
```

```csharp
[A]
[B]
interface I
{
}
```

### RH5522-004 — The fix is withheld for a comment or directive inside the list

The code fix MUST NOT be offered when SHARED-ATTR-019 withholds it. The diagnostic is still reported.

Why: A comment inside the list belongs to the attribute next to it, and only the author can tell which of the new lists it belongs to.

Example:

```csharp
{|RH5522:[A, /* c */ B]|}
interface I
{
}
```

is reported, and no code fix is offered.
