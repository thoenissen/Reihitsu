# Analyzer — RH5107 Comma must be on same line as previous parameter

| | |
|---|---|
| ID prefix | RH5107 |
| Status | Active |
| Category | Layout |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH5107CommaMustBeOnSameLineAsPreviousParameterAnalyzer`, `RH5107CommaMustBeOnSameLineAsPreviousParameterCodeFixProvider` |
| Uses | FMT-BREAK-011, SHARED-JOIN-001 |

RH5107 reports a comma of a parameter list that starts a line below the end of the parameter in front of it, and offers a code fix that moves the comma behind that parameter.

## Non-goals

- The commas of an argument list.
- The bracketed parameter list of an indexer.
- The spaces around a comma — RH6002.

## Requirements

### RH5107-001 — A comma below its parameter is reported

The analyzer MUST report a comma between two parameters of a parenthesized parameter list — of a declaration, a primary constructor, an anonymous method, or a parenthesized lambda — when the comma starts on a later line than the parameter in front of it ends on, except where SHARED-JOIN-001 keeps the gap from being reported.

Why: A comma at the start of a line separates a parameter from its separator, which is easy to misread (FMT-BREAK-011); at the end of the line it shows that the list continues.

Example:

```csharp
using System;

class C
{
    void M(int a
           {|RH5107:,|} int b
           {|RH5107:,|}int c)
    {
        Func<int, int, int> f = (int x
            {|RH5107:,|} int y) => x;
        N(1
          , 2);
    }

    void N(params int[] values)
    {
    }
}
```

### RH5107-002 — The diagnostic is on the comma

The analyzer MUST report one diagnostic per misplaced comma, located on the comma.

Why: Each comma is moved on its own.

Example: see RH5107-001.

### RH5107-003 — The fix moves the comma behind the previous parameter

The code fix MUST insert the comma directly behind the parameter in front of it and remove it from its own line. When the comma's line holds more than whitespace after the comma, the indentation, the comma, and the whitespace after it MUST be replaced with spaces up to the column of the list's first parameter. When nothing but whitespace remains on the comma's line, that line MUST be removed, line break included.

Why: The parameter that followed the comma now starts its line, so it is aligned under the first parameter. A line that held only the comma would otherwise stay behind empty.

Example:

```csharp
class C
{
    void M(int a
           {|RH5107:,|} int b)
    {
    }

    void N(int a
           {|RH5107:,|}
           int b)
    {
    }
}
```

```csharp
class C
{
    void M(int a,
           int b)
    {
    }

    void N(int a,
           int b)
    {
    }
}
```
