# Analyzer — RH4112 Protected property casing

| | |
|---|---|
| ID prefix | RH4112 |
| Status | Active |
| Category | Naming |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH4112ProtectedPropertyCasingAnalyzer`, `RH4112ProtectedPropertyCasingCodeFixProvider` |
| Uses | SHARED-CASING-001, SHARED-CASING-004, SHARED-CASING-006, SHARED-CASING-007, SHARED-CASING-008, SHARED-CASING-009, SHARED-CASING-010 |

RH4112 reports a protected property whose name is not in PascalCase and offers a code fix that renames the property and every reference to it.

## Non-goals

- Properties of the private, internal, and public groups — RH4111, RH4113, and RH4114.
- Names of fields — RH4106 to RH4110.

## Requirements

### RH4112-001 — Protected property names are in PascalCase

The analyzer MUST report every property declaration that belongs to the protected group of SHARED-CASING-004 and whose name is not in PascalCase as SHARED-CASING-001 defines it. Static properties and expression-bodied properties MUST be checked too. The analyzer MUST report one diagnostic per property, located on its identifier.

Why: A protected property is part of the surface a derived type programs against, and it is read like any other member of the type, so it is named like the other members.

Example:

```csharp
public class C
{
    protected int {|RH4112:count|} { get; set; }
    private protected int {|RH4112:offset|} { get; set; }
    protected static int {|RH4112:instance_count|} => 0;
    protected int Limit { get; set; }
    protected internal int scale { get; set; }
    int total { get; set; }
}
```

### RH4112-002 — The fix renames the property to PascalCase

The code fix MUST rename the property and every reference to it (SHARED-CASING-007) to the PascalCase name that SHARED-CASING-006 derives from its old name. It is withheld as SHARED-CASING-008 and SHARED-CASING-009 specify, and its Fix All skips colliding names as SHARED-CASING-010 specifies. This requirement covers the renames that SHARED-CASING-007 covers.

Why: The fix makes exactly the change the diagnostic asks for, and a property is referenced throughout its type and the types derived from it.

Example:

```csharp
public class BaseView
{
    protected int {|RH4112:item_count|} { get; set; }

    protected int {|RH4112:offset|} => 0;

    public int Sum => item_count + offset;
}
```

```csharp
public class BaseView
{
    protected int ItemCount { get; set; }

    protected int Offset => 0;

    public int Sum => ItemCount + Offset;
}
```
