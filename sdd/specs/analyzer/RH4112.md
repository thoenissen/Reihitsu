# Analyzer — RH4112 Protected property casing

| | |
|---|---|
| ID prefix | RH4112 |
| Status | Active |
| Category | Naming |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH4112ProtectedPropertyCasingAnalyzer`, `RH4112ProtectedPropertyCasingCodeFixProvider` |
| Uses | SHARED-CASING-001, SHARED-CASING-004, SHARED-CASING-006, SHARED-CASING-007, SHARED-CASING-008, SHARED-CASING-009, SHARED-CASING-010 |

RH4112 reports a protected property whose name is not in PascalCase and offers a code fix that renames the property and every reference to it.

## Non-goals

- Properties of the private, internal, and public groups — RH4111, RH4113, and RH4114.
- Names of fields — RH4106 to RH4110.

## Requirements

### RH4112-001 — Protected property names are in PascalCase

The analyzer MUST report every property declaration that belongs to the protected group of SHARED-CASING-004 and whose name is not in PascalCase as SHARED-CASING-001 defines it. Static, expression-bodied, virtual, and abstract properties, and overrides whose original definition is declared in source, MUST be checked too. The analyzer MUST report one diagnostic per property declaration, located on its identifier, so each part of a partial property gets its own diagnostic.

This requirement covers a property whose original definition is declared in source: following the properties it overrides, through every level, and the interface properties it implicitly implements never leads to a property declared in a referenced assembly.

Why: A protected property is part of the surface a derived type programs against, and it is read like any other member of the type, so it is named like the other members.

Example:

```csharp
public class C
{
    protected int {|RH4112:count|} { get; set; }
    private protected int {|RH4112:offset|} { get; set; }
    protected static int {|RH4112:instance_count|} => 0;
    protected int Limit { get; set; }
    protected internal int scale { get; set; }
    int total { get; set; }
}
```

Example — a partial property, reported on each part:

```csharp
public partial class C
{
    protected partial int {|RH4112:count|} { get; }
}

public partial class C
{
    protected partial int {|RH4112:count|} => 0;
}
```

### RH4112-002 — The fix renames the property to PascalCase

The code fix MUST rename the property and every reference to it (SHARED-CASING-007) to the PascalCase name that SHARED-CASING-006 derives from its old name. Renaming a property also renames, in source, the properties it overrides and the properties that override it. It is withheld as SHARED-CASING-008 and SHARED-CASING-009 specify, and its Fix All skips colliding names as SHARED-CASING-010 specifies. This requirement covers the renames that SHARED-CASING-007 covers, for the properties that RH4112-001 covers. It further covers only a property whose name is not also the name of a parameter of its record's primary constructor.

Why: The fix makes exactly the change the diagnostic asks for, and a property is referenced throughout its type and the types derived from it.

Example:

```csharp
public class BaseView
{
    protected int {|RH4112:item_count|} { get; set; }

    protected int {|RH4112:offset|} => 0;

    public int Sum => item_count + offset;
}
```

```csharp
public class BaseView
{
    protected int ItemCount { get; set; }

    protected int Offset => 0;

    public int Sum => ItemCount + Offset;
}
```

Example — an override in source:

```csharp
public class BaseView
{
    protected virtual int {|RH4112:row_count|} => 0;
}

public class GridView : BaseView
{
    protected override int {|RH4112:row_count|} => 1;
}
```

```csharp
public class BaseView
{
    protected virtual int RowCount => 0;
}

public class GridView : BaseView
{
    protected override int RowCount => 1;
}
```
