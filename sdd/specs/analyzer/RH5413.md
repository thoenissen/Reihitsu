# Analyzer — RH5413 Empty structs should use semicolon declarations

| | |
|---|---|
| ID prefix | RH5413 |
| Status | Active |
| Category | Layout |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH5413EmptyStructsShouldUseSemicolonDeclarationsAnalyzer`, `RH5413EmptyStructsShouldUseSemicolonDeclarationsCodeFixProvider` |
| Uses | SHARED-EMPTY-001, SHARED-EMPTY-002, SHARED-EMPTY-003, SHARED-EMPTY-004 |

RH5413 reports a struct declaration with an empty brace body from C# 12 on, and offers a code fix that replaces the braces with a semicolon as SHARED-EMPTY-003 specifies, unless SHARED-EMPTY-004 withholds it.

## Non-goals

- Empty classes — RH5412; interfaces — RH5414; records — RH5415; record structs — RH5416.

## Requirements

### RH5413-001 — An empty struct is reported from C# 12 on

The analyzer MUST report a struct declaration, with any modifiers such as `readonly` or `ref`, as SHARED-EMPTY-001 and SHARED-EMPTY-002 specify when the project's C# version is 12 or later. Below C# 12 it MUST NOT report a struct. A record struct MUST NOT be reported by this rule.

Why: C# 12 is the first version in which a struct can be declared with a semicolon instead of a body. A record struct is a record, which RH5416 checks.

Example:

```csharp
struct {|RH5413:A|}
{
}

readonly ref struct {|RH5413:B|}
{
}

record struct C
{
}
```

Under C# 11, no struct is reported.
