# Analyzer — RH7405 Non-override methods should not be placed in override regions

| | |
|---|---|
| ID prefix | RH7405 |
| Status | Active |
| Category | Organization |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH7405NonOverrideMethodsShouldNotBePlacedInOverrideRegionsAnalyzer` |
| Uses | SHARED-DIAG-004, SHARED-DIAG-012, SHARED-REGGROUP-001, SHARED-REGGROUP-005, SHARED-REGGROUP-006, SHARED-TYPEREGION-006 |

RH7405 reports a method that overrides nothing when it lies in a top-level region named after the type that one of the type's override methods comes from. It has no code fix.

## Non-goals

- Where an override method belongs — RH7401.
- Properties, events, and indexers that override nothing — RH7406, RH7407, RH7408.

## Requirements

### RH7405-001 — A method that overrides nothing in an override region is reported

In every type declaration it checks (SHARED-REGGROUP-001), the analyzer MUST report each method declaration that overrides no method — a static, `new`, `virtual`, or `abstract` method and an interface implementation alike — when it lies in a top-level region (SHARED-TYPEREGION-006), and in no region nested in it, that is an override region of methods (SHARED-REGGROUP-006). The diagnostic MUST be placed as SHARED-REGGROUP-005 specifies.

A `partial` method is one method (SHARED-DIAG-004): it is reported at most once, on the part SHARED-DIAG-012 selects. This requirement covers a `partial` method only when each of its parts, judged on its own, would be reported; whether a `partial` method is reported when only some of its parts would be is not covered.

Why: A region named after a base type groups the members that override that type's members. A helper method placed among them hides the override surface of the type and makes inheritance-focused navigation unreliable.

Example:

```csharp
interface IRunnable
{
    void Run();
}

class B
{
    public virtual void M()
    {
    }
}

class C : B, IRunnable
{
    #region B

    public override void M()
    {
    }

    public static void {|RH7405:S|}()
    {
    }

    public new string {|RH7405:ToString|}() => "";

    public void {|RH7405:Run|}()
    {
    }

    #endregion
}
```

Example — a `partial` method that overrides nothing and whose parts both lie in an override region is reported once, on its defining part:

```csharp
class B
{
    public virtual void Run()
    {
    }
}

partial class C : B
{
    #region B

    public override void Run()
    {
    }

    public partial void {|RH7405:N|}();

    public partial void N()
    {
    }

    #endregion
}
```

### RH7405-002 — Other members and other regions are not reported

The analyzer MUST NOT report a method that lies in no region, or in a top-level region that is not an override region and in no region nested in it. It MUST NOT report an override method or a member that is not a method declaration, such as a constructor or an operator.

Why: Outside an override region a method that overrides nothing is where it belongs, an override in an override region is where RH7401 asks it to be, and constructors and operators are other kinds of member.

Example:

```csharp
class B
{
    public virtual void M()
    {
    }
}

class C : B
{
    #region B

    public override void M()
    {
    }

    public C()
    {
    }

    public static C operator +(C left, C right) => left;

    #endregion

    #region Methods

    private void N()
    {
    }

    #endregion
}
```

is not reported.
