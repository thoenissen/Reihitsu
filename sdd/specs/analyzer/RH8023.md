# Analyzer — RH8023 Private properties must be documented

| | |
|---|---|
| ID prefix | RH8023 |
| Status | Active |
| Category | Documentation |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH8023PrivatePropertiesMustBeDocumentedAnalyzer` |
| Uses | SHARED-DOC-001, SHARED-DOC-002, SHARED-DOC-004, SHARED-DOC-005, SHARED-DOC-006, SHARED-DOC-007, SHARED-DOC-008, SHARED-DOC-009 |

RH8023 reports a property in the private group that has no `<summary>` or `<inheritdoc>` documentation.

## Non-goals

- Properties in the non-private group — RH8022.
- Indexers — RH8024 and RH8025.
- Whether the summary has text — RH8030; the wording of a property summary — RH8306.

## Requirements

### RH8023-001 — Undocumented private properties are reported

The analyzer MUST report every property declaration in the private group of SHARED-DOC-002 that is not documented, checked as SHARED-DOC-001 specifies, except an explicit interface implementation, which SHARED-DOC-009 exempts although it has no access modifier. A property declaration is a property declared in the body of a class, struct, interface, record, record struct, or extension block; an indexer is not one. The group is decided by the modifiers of the property, not by those of its accessors. Whether it is documented MUST be decided as SHARED-DOC-004, SHARED-DOC-005, SHARED-DOC-006, and SHARED-DOC-007 specify, and nothing is reported when SHARED-DOC-008 applies.

Why: A private property is visible only inside its type, so nothing outside the type explains what it holds. The summary records what the value stands for and when it is valid, and the editor shows it at every use inside the file. It has a rule of its own, so a project can require documentation for what other code uses without requiring it here.

Example:

```csharp
/// <summary>
/// Entity
/// </summary>
public interface IEntity
{
    /// <summary>
    /// Gets the name
    /// </summary>
    string Name { get; }
}

/// <summary>
/// Settings
/// </summary>
public class Settings : IEntity
{
    private string {|RH8023:Cache|} { get; set; }

    /// <remarks>
    /// No summary
    /// </remarks>
    int {|RH8023:Count|} => 0;

    /// <summary>
    /// Gets the profile
    /// </summary>
    private string Profile { get; }

    public int Version { get; private set; }

    string IEntity.Name => "";
}

/// <summary>
/// Point
/// </summary>
public struct Point
{
    int {|RH8023:Length|} => 0;
}
```

### RH8023-002 — The diagnostic is on the property name

The analyzer MUST report one diagnostic per undocumented property declaration, located on its identifier.

Why: The name is what the documentation describes; marking it identifies the declaration without marking its accessors.

Example: see RH8023-001.
