# Analyzer — RH8015 Non-private delegates must be documented

| | |
|---|---|
| ID prefix | RH8015 |
| Status | Active |
| Category | Documentation |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH8015NonPrivateDelegatesMustBeDocumentedAnalyzer` |
| Uses | SHARED-DOC-001, SHARED-DOC-002, SHARED-DOC-004, SHARED-DOC-005, SHARED-DOC-006, SHARED-DOC-007, SHARED-DOC-008 |

RH8015 reports a delegate in the non-private group that has no `<summary>` or `<inheritdoc>` documentation.

## Non-goals

- Delegates in the private group — RH8016.
- Whether the summary has text — RH8030; the documentation of parameters, the return value, and type parameters — RH8101, RH8105, and RH8108.

## Requirements

### RH8015-001 — Undocumented non-private delegates are reported

The analyzer MUST report every delegate declaration in the non-private group of SHARED-DOC-002 that is not documented, checked as SHARED-DOC-001 specifies. Generic delegates and delegates nested in other types are delegate declarations too. Whether it is documented MUST be decided as SHARED-DOC-004, SHARED-DOC-005, SHARED-DOC-006, and SHARED-DOC-007 specify, and nothing is reported when SHARED-DOC-008 applies.

Why: A delegate that other code can use is part of the contract that code builds on. Without a summary, the generated documentation and the editor's tooltip show nothing, and readers have to infer what the delegate is for from its implementation.

Example:

```csharp
public delegate void {|RH8015:Handler|}(object sender);

/// <remarks>
/// No summary
/// </remarks>
internal delegate int {|RH8015:Counter|}();

delegate T {|RH8015:Factory|}<T>();

/// <summary>
/// Outer
/// </summary>
public class Outer
{
    protected delegate void {|RH8015:Callback|}();

    private delegate void Hidden();
}
```

### RH8015-002 — The diagnostic is on the delegate name

The analyzer MUST report one diagnostic per undocumented delegate declaration, located on its identifier, without its type parameter list.

Why: The name is what the documentation describes; marking it identifies the declaration without marking its whole body.

Example: see RH8015-001.
