# Analyzer — RH2108 Nested delegates should not be used

| | |
|---|---|
| ID prefix | RH2108 |
| Status | Active |
| Category | Design |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH2108NestedDelegatesShouldNotBeUsedAnalyzer` |
| Uses | SHARED-NESTED-001, SHARED-NESTED-002 |

RH2108 reports a delegate declared inside another type.

## Non-goals

- Nested classes, structs, interfaces, records, and enums — RH2101, RH2104, RH2105, RH2106, and RH2107.

## Requirements

### RH2108-001 — A nested delegate is reported

The analyzer MUST report a delegate declaration that is nested as SHARED-NESTED-001 defines it, located as SHARED-NESTED-002 specifies.

Why: A delegate inside another type is harder to find and to reuse as the contract of a callback. A top-level delegate keeps that contract visible.

Example:

```csharp
class Outer
{
    delegate void {|RH2108:Callback|}(int value);
}

interface I
{
    delegate int {|RH2108:Selector|}();
}
```
