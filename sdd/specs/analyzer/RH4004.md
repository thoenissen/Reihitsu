# Analyzer — RH4004 Enum name casing

| | |
|---|---|
| ID prefix | RH4004 |
| Status | Active |
| Category | Naming |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH4004EnumNameCasingAnalyzer`, `RH4004EnumNameCasingCodeFixProvider` |
| Uses | SHARED-CASING-001, SHARED-CASING-006, SHARED-CASING-007, SHARED-CASING-008, SHARED-CASING-009, SHARED-CASING-010 |

RH4004 reports an enum whose name is not in PascalCase and offers a code fix that renames the enum and every reference to it.

## Non-goals

- The names of enum members — RH4101.
- Class, struct, interface, and delegate names — RH4002, RH4003, RH4005, and RH4006.

## Requirements

### RH4004-001 — Enum names are in PascalCase

The analyzer MUST report every enum declaration whose name is not in PascalCase as SHARED-CASING-001 defines it, whatever its accessibility, attributes, or nesting. The diagnostic MUST be located on the enum's identifier.

Why: An enum is a type; PascalCase is how .NET spells type names, and a reader recognizes a type by it.

Example:

```csharp
using System;

public enum Direction
{
}

[Flags]
public enum {|RH4004:accessMode|}
{
}

public class C
{
    internal enum {|RH4004:errorKind|}
    {
    }
}
```

### RH4004-002 — The fix renames the enum to PascalCase

The code fix MUST rename the enum and every reference to it (SHARED-CASING-007) to the PascalCase name that SHARED-CASING-006 derives from its old name. It is withheld as SHARED-CASING-008 and SHARED-CASING-009 specify, and its Fix All skips colliding names as SHARED-CASING-010 specifies.

Why: The fix makes exactly the change the diagnostic asks for, and an enum is referenced wherever its type or one of its members is used.

Example:

```csharp
public enum {|RH4004:orderState|}
{
    Open
}

public class C
{
    public orderState State = orderState.Open;
}
```

```csharp
public enum OrderState
{
    Open
}

public class C
{
    public OrderState State = OrderState.Open;
}
```
