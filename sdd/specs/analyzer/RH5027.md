# Analyzer — RH5027 While-do footer must not be preceded by blank line

| | |
|---|---|
| ID prefix | RH5027 |
| Status | Active |
| Category | Layout |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH5027WhileDoFooterMustNotBePrecededByBlankLineAnalyzer`, `RH5027WhileDoFooterMustNotBePrecededByBlankLineCodeFixProvider` |
| Uses | SHARED-WS-001 |

RH5027 reports a blank line directly above the line that holds the `while` footer of a `do` statement, and offers a code fix that deletes it as SHARED-WS-001 specifies.

In the examples, a reported blank line is marked from its start to the end of its line break, so the markup encloses the line break itself.

## Non-goals

- `while` statements — they have no footer.
- The other blank lines of a run above the footer — RH5023.

## Requirements

### RH5027-001 — A blank line above a `do` statement's footer is reported

The analyzer MUST report the blank line directly above the line that holds the `while` keyword of a `do` statement whose `while` keyword is on a later line than its `do` keyword, whether the `while` keyword begins its line or follows the body's closing brace on it. A line holding nothing but whitespace counts as blank. A blank line above `} while` is reported by RH5024 as well.

Why: The footer closes the `do` statement; a blank line between the body and the footer makes the footer look like the start of a separate `while` loop.

Example:

```csharp
class C
{
    void M(int a)
    {
        do
        {
            a++;
        }
{|RH5027:
|}        while (a < 3);

        do
        {
            a++;
{|RH5027:
|}        } while (a < 4);
    }
}
```

### RH5027-002 — A `while` statement is not reported

The analyzer MUST NOT report a blank line above the `while` keyword of a `while` statement.

Why: A `while` statement starts a loop of its own, and the blank line above it separates it from the code before it.

Example:

```csharp
class C
{
    void M(int a)
    {
        a++;

        while (a < 5)
        {
            a++;
        }
    }
}
```

is not reported.

### RH5027-003 — One diagnostic per footer, on the line directly above it

The analyzer MUST report one diagnostic per `do` statement, located on the line directly above the line that holds the `while` keyword, from the line's start to the end of its line break.

Why: The diagnostic covers exactly the line the footer touches; a run of blank lines is RH5023's concern.

Example: see RH5027-001.

### RH5027-004 — The fix deletes the blank line

The code fix MUST delete the reported line as SHARED-WS-001 specifies. It is offered for every reported line.

Why: The reported span holds nothing but whitespace and its line break, so deleting it can never touch a comment, a directive, or a token.

Example:

```csharp
class C
{
    void M(int a)
    {
        do
        {
            a++;
        }
{|RH5027:
|}        while (a < 3);
    }
}
```

```csharp
class C
{
    void M(int a)
    {
        do
        {
            a++;
        }
        while (a < 3);
    }
}
```
