# Analyzer — RH5027 While-do footer must not be preceded by blank line

| | |
|---|---|
| ID prefix | RH5027 |
| Status | Active |
| Category | Layout |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH5027WhileDoFooterMustNotBePrecededByBlankLineAnalyzer`, `RH5027WhileDoFooterMustNotBePrecededByBlankLineCodeFixProvider` |
| Uses | RH5024-001, SHARED-DIAG-003, SHARED-FIX-001, SHARED-WS-001 |

RH5027 reports a blank line directly above the line that holds the `while` footer of a `do` statement, and offers a code fix that deletes it, together with the rest of its run of blank lines, as SHARED-WS-001 specifies for that run.

In the examples, a reported blank line is marked from its start to the end of its line break, so the markup encloses the line break itself.

## Non-goals

- `while` statements — they have no footer.

## Requirements

### RH5027-001 — A blank line above a `do` statement's footer is reported

The analyzer MUST report the blank line directly above the line that holds the `while` keyword of a `do` statement, when nothing but whitespace, or whitespace and the closing brace of the statement's block body, stands in front of the `while` keyword on its line. A line holding nothing but whitespace counts as blank. A blank line above `} while` is reported by RH5024 as well.

Why: The footer closes the `do` statement; a blank line between the body and the footer makes the footer look like the start of a separate `while` loop.

Example:

```csharp
class C
{
    void M(int a)
    {
        do
        {
            a++;
        }
{|RH5027:
|}        while (a < 3);

        do
        {
            a++;
{|RH5027:
|}        } while (a < 4);
    }
}
```

Example — code, a comment, or the end of a literal or a comment stands in front of the `while` keyword on its line, so the line above is not the footer's gap:

```csharp
class C
{
    void M(int a)
    {
        a++;

        do a++; while (a < 3);
        string s;
        do s = @"x

".Trim(); while (s.Length > 3);
        do a++; /* x

        */ while (a < 4);
        do
            a++;

        /* c */ while (a < 5);
        do
        {
            a++;

        } /* c */ while (a < 6);
    }
}
```

is not reported. The empty lines inside the literal and the comment are part of their text (SHARED-DIAG-003). In front of the last two `while` keywords stands a comment, so their lines are not the footer's gap either; the blank line above `} /* c */ while` is reported by RH5024 (RH5024-001).

### RH5027-002 — A `while` statement is not reported

The analyzer MUST NOT report a blank line above the `while` keyword of a `while` statement.

Why: A `while` statement starts a loop of its own, and the blank line above it separates it from the code before it.

Example:

```csharp
class C
{
    void M(int a)
    {
        a++;

        while (a < 5)
        {
            a++;
        }
    }
}
```

is not reported.

### RH5027-003 — One diagnostic per footer, on the line directly above it

The analyzer MUST report one diagnostic per `do` statement, located on the line directly above the line that holds the `while` keyword, from the line's start to the end of its line break.

Why: The diagnostic covers exactly the line the footer touches, which the fix deletes together with the rest of its run.

Example: see RH5027-001.

### RH5027-004 — The fix deletes the run of blank lines

The code fix MUST delete the reported line together with every blank line of the run it belongs to — the blank lines that directly precede it, up to the previous line that is not blank — and MUST NOT change any other text, as SHARED-WS-001 specifies for the span of that run. It is offered for every reported line.

Why: For the lines RH5027-001 names, the run lies between two tokens and holds nothing but whitespace and line breaks, so deleting it can never touch a comment, a directive, a literal, or a token. One application removes the whole run (SHARED-FIX-001); deleting only the reported line would leave a blank line that the rule reports again.

Example:

```csharp
class C
{
    void M(int a)
    {
        do
        {
            a++;
        }
{|RH5027:
|}        while (a < 3);
    }
}
```

```csharp
class C
{
    void M(int a)
    {
        do
        {
            a++;
        }
        while (a < 3);
    }
}
```

Example — a run of two blank lines; RH5023 reports the line directly above the footer as well:

```csharp
class C
{
    void M(int a)
    {
        do
        {
            a++;
        }

{|RH5027:
|}        while (a < 3);
    }
}
```

```csharp
class C
{
    void M(int a)
    {
        do
        {
            a++;
        }
        while (a < 3);
    }
}
```
