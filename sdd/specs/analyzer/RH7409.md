# Analyzer — RH7409 Interface implementation methods should be grouped by interface regions

| | |
|---|---|
| ID prefix | RH7409 |
| Status | Active |
| Category | Organization |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH7409InterfaceMethodsShouldBeGroupedByInterfaceRegionsAnalyzer` |
| Uses | SHARED-REGGROUP-001, SHARED-REGGROUP-002, SHARED-REGGROUP-003, SHARED-REGGROUP-005, SHARED-REGGROUP-006 |

RH7409 reports a method that implements an interface method, explicitly or implicitly, when it does not lie in a top-level region named after the interface that declares the member. It has no code fix.

## Non-goals

- Interface implementations that are properties, events, or indexers — RH7410, RH7411, RH7412.
- An override that implements an interface method — RH7401.

## Requirements

### RH7409-001 — An interface implementation method outside its interface's region is reported

In every type declaration it checks (SHARED-REGGROUP-001), the analyzer MUST report each method declaration that comes from an interface (SHARED-REGGROUP-005) — an explicit and an implicit implementation alike, a `static` implementation of a `static abstract` member included — when the method does not lie (SHARED-REGGROUP-002) in a top-level region whose name matches (SHARED-REGGROUP-003) that interface, whether it lies in a region of another name or in no region. The diagnostic MUST be placed as SHARED-REGGROUP-006 specifies.

Why: Members that implement an interface are easier to scan when they are grouped by the interface they belong to; a generic region name such as `Methods` hides that relationship in a type that implements several interfaces.

Example:

```csharp
interface IRunnable
{
    void Run();
}

interface IStoppable
{
    void Stop();
}

interface ICreatable
{
    static abstract void Create();
}

class C : IRunnable, IStoppable, ICreatable
{
    #region Methods

    public void {|RH7409:Run|}()
    {
    }

    void IStoppable.{|RH7409:Stop|}()
    {
    }

    #endregion

    public static void {|RH7409:Create|}()
    {
    }
}
```

while implementations in the regions named after their interfaces:

```csharp
interface IRunnable
{
    void Run();
}

interface IStoppable
{
    void Stop();
}

class C : IRunnable, IStoppable
{
    #region IRunnable

    public void Run()
    {
    }

    #endregion

    #region IStoppable

    void IStoppable.Stop()
    {
    }

    #endregion
}
```

are not reported.

### RH7409-002 — Other members are not reported

The analyzer MUST NOT report a method that implements no interface member, an override method, or an interface implementation that is not a method declaration.

Why: A method that implements nothing has no interface to be grouped by, an override is grouped by its base type (SHARED-REGGROUP-005), and the other member kinds have rules of their own.

Example:

```csharp
interface INamed
{
    string Name { get; }
}

class C : INamed
{
    #region Properties

    public string Name => "";

    #endregion

    #region Methods

    public void M()
    {
    }

    #endregion
}
```

is not reported.
