# Analyzer — RH7409 Interface implementation methods should be grouped by interface regions

| | |
|---|---|
| ID prefix | RH7409 |
| Status | Active |
| Category | Organization |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH7409InterfaceMethodsShouldBeGroupedByInterfaceRegionsAnalyzer` |
| Uses | SHARED-DIAG-004, SHARED-DIAG-012, SHARED-REGGROUP-001, SHARED-REGGROUP-002, SHARED-REGGROUP-004, SHARED-REGGROUP-005, SHARED-TYPEREGION-006 |

RH7409 reports a method that implements an interface method, explicitly or implicitly, when it does not lie in a region named after an interface that declares the member, judged by the innermost region that encloses it. It has no code fix.

## Non-goals

- Interface implementations that are properties, events, or indexers — RH7410, RH7411, RH7412.
- An override that implements an interface method — RH7401.

## Requirements

### RH7409-001 — An interface implementation method outside its interface's region is reported

In every type declaration it checks (SHARED-REGGROUP-001), the analyzer MUST report each method declaration that comes from an interface (SHARED-REGGROUP-004) — an explicit and an implicit implementation alike, a `static` implementation of a `static abstract` member included — when the innermost region that encloses it (SHARED-REGGROUP-001, SHARED-TYPEREGION-006) does not have a name that matches (SHARED-REGGROUP-002) that interface, or one of those interfaces when it implements members of several (SHARED-REGGROUP-004) — whether it lies in a region of another name, in a region of another name nested in a region that matches, or in no region. The diagnostic MUST be placed as SHARED-REGGROUP-005 specifies.

A `partial` method is one method (SHARED-DIAG-004): it is reported at most once, on the part SHARED-DIAG-012 selects. It is reported when any of its parts, judged on its own by the region it lies in, would be reported: every part has to lie in a matching region.

Why: Members that implement an interface are easier to scan when they are grouped by the interface they belong to; a generic region name such as `Methods` hides that relationship in a type that implements several interfaces.

Example:

```csharp
interface IRunnable
{
    void Run();
}

interface IStoppable
{
    void Stop();
}

interface ICreatable
{
    static abstract void Create();
}

class C : IRunnable, IStoppable, ICreatable
{
    #region Methods

    public void {|RH7409:Run|}()
    {
    }

    void IStoppable.{|RH7409:Stop|}()
    {
    }

    #endregion

    public static void {|RH7409:Create|}()
    {
    }
}
```

while implementations in the regions named after their interfaces:

```csharp
interface IRunnable
{
    void Run();
}

interface IStoppable
{
    void Stop();
}

class C : IRunnable, IStoppable
{
    #region IRunnable

    public void Run()
    {
    }

    #endregion

    #region IStoppable

    void IStoppable.Stop()
    {
    }

    #endregion
}
```

are not reported.

Example — a `partial` method whose parts both lie outside a matching region is reported once, on its defining part:

```csharp
interface I
{
    void M();
}

partial class C : I
{
    #region Methods

    public partial void {|RH7409:M|}();

    public partial void M()
    {
    }

    #endregion
}
```

Example — a `partial` method of which only one part lies in the region of its interface is reported once, on the part that does not, whichever part that is:

```csharp
interface I
{
    void M();

    void N();
}

partial class C : I
{
    #region Methods

    public partial void {|RH7409:M|}();

    public partial void {|RH7409:N|}()
    {
    }

    #endregion

    #region I

    public partial void M()
    {
    }

    public partial void N();

    #endregion
}
```

### RH7409-002 — Other members are not reported

The analyzer MUST NOT report a method that implements no interface member, an override method, or an interface implementation that is not a method declaration.

Why: A method that implements nothing has no interface to be grouped by, an override is grouped by its base type (SHARED-REGGROUP-004), and the other member kinds have rules of their own.

Example:

```csharp
interface INamed
{
    string Name { get; }
}

class C : INamed
{
    #region Properties

    public string Name => "";

    #endregion

    #region Methods

    public void M()
    {
    }

    #endregion
}
```

is not reported.
