# Analyzer — RH5521 Interface attributes must be on their own line

| | |
|---|---|
| ID prefix | RH5521 |
| Status | Active |
| Category | Layout |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH5521InterfaceAttributesMustFollowPlacementRulesAnalyzer`, `RH5521InterfaceAttributesMustFollowPlacementRulesCodeFixProvider` |
| Uses | SHARED-ATTR-001, SHARED-ATTR-004, SHARED-ATTR-005, SHARED-ATTR-007, SHARED-ATTR-008, SHARED-ATTR-011, SHARED-ATTR-012 |

RH5521 reports an attribute list of an interface that shares its line with the token after it, and offers a code fix that moves that token onto the next line. The rule uses `shared/attribute-targets.md`.

## Non-goals

- Attributes of the members of an interface — the member rules, such as RH5513 and RH5515.

## Requirements

### RH5521-001 — Interface attribute lists are on their own line

The analyzer MUST check every attribute list that resolves to the interface target: the lists of an `interface` declaration without a specifier or with `type:` (SHARED-ATTR-001), and MUST report such a list whose closing bracket shares its line with the first token after it, as SHARED-ATTR-004 and SHARED-ATTR-005 specify for a list that must be on its own line.

Why: A reader scanning a file for its types looks down a column of modifiers and type names; an attribute in front of the declaration pushes that line to the right by however long the attribute is.

Example:

```csharp
{|RH5521:[A]|} interface I
{
}

[A]
interface J
{
}
```

### RH5521-002 — The diagnostic is on the attribute list

The analyzer MUST report the diagnostic on the attribute list, as SHARED-ATTR-007 specifies.

Why: The list is what is misplaced; each list of a declaration is reported and fixed on its own.

Example: see RH5521-001.

### RH5521-003 — The fix moves what follows onto the next line

The code fix MUST put the first token after the list on a new line, as SHARED-ATTR-008 specifies.

Why: The fix makes only the change the diagnostic asks for: what follows the list starts on its own line.

Example:

```csharp
{|RH5521:[A]|} interface I
{
}
```

```csharp
[A]
interface I
{
}
```

### RH5521-004 — The fix is withheld for comments, directives, and missing braces

The code fix MUST NOT be offered when SHARED-ATTR-011 or SHARED-ATTR-012 withholds it. The diagnostic is still reported.

Why: A comment inside the list belongs to the attribute next to it, and an unclosed scope leaves no indentation to compute; both are left to the author.

Example:

```csharp
{|RH5521:[A /* c */]|} interface I
{
}
```

is reported, and no code fix is offered.
