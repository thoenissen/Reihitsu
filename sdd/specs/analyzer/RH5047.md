# Analyzer — RH5047 Comments must not be placed inside an auto-property accessor list

| | |
|---|---|
| ID prefix | RH5047 |
| Status | Active |
| Category | Layout |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH5047CommentsMustNotBePlacedInsideAutoPropertyAccessorListAnalyzer` |
| Uses | SHARED-COMMENT-001, SHARED-COMMENT-002, SHARED-COMMENT-003, SHARED-COMMENT-004, SHARED-COMMENT-005, SHARED-COMMENT-006, SHARED-COMMENT-008, SHARED-COMMENT-009 |

RH5047 reports a comment placed inside the accessor list of a property or indexer whose accessors have no body, or between its signature and that accessor list.

## Non-goals

- A comment around the `=` of a property initializer — RH5042.
- How an accessor list is laid out — the line-break rules.

## Requirements

### RH5047-001 — A comment inside an auto-property accessor list is reported

The analyzer MUST report every ordinary comment (SHARED-COMMENT-001, SHARED-COMMENT-002) inside the accessor list of a property or an indexer, from `{` to `}`, when none of its accessors has a block body or an expression body, as SHARED-COMMENT-003, SHARED-COMMENT-004, SHARED-COMMENT-005, SHARED-COMMENT-006, SHARED-COMMENT-008, and SHARED-COMMENT-009 specify for a region. An accessor list in which any accessor has a body, and the accessor list of an event, MUST NOT be checked.

Why: An auto-property, an abstract property, and an interface property are single short declarations; a comment inside their accessor list describes only part of them and splits them across lines. An accessor with a body is a declaration of its own, so a comment above it describes that accessor.

Example:

```csharp
using System;

abstract class C
{
    private int _value;

    public int Value
    {
        {|RH5047:// read|}
        get;
        set;
    }

    public int Other { get; {|RH5047:/* write */|} }

    public abstract int Abstract { {|RH5047:/* read */|} get; }

    public int Stored
    {
        // read
        get { return _value; }
        set { _value = value; }
    }

    public int Computed
    {
        // computed
        get => 1;
    }

    public event Action Changed
    {
        // subscribe
        add { }
        remove { }
    }
}
```

The comments in `Stored`, `Computed`, and `Changed` are not reported.

### RH5047-002 — A comment before an auto-property accessor list is reported

The analyzer MUST also report a comment directly before the `{` of an accessor list that RH5047-001 checks. A comment before the property and a comment after the accessor list MUST NOT be reported.

Why: An auto-property is read as one line; a comment between its signature and its accessor list splits it just like a comment inside the list.

Example:

```csharp
interface I
{
    int Value
        {|RH5047:// storage|}
        { get; set; }

    // read only
    int this[int index] { get; }
    // next
    int Other { get; }
}
```

The comments `// read only` and `// next` are not reported.
