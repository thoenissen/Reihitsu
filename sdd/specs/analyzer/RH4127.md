# Analyzer — RH4127 Single-letter catch exception variable names

| | |
|---|---|
| ID prefix | RH4127 |
| Status | Active |
| Category | Naming |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH4127SingleLetterCatchExceptionVariableNamesAnalyzer` |
| Uses | SHARED-SINGLE-001 |

RH4127 reports the exception variable of a `catch` declaration whose name is a single letter.

## Non-goals

- Other local variables — RH4125 and RH4126.
- The casing of exception variable names — RH4115.

## Requirements

### RH4127-001 — Single-letter exception variable names are reported

The analyzer MUST report the exception variable of a `catch` declaration whose name is a single-letter name (SHARED-SINGLE-001). A `catch` clause that declares no variable is not reported. The analyzer MUST report one diagnostic per variable, located on its identifier.

Why: A descriptive exception name makes error-handling code clearer, especially where the exception is logged, wrapped, or inspected.

Example:

```csharp
using System;

class C
{
    void M()
    {
        try
        {
        }
        catch (ArgumentException {|RH4127:e|})
        {
        }
        catch (FormatException _)
        {
        }
        catch (InvalidOperationException exception)
        {
        }
        catch (Exception)
        {
        }
    }
}
```
