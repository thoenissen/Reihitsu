# Analyzer — RH5418 Empty unions should use semicolon declarations

| | |
|---|---|
| ID prefix | RH5418 |
| Status | Active |
| Category | Layout |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH5418EmptyUnionsShouldUseSemicolonDeclarationsAnalyzer`, `RH5418EmptyUnionsShouldUseSemicolonDeclarationsCodeFixProvider` |
| Uses | SHARED-EMPTY-001, SHARED-EMPTY-002, SHARED-EMPTY-003, SHARED-EMPTY-004 |

RH5418 reports a union declaration with an empty brace body from C# 15 on, and offers a code fix that replaces the braces with a semicolon as SHARED-EMPTY-003 specifies, unless SHARED-EMPTY-004 withholds it.

## Non-goals

- Empty classes — RH5412; structs — RH5413; interfaces — RH5414; records — RH5415; record structs — RH5416.
- A union's case-type list, which is not a body: every union declares its case types in one of its declarations, and the list is never checked for being empty.

## Requirements

### RH5418-001 — An empty union is reported from C# 15 on

The analyzer MUST report a union declaration, with any modifiers such as `readonly` or `partial`, with or without type parameters and constraint clauses, top-level or nested, as SHARED-EMPTY-001 and SHARED-EMPTY-002 specify when the project's C# version is 15 or later. Below C# 15 it MUST NOT report a union. A struct or record struct MUST NOT be reported by this rule, although the compiler emits a union as a struct.

Why: Union declarations and their semicolon declaration both exist from C# 15 on. A union states what it holds through its case-type list, so its body is often empty. Every other type kind with a semicolon declaration has a rule of its own, and a union is declared with its own keyword, so a project can configure it on its own; structs and record structs are RH5413's and RH5416's.

Example:

```csharp
union {|RH5418:A|}(int, string)
{
}

public readonly union {|RH5418:B|}<T>(T, string)
    where T : class
{
    // reserved
}

union C(int, string);

union D(int, string)
{
    public int Get() => 1;
}

struct E
{
}

class Outer
{
    union {|RH5418:F|}(long, string) { }
}
```

`C` already ends with a semicolon and `D` has a member (SHARED-EMPTY-002); `E` is RH5413's. `B` is reported, and no code fix is offered for it, because the comment keeps its braces (SHARED-EMPTY-004). The fix gives:

```csharp
union A(int, string);

public readonly union B<T>(T, string)
    where T : class
{
    // reserved
}

union C(int, string);

union D(int, string)
{
    public int Get() => 1;
}

struct E
{
}

class Outer
{
    union F(long, string);
}
```

Below C# 15, `union` does not declare a type, so nothing is reported.
