# Analyzer — RH5405 Braces must not be omitted

| | |
|---|---|
| ID prefix | RH5405 |
| Status | Active |
| Category | Layout |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH5405BracesMustNotBeOmittedAnalyzer`, `RH5405BracesMustNotBeOmittedCodeFixProvider` |
| Uses | SHARED-BRACE-001, SHARED-BRACE-002 |

RH5405 reports an `if` or `else` body without braces that is on one line, and offers the code fix of SHARED-BRACE-002, which wraps the body in braces.

## Non-goals

- A body without braces that spans several lines — RH5406.
- An `if` statement whose branches mix bodies with and without braces — RH5407.

## Requirements

### RH5405-001 — An unbraced body on one line is reported

The analyzer MUST report a body that SHARED-BRACE-001 names when it is not a block and is on one line, whether that line is the line of its `if` or `else` or a later one. A body that is a block, and a body without braces that spans several lines, MUST NOT be reported.

Why: A one-line body without braces is the shape in which a second statement is most easily added below it by mistake; a body that spans several lines is RH5406's, so the two rules never report the same body.

Example:

```csharp
class C
{
    void M(bool a, int b)
    {
        if (a)
            {|RH5405:M(a, b);|}
        if (a) {|RH5405:M(a, b);|}
        if (a)
            M(a,
              b);
        if (a)
        {
            M(a, b);
        }
    }
}
```

### RH5405-002 — The diagnostic is on the body

The analyzer MUST report one diagnostic per body, located on the whole body statement.

Why: The body is what the fix wraps in braces.

Example: see RH5405-001.
