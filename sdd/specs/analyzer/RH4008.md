# Analyzer — RH4008 Namespace casing

| | |
|---|---|
| ID prefix | RH4008 |
| Status | Active |
| Category | Naming |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH4008NamespaceCasingAnalyzer` |
| Uses | SHARED-CASING-001, SHARED-CASING-005 |

RH4008 reports each segment of a block-scoped namespace declaration that is not in PascalCase.

## Non-goals

- File-scoped namespace declarations — RH4007.
- Which namespaces a project may declare — RH4009.

## Requirements

### RH4008-001 — Block-scoped namespace names are in PascalCase

The analyzer MUST check the name of every block-scoped namespace declaration segment by segment, as SHARED-CASING-005 specifies, and report each segment that is not in PascalCase as SHARED-CASING-001 defines it.

Why: PascalCase is how .NET spells namespaces; a namespace written otherwise reads like a type or a member in every `using` directive and qualified name.

Example:

```csharp
namespace Reihitsu.{|RH4008:analyzer|}.Naming.{|RH4008:resources|}
{
}

namespace Company.Product
{
}
```
