# Analyzer — RH4124 Single-letter lambda and anonymous method parameter names

| | |
|---|---|
| ID prefix | RH4124 |
| Status | Active |
| Category | Naming |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH4124SingleLetterLambdaAndAnonymousMethodParameterNamesAnalyzer` |
| Uses | SHARED-SINGLE-001 |

RH4124 reports a parameter of a lambda or an anonymous method whose name is a single letter.

## Non-goals

- Parameters of methods and other members — RH4122; of local functions — RH4123.
- The casing of parameter names — RH4105.

## Requirements

### RH4124-001 — Single-letter lambda and anonymous method parameter names are reported

The analyzer MUST report every parameter of a simple lambda, a parenthesized lambda, or an anonymous method whose name is a single-letter name (SHARED-SINGLE-001). The analyzer MUST report one diagnostic per parameter, located on its identifier.

Why: A descriptive parameter name lets a reader understand a transformation or a predicate without tracing the parameter's type and the collection it comes from.

Example:

```csharp
using System;

class C
{
    void M()
    {
        Func<int, int> f = {|RH4124:x|} => x;
        Func<int, int, int> g = ({|RH4124:a|}, {|RH4124:B|}) => a + B;
        Action<int> h = delegate (int {|RH4124:v|}) { };
        Func<int, int, int> i = (_, _) => 0;
        Func<int, int> j = value => value;
    }
}
```

### RH4124-002 — Parameters of other members are not checked

The analyzer MUST NOT report a parameter of a method, constructor, or other member, nor a parameter of a local function.

Why: Those parameters have rules of their own (RH4122 and RH4123), so each kind can be configured separately.

Example:

```csharp
class C
{
    void M(int a)
    {
        int Local(int b) => b;
    }
}
```

is not reported.
