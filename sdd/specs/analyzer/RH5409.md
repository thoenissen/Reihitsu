# Analyzer — RH5409 Final enum members must not have trailing commas

| | |
|---|---|
| ID prefix | RH5409 |
| Status | Active |
| Category | Layout |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH5409FinalEnumMemberMustNotHaveTrailingCommaAnalyzer`, `RH5409FinalEnumMemberMustNotHaveTrailingCommaCodeFixProvider` |
| Uses | SHARED-TRAIL-001, SHARED-TRAIL-002, SHARED-TRAIL-003 |

RH5409 reports a comma after the last member of an enum declaration, and offers a code fix that removes it as SHARED-TRAIL-003 specifies.

## Non-goals

- Trailing commas in array initializers — RH5410; in collection initializers — RH5411.
- The line breaks between enum members.

## Requirements

### RH5409-001 — A comma after the last enum member is reported

The analyzer MUST report the comma after the last member of an enum declaration as SHARED-TRAIL-001 and SHARED-TRAIL-002 specify, whether or not the members have values or attributes and whether the enum is written on one line or on several.

Why: The last member ends the list of values; a comma behind it suggests a further value that does not exist.

Example:

```csharp
using System;

enum E
{
    A = 1,
    [Obsolete]
    B = 2{|RH5409:,|}
}

enum F { A{|RH5409:,|} }
```
