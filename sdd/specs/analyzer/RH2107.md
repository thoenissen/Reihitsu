# Analyzer — RH2107 Nested enums should not be used

| | |
|---|---|
| ID prefix | RH2107 |
| Status | Active |
| Category | Design |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH2107NestedEnumsShouldNotBeUsedAnalyzer` |
| Uses | SHARED-NESTED-001, SHARED-NESTED-002 |

RH2107 reports an enum declared inside another type.

## Non-goals

- Nested classes, structs, interfaces, records, and delegates — RH2101, RH2104, RH2105, RH2106, and RH2108.

## Requirements

### RH2107-001 — A nested enum is reported

The analyzer MUST report an enum declaration that is nested as SHARED-NESTED-001 defines it, located as SHARED-NESTED-002 specifies.

Why: An enum inside another type is less discoverable and couples every user of its values to the containing type. A top-level enum is easier to share.

Example:

```csharp
class Outer
{
    enum {|RH2107:Mode|}
    {
        On,
        Off,
    }
}

struct S
{
    enum {|RH2107:Kind|}
    {
        A,
    }
}
```
