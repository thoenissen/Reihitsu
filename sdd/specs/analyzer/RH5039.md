# Analyzer — RH5039 Comments must not be placed inside a statement header

| | |
|---|---|
| ID prefix | RH5039 |
| Status | Active |
| Category | Layout |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH5039CommentsMustNotBePlacedInsideStatementHeaderAnalyzer` |
| Uses | SHARED-COMMENT-001, SHARED-COMMENT-002, SHARED-COMMENT-003, SHARED-COMMENT-004, SHARED-COMMENT-005, SHARED-COMMENT-006, SHARED-COMMENT-008, SHARED-COMMENT-009, SHARED-COMMENT-010 |

RH5039 reports a comment placed inside the header of an `if`, `while`, `for`, `foreach`, `using`, `lock`, or `fixed` statement, from its keyword to the closing parenthesis.

## Non-goals

- A comment between the header and the body — RH5036.

## Requirements

### RH5039-001 — A comment inside a statement header is reported

The analyzer MUST report every ordinary comment (SHARED-COMMENT-001, SHARED-COMMENT-002) inside a statement header, as SHARED-COMMENT-010 defines it, as SHARED-COMMENT-003, SHARED-COMMENT-004, SHARED-COMMENT-005, SHARED-COMMENT-006, SHARED-COMMENT-008, and SHARED-COMMENT-009 specify for a region. A comment inside the parentheses of a `switch` statement, a `catch` clause, or the `while` of a `do` statement MUST NOT be reported.

Why: A comment inside a header leaves it unclear which part of the condition or the declaration it describes, and it splits the header across lines. A comment above the statement describes the statement as a whole.

Example:

```csharp
using System.Collections.Generic;
using System.Threading.Tasks;

class C
{
    async Task M(bool a, IAsyncEnumerable<int> values)
    {
        if {|RH5039:/* condition */|} (a)
        {
        }

        for (
            {|RH5039:// start|}
            var index = 0; index < 1; index++)
        {
        }

        await {|RH5039:/* each */|} foreach (var value in values)
        {
        }

        // condition
        while (a)
            // body
            break;
    }
}
```

```csharp
using System;

class C
{
    void M(bool a)
    {
        switch (/* value */ a)
        {
            default:
                break;
        }

        try
        {
        }
        catch (/* any */ Exception)
        {
        }

        do
        {
        }
        while (/* again */ a);
    }
}
```

is not reported.
