# Analyzer — RH2104 Nested structs should not be used

| | |
|---|---|
| ID prefix | RH2104 |
| Status | Active |
| Category | Design |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH2104NestedStructsShouldNotBeUsedAnalyzer` |
| Uses | SHARED-NESTED-001, SHARED-NESTED-002 |

RH2104 reports a struct declared inside another type.

## Non-goals

- Nested record structs, which are reported by RH2106, and nested classes, interfaces, enums, and delegates — RH2101, RH2105, RH2107, and RH2108.

## Requirements

### RH2104-001 — A nested struct is reported

The analyzer MUST report a struct declaration that is nested as SHARED-NESTED-001 defines it, located as SHARED-NESTED-002 specifies. A record struct MUST NOT be reported.

Why: A struct inside another type is harder to discover and to reuse, and it hides a declaration inside a type that is about something else.

Example:

```csharp
class Outer
{
    struct {|RH2104:Entry|}
    {
    }

    record struct Point(int X);
}

interface I
{
    struct {|RH2104:Value|}
    {
    }
}
```
