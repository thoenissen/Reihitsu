# Analyzer — RH8110 Generic type parameter documentation must declare parameter name

| | |
|---|---|
| ID prefix | RH8110 |
| Status | Active |
| Category | Documentation |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH8110GenericTypeParameterDocumentationMustDeclareParameterNameAnalyzer` |
| Uses | SHARED-DOC-008, SHARED-DOC-016 |

RH8110 reports a `<typeparam>` element that does not name its type parameter.

## Non-goals

- Whether the name matches a type parameter — RH8109; whether the description has text — RH8111.
- `<param>` elements — RH8103.

## Requirements

### RH8110-001 — A `<typeparam>` element without a name is reported

The analyzer MUST report each `<typeparam>` element that SHARED-DOC-016 requires to name a type parameter, in the documentation comment of a class, struct, interface, record, record struct, delegate, or method declaration, whether or not the declaration is generic. A method that explicitly implements an interface member MUST be checked as well, and the declaration's accessibility does not matter. Nothing is reported when SHARED-DOC-008 applies.

This requirement covers what SHARED-DOC-016 covers. The documentation comments of other declarations, such as constructors, properties, and enums, are not covered.

Why: A `<typeparam>` element without a name describes no type parameter: the tooltip of every type parameter stays empty, and the reader has to guess which one the text means.

Example:

```csharp
/// <summary>
/// Container
/// </summary>
/// {|RH8110:<typeparam>Element</typeparam>|}
public class C<T>
{
    /// <summary>
    /// Runs
    /// </summary>
    /// {|RH8110:<typeparam/>|}
    public void Run()
    {
    }
}

/// <summary>
/// Handler
/// </summary>
/// {|RH8110:<typeparam name="">Argument</typeparam>|}
public delegate void Handler<T>(T value);
```

### RH8110-002 — The diagnostic is on the element

The analyzer MUST report one diagnostic per reported `<typeparam>` element, located on the whole element: the empty element, or everything from the start tag through the end tag.

Why: The element is what needs the `name` attribute, and each element is corrected on its own.

Example: see RH8110-001.
