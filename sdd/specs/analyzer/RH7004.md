# Analyzer — RH7004 Using declarations should not be used

| | |
|---|---|
| ID prefix | RH7004 |
| Status | Active |
| Category | Organization |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH7004UsingDeclarationsShouldNotBeUsedAnalyzer`, `RH7004UsingDeclarationsShouldNotBeUsedCodeFixProvider` |
| Uses | — |

RH7004 reports a `using` local declaration, and offers a code fix that turns it into a `using` statement whose block holds the statements that followed the declaration.

## Non-goals

- `using` statements, `using` directives, and `using static` directives — they are not using declarations.
- How small the block of the `using` statement should be. The fix moves every following statement of the block into it; narrowing the block is the author's decision.

## Requirements

### RH7004-001 — A using declaration is reported

The analyzer MUST report every local declaration that starts with the `using` keyword, with or without `await`, whether it declares its variables with `var` or with an explicit type, wherever the declaration stands — in a method, accessor, lambda, or local function body, in a nested block, or as a top-level statement.

Why: A using declaration disposes its resource at the end of the enclosing scope, which the reader has to find by looking for the closing brace. A `using` statement makes the statements that run while the resource is alive visible as one block.

Example:

```csharp
using System;
using System.IO;
using System.Threading.Tasks;

class C
{
    async Task M(IAsyncDisposable resource)
    {
        {|RH7004:using|} var stream = new MemoryStream();
        {|RH7004:using|} MemoryStream first = new MemoryStream(), second = new MemoryStream();
        await {|RH7004:using|} var handle = resource;

        Action action = () =>
        {
            {|RH7004:using|} var inner = new MemoryStream();
        };
    }
}
```

### RH7004-002 — A using statement is not reported

The analyzer MUST NOT report a `using` statement, with or without `await`.

Why: A `using` statement already states the lifetime of its resource as a block.

Example:

```csharp
using System.IO;

class C
{
    void M()
    {
        using (var stream = new MemoryStream())
        {
            stream.Flush();
        }
    }
}
```

is not reported.

### RH7004-003 — The diagnostic is on the `using` keyword

The analyzer MUST report one diagnostic per using declaration, located on its `using` keyword; for an `await using` declaration the diagnostic does not include `await`.

Why: The `using` keyword is what turns the local declaration into a using declaration, and one diagnostic per declaration keeps Fix All one action per declaration.

Example: see RH7004-001.

### RH7004-004 — The fix wraps the following statements into a using statement

The code fix MUST replace the using declaration with a `using` statement that declares the same variables with the same type and initializers, keeps `await` when the declaration had it, and whose block holds every statement that followed the declaration in the same block, in their order. When no statement follows the declaration, the block is empty.

Why: The resource of a using declaration lives until the end of its block, so a `using` statement over exactly the following statements disposes it at the same point and keeps every variable those statements use in scope.

Example:

```csharp
using System.IO;

class C
{
    void M()
    {
        {|RH7004:using|} var stream = new MemoryStream();
        stream.Flush();
    }
}
```

```csharp
using System.IO;

class C
{
    void M()
    {
        using (var stream = new MemoryStream())
        {
            stream.Flush();
        }
    }
}
```

With `await`, several declarators, and no following statement:

```csharp
using System;
using System.IO;

class C
{
    async System.Threading.Tasks.Task M(IAsyncDisposable resource)
    {
        await {|RH7004:using|} var handle = resource;
    }

    void N()
    {
        {|RH7004:using|} MemoryStream first = new MemoryStream(), second = new MemoryStream();
    }
}
```

```csharp
using System;
using System.IO;

class C
{
    async System.Threading.Tasks.Task M(IAsyncDisposable resource)
    {
        await using (var handle = resource)
        {
        }
    }

    void N()
    {
        using (MemoryStream first = new MemoryStream(), second = new MemoryStream())
        {
        }
    }
}
```

### RH7004-005 — The fix is withheld outside a block

The code fix MUST NOT be offered for a using declaration that is not a statement of a block, such as a top-level statement. The diagnostic is still reported.

Why: The fix closes the new `using` statement where the enclosing block ends. Top-level statements have no enclosing block whose end the fix could use, and a file with top-level statements may also declare types after them, which a block cannot hold.

Example:

```csharp
using System.IO;

{|RH7004:using|} var stream = new MemoryStream();
stream.Flush();
```

is reported, and no code fix is offered.

### RH7004-006 — The fix is withheld when a local function or label follows directly

The code fix MUST NOT be offered when a statement that follows the using declaration directly in the same block is a local function declaration or a labeled statement. The diagnostic is still reported. A local function or label nested deeper, inside a following statement, does not withhold the fix.

Why: The fix moves the following statements into the new block, where the statements before the declaration can no longer see them: a call to the local function no longer compiles (CS0103), and neither does a `goto` to the label (CS0159). A local function or label nested inside a following statement was never visible to those statements, so moving it changes nothing.

Example:

```csharp
using System.IO;

class C
{
    void M()
    {
        Helper();
        {|RH7004:using|} var stream = new MemoryStream();

        void Helper()
        {
        }
    }
}
```

is reported, and no code fix is offered. A local function nested in a following statement moves with it:

```csharp
using System.IO;

class C
{
    void M()
    {
        {|RH7004:using|} var stream = new MemoryStream();
        if (stream.CanRead)
        {
            void Helper()
            {
            }
        }
    }
}
```

```csharp
using System.IO;

class C
{
    void M()
    {
        using (var stream = new MemoryStream())
        {
            if (stream.CanRead)
            {
                void Helper()
                {
                }
            }
        }
    }
}
```
