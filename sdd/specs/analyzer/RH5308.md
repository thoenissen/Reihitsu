# Analyzer — RH5308 Conditional expressions should be formatted correctly

| | |
|---|---|
| ID prefix | RH5308 |
| Status | Active |
| Category | Layout |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH5308ConditionalExpressionsShouldBeFormattedCorrectlyAnalyzer`, `RH5308ConditionalExpressionsShouldBeFormattedCorrectlyCodeFixProvider` |
| Uses | FMT-BREAK-018, FMT-INDENT-020 |

RH5308 reports a conditional expression that spans several lines when its `?` or `:` does not start its own line, or starts it outside its column, and offers a code fix that lays out the conditional the way the formatter does.

## Non-goals

- The layout of a branch after its first token.
- The null-conditional operators `?.` and `?[]`, and the null-coalescing operator `??`.

## Requirements

### RH5308-001 — An operator that does not start its line is reported

The analyzer MUST report a conditional expression that spans several lines when its `?` is on the line its condition ends on, or its `:` is on the line its `true` branch ends on. A conditional expression nested in the `true` or the `false` branch of such a conditional MUST be checked in the same way. A conditional expression on one line that contains no nested conditional expression MUST NOT be reported.

Why: A partly wrapped conditional mixes two shapes and hides a branch at the end of a line; once wrapped, each branch starts its own line behind its operator (FMT-BREAK-018).

Example:

```csharp
class C
{
    int M(bool a)
    {
        var x = a {|RH5308:?|}
                1 :
                2;
        var y = a
                    ? 1 {|RH5308::|} 2;
        var z = a ? 1 : 2;

        return x;
    }
}
```

### RH5308-002 — An operator that starts its line outside its column is reported

The analyzer MUST report a conditional expression that spans several lines when a `?` or `:` that starts a line does not start four columns to the right of the first token of the outermost condition. The `?` and `:` of a conditional nested in the `true` or the `false` branch MUST start one further level (four columns) to the right for each level of nesting. A wrapped conditional whose operators all start their own lines in these columns, each followed by its branch on that line, MUST NOT be reported.

Why: The operators one level deeper than the condition, and one level further for each nested conditional, make the nesting visible as a stair (FMT-INDENT-020).

Example:

```csharp
class C
{
    int M(bool a, bool b)
    {
        var x = a
                {|RH5308:?|} 1
                : 2;
        var y = a
                    ? 1
                    : b
                    {|RH5308:?|} 2
                    : 3;
        var z = a
                    ? 1
                    : b
                        ? 2
                        : 3;

        return x;
    }
}
```

### RH5308-003 — The diagnostic is on the first misplaced operator

The analyzer MUST report one diagnostic per outermost conditional expression — one that is not itself a branch of a conditional expression — located on its first misplaced operator: the `?`, then the `:`, then the operators of a conditional nested in the `true` branch, then those of a conditional nested in the `false` branch.

Why: The fix lays out the whole conditional at once, so one diagnostic per conditional is enough, and two diagnostics for one conditional would offer fixes that overlap.

Example:

```csharp
class C
{
    int M(bool a)
    {
        var x = a {|RH5308:?|}
                1 :
                2;

        return x;
    }
}
```

The `?` and the `:` are both misplaced, and only the `?` is reported.

### RH5308-004 — The fix lays out the conditional expression

The code fix MUST lay out the reported conditional expression as the formatter lays it out: every `?` and `:` starts its own line, followed by its branch, one level deeper than the condition, and one further level for each nested conditional (FMT-BREAK-018, FMT-INDENT-020).

Why: The formatter owns the layout of conditional expressions; delegating to it applies that layout instead of a second one.

Example:

```csharp
class C
{
    int M(bool a, bool b)
    {
        var x = a {|RH5308:?|}
                1 :
                b ? 2 : 3;

        return x;
    }
}
```

```csharp
class C
{
    int M(bool a, bool b)
    {
        var x = a
                    ? 1
                    : b
                        ? 2
                        : 3;

        return x;
    }
}
```
