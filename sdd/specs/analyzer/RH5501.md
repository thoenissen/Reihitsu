# Analyzer — RH5501 Assembly attributes must be on their own line

| | |
|---|---|
| ID prefix | RH5501 |
| Status | Active |
| Category | Layout |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH5501AssemblyAttributesMustFollowPlacementRulesAnalyzer`, `RH5501AssemblyAttributesMustFollowPlacementRulesCodeFixProvider` |
| Uses | SHARED-ATTR-002, SHARED-ATTR-004, SHARED-ATTR-005, SHARED-ATTR-006, SHARED-ATTR-007, SHARED-ATTR-008, SHARED-ATTR-009, SHARED-ATTR-011, SHARED-ATTR-012 |

RH5501 reports an assembly attribute list that shares its line with the token after it, and offers a code fix that moves that token onto the next line. The rule uses `shared/attribute-targets.md`.

## Non-goals

- Module attributes — RH5503.

## Requirements

### RH5501-001 — Assembly attribute lists are on their own line

The analyzer MUST check every attribute list with the `assembly:` specifier (SHARED-ATTR-002), and MUST report such a list whose closing bracket shares its line with the first token after it, as SHARED-ATTR-004, SHARED-ATTR-005, and SHARED-ATTR-006 specify for a list that must be on its own line.

Why: An assembly attribute applies to the whole assembly, not to the declaration written after it; on the same line it reads like a decoration of that declaration.

Example:

```csharp
[assembly: A]
{|RH5501:[assembly: B]|} {|RH5501:[assembly: C]|} class D
{
}
```

### RH5501-002 — The diagnostic is on the attribute list

The analyzer MUST report the diagnostic on the attribute list, as SHARED-ATTR-007 specifies.

Why: The list is what is misplaced; each list of a declaration is reported and fixed on its own.

Example: see RH5501-001.

### RH5501-003 — The fix moves what follows onto the next line

The code fix MUST put the first token after the list on a new line, as SHARED-ATTR-008 and SHARED-ATTR-009 specify.

Why: The fix makes only the change the diagnostic asks for: the declaration starts on its own line, and the list stays where it is.

Example:

```csharp
{|RH5501:[assembly: A]|} class C
{
}
```

```csharp
[assembly: A]
class C
{
}
```

### RH5501-004 — The fix is withheld for comments, directives, and missing braces

The code fix MUST NOT be offered when SHARED-ATTR-011 or SHARED-ATTR-012 withholds it. The diagnostic is still reported.

Why: A comment inside the list belongs to the attribute next to it, and an unclosed scope leaves no indentation to compute; both are left to the author.

Example:

```csharp
{|RH5501:[assembly: A /* c */]|} class C
{
}
```

is reported, and no code fix is offered.
