# Analyzer — RH5036 Comments must not be placed between a statement header and its body

| | |
|---|---|
| ID prefix | RH5036 |
| Status | Active |
| Category | Layout |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH5036CommentsMustNotBePlacedBetweenStatementHeaderAndBodyAnalyzer` |
| Uses | SHARED-COMMENT-001, SHARED-COMMENT-002, SHARED-COMMENT-003 |

RH5036 reports a comment placed between the header of an `if`, `while`, `for`, `foreach`, `using`, `lock`, or `fixed` statement and its body.

## Non-goals

- A comment inside the header itself — RH5039.
- A comment before `else`, `catch`, `finally`, or the `while` of a `do` loop — RH5037.

## Requirements

### RH5036-001 — A comment between a statement header and its body is reported

The analyzer MUST report every ordinary comment (SHARED-COMMENT-001, SHARED-COMMENT-002) directly after the closing parenthesis of the header of an `if`, `while`, `for`, `foreach`, `await foreach`, `using`, `await using`, `lock`, or `fixed` statement and directly before the first token of its embedded statement, whether that statement is a block or a single statement, as SHARED-COMMENT-003 specifies. A comment before the statement or inside its body MUST NOT be reported.

Why: The header and the body form one statement. A comment between them separates the two and leaves it unclear whether it describes the condition or the body.

Example:

```csharp
class C
{
    int Run(params object[] values) => 0;

    void M(bool a, int[] items)
    {
        if (a) {|RH5036:// explanation|}
        {
        }

        foreach (var item in items)
            {|RH5036:// explanation|}
            Run(item);

        // explanation
        while (a)
        {
            // explanation
            break;
        }
    }
}
```

### RH5036-002 — Other statements with a body are not checked

The analyzer MUST NOT report a comment between `else` or `do` and its body, nor one between the header of a `switch` statement and its opening brace.

Why: `else` and `do` have no header whose condition the comment could be confused with, and a `switch` body is a list of sections, not a statement.

Example:

```csharp
class C
{
    void M(bool a, int x)
    {
        if (a)
        {
        }
        else
            // explanation
        {
        }

        do
            // explanation
        {
        }
        while (a);

        switch (x) // explanation
        {
            default:
                break;
        }
    }
}
```

is not reported.
