# Analyzer — RH4011 Record struct name casing

| | |
|---|---|
| ID prefix | RH4011 |
| Status | Active |
| Category | Naming |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH4011RecordStructNameCasingAnalyzer`, `RH4011RecordStructNameCasingCodeFixProvider` |
| Uses | SHARED-CASING-001, SHARED-CASING-006, SHARED-CASING-007, SHARED-CASING-008, SHARED-CASING-009, SHARED-CASING-010 |

RH4011 reports a record struct whose name is not in PascalCase and offers a code fix that renames the record struct and every reference to it.

## Non-goals

- Records declared as `record` or `record class` — RH4010.
- Structs declared with `struct` — RH4003.
- The names of the record struct's primary constructor parameters — RH4120.

## Requirements

### RH4011-001 — Record struct names are in PascalCase

The analyzer MUST report every `record struct` whose name is not in PascalCase as SHARED-CASING-001 defines it. A record declared as `record` or `record class` MUST NOT be reported. The diagnostic MUST be located on the record struct's identifier.

Why: A record struct is a type; PascalCase is how .NET spells type names. Record classes have their own rule, so each record is checked by exactly one rule.

Example:

```csharp
public record struct CurrencyValue(decimal Amount);

public record struct {|RH4011:currencyvalue|}(decimal Amount);

public record orderLine(int Value);

public record class customerAggregate(int Value);
```

### RH4011-002 — The fix renames the record struct to PascalCase

The code fix MUST rename the record struct and every reference to it (SHARED-CASING-007) to the PascalCase name that SHARED-CASING-006 derives from its old name. It is withheld as SHARED-CASING-008 and SHARED-CASING-009 specify, and its Fix All skips colliding names as SHARED-CASING-010 specifies. This requirement covers the renames that SHARED-CASING-007 covers.

Why: The fix makes exactly the change the diagnostic asks for, and a record struct is referenced wherever its type is used.

Example:

```csharp
public record struct {|RH4011:pointRecord|}(int X, int Y);

public record struct {|RH4011:sizeRecord|}(int Width, int Height);

public class C
{
    public pointRecord Location { get; set; }

    public sizeRecord Size { get; set; }
}
```

```csharp
public record struct PointRecord(int X, int Y);

public record struct SizeRecord(int Width, int Height);

public class C
{
    public PointRecord Location { get; set; }

    public SizeRecord Size { get; set; }
}
```
