# Analyzer — RH3204 Interpolated strings without interpolation should not use the dollar marker

| | |
|---|---|
| ID prefix | RH3204 |
| Status | Active |
| Category | Clarity |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH3204InterpolatedStringsWithoutInterpolationShouldNotUseDollarAnalyzer`, `RH3204InterpolatedStringsWithoutInterpolationShouldNotUseDollarCodeFixProvider` |
| Uses | — |

RH3204 reports an interpolated string that has no interpolation and is used as a `string`, and offers a code fix that turns it into the string literal with the same value.

## Non-goals

- An empty string literal that the fix leaves behind — RH3003 reports `""`.
- Interpolated strings with at least one interpolation, whose `$` is needed.

## Requirements

### RH3204-001 — An interpolated string without interpolation used as a `string` is reported

The analyzer MUST report an interpolated string — regular, verbatim, or raw, with any number of `$` — that contains no interpolation and whose converted type is `string`. An interpolated string converted to any other type, such as `FormattableString`, `IFormattable`, or `object`, MUST NOT be reported.

Why: The `$` promises interpolation the string does not have and adds noise. Converted to `FormattableString` or `IFormattable`, though, the string only compiles, or only selects the same overload, because it is interpolated, so there the `$` is not redundant.

Example:

```csharp
using System;

class C
{
    void M(int x)
    {
        var a = {|RH3204:$"text"|};
        var b = {|RH3204:$@"C:\a"|};
        var c = {|RH3204:$$"""a {b}"""|};
        Console.WriteLine({|RH3204:$"x"|});
        var d = $"{x}";
        FormattableString e = $"text";
        IFormattable f = $"text";
        object g = $"text";
    }
}
```

### RH3204-002 — The diagnostic covers the interpolated string

The analyzer MUST report one diagnostic per interpolated string, from its first `$` or `@` to its closing quotes.

Why: The fix rewrites the whole literal: its start and, for a regular or verbatim string, the braces inside it.

Example: see RH3204-001.

### RH3204-003 — The fix writes the literal with the same value

The code fix MUST remove every `$` from the start of the string and keep `@` and the quotes. In a regular or verbatim interpolated string, it MUST also replace each `{{` with `{` and each `}}` with `}`; in a raw interpolated string, it MUST keep the braces as they are. It MUST keep the trivia in front of and after the string.

Why: The value of the string must not change. A regular or verbatim interpolated string writes a brace as `{{`, a string literal as `{`; a raw string writes a brace the same way with and without `$`.

Example:

```csharp
class C
{
    void M()
    {
        var a = {|RH3204:$"text"|};
        var b = {|RH3204:$@"C:\a"|};
        var c = {|RH3204:@$"C:\a"|};
        var d = {|RH3204:$"a {{b}}"|};
        var e = {|RH3204:$"""text"""|};
        var f = {|RH3204:$$"""a {b}"""|};
        var g = /* x */ {|RH3204:$"text"|} /* y */;
    }
}
```

```csharp
class C
{
    void M()
    {
        var a = "text";
        var b = @"C:\a";
        var c = @"C:\a";
        var d = "a {b}";
        var e = """text""";
        var f = """a {b}""";
        var g = /* x */ "text" /* y */;
    }
}
```
