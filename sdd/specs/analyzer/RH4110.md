# Analyzer — RH4110 Const field casing

| | |
|---|---|
| ID prefix | RH4110 |
| Status | Active |
| Category | Naming |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH4110ConstFieldCasingAnalyzer`, `RH4110ConstFieldCasingCodeFixProvider` |
| Uses | SHARED-CASING-001, SHARED-CASING-006, SHARED-CASING-007, SHARED-CASING-008, SHARED-CASING-009, SHARED-CASING-010 |

RH4110 reports a `const` field whose name is not in PascalCase and offers a code fix that renames the constant and every reference to it.

## Non-goals

- Fields that are not `const` — RH4106 to RH4109.
- Local constants — RH4115.

## Requirements

### RH4110-001 — Constant names are in PascalCase

The analyzer MUST report every variable declarator of a `const` field declaration whose name is not in PascalCase as SHARED-CASING-001 defines it, whatever the field's accessibility. The analyzer MUST report one diagnostic per declarator, located on its identifier.

Why: .NET names constants in PascalCase, whoever can see them; a constant is a fixed value, not state, so the underscore prefix of private state does not apply.

Example:

```csharp
public class C
{
    public const int MaxRetries = 3;
    public const int {|RH4110:maxItems|} = 10;
    private const int {|RH4110:retryDelay|} = 5, {|RH4110:timeout_ms|} = 100;
    internal const int {|RH4110:MAX_PAGES|} = 4;
    private int count;

    public void M()
    {
        const int localLimit = 1;
    }
}
```

### RH4110-002 — The fix renames the constant to PascalCase

The code fix MUST rename the constant and every reference to it (SHARED-CASING-007) to the PascalCase name that SHARED-CASING-006 derives from its old name. It is withheld as SHARED-CASING-008 and SHARED-CASING-009 specify, and its Fix All skips colliding names as SHARED-CASING-010 specifies. This requirement covers the renames that SHARED-CASING-007 covers.

Why: The fix makes exactly the change the diagnostic asks for, and a constant is referenced wherever its value is used, including other constants' initializers.

Example:

```csharp
public class Limits
{
    private const int {|RH4110:maxItems|} = 10;
    private const int {|RH4110:maxPages|} = maxItems / 2;
}
```

```csharp
public class Limits
{
    private const int MaxItems = 10;
    private const int MaxPages = MaxItems / 2;
}
```
