# Analyzer — RH7412 Interface implementation indexers should be grouped by interface regions

| | |
|---|---|
| ID prefix | RH7412 |
| Status | Active |
| Category | Organization |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH7412InterfaceIndexersShouldBeGroupedByInterfaceRegionsAnalyzer` |
| Uses | SHARED-DIAG-004, SHARED-DIAG-012, SHARED-REGGROUP-001, SHARED-REGGROUP-002, SHARED-REGGROUP-004, SHARED-REGGROUP-005, SHARED-TYPEREGION-006 |

RH7412 reports an indexer that implements an interface indexer, explicitly or implicitly, when it does not lie in a region named after an interface that declares the member, judged by the innermost region that encloses it. It has no code fix.

## Non-goals

- Interface implementations that are methods, properties, or events — RH7409, RH7410, RH7411.
- An override that implements an interface indexer — RH7404.

## Requirements

### RH7412-001 — An interface implementation indexer outside its interface's region is reported

In every type declaration it checks (SHARED-REGGROUP-001), the analyzer MUST report each indexer declaration that comes from an interface (SHARED-REGGROUP-004) — an explicit and an implicit implementation alike — when the innermost region that encloses it (SHARED-REGGROUP-001, SHARED-TYPEREGION-006) does not have a name that matches (SHARED-REGGROUP-002) that interface, or one of those interfaces when it implements members of several (SHARED-REGGROUP-004) — whether it lies in a region of another name, in a region of another name nested in a region that matches, or in no region. The diagnostic MUST be placed as SHARED-REGGROUP-005 specifies.

A `partial` indexer is one indexer (SHARED-DIAG-004): it is reported at most once, on the part SHARED-DIAG-012 selects. It is reported when any of its parts, judged on its own by the region it lies in, would be reported: every part has to lie in a matching region.

Why: Members that implement an interface are easier to scan when they are grouped by the interface they belong to; a generic region name such as `Indexers` hides that relationship in a type that implements several interfaces.

Example:

```csharp
interface IIndexed
{
    int this[int index] { get; }
}

interface IKeyed
{
    int this[string key] { get; }
}

interface ILongIndexed
{
    int this[long index] { get; }
}

class C : IIndexed, IKeyed, ILongIndexed
{
    #region Indexers

    public int {|RH7412:this|}[int index] => index;

    int IKeyed.{|RH7412:this|}[string key] => 0;

    #endregion

    public int {|RH7412:this|}[long index] => 0;
}
```

while implementations in the regions named after their interfaces:

```csharp
interface IIndexed
{
    int this[int index] { get; }
}

interface IKeyed
{
    int this[string key] { get; }
}

class C : IIndexed, IKeyed
{
    #region IIndexed

    public int this[int index] => index;

    #endregion

    #region IKeyed

    int IKeyed.this[string key] => 0;

    #endregion
}
```

are not reported.

Example — a `partial` indexer whose parts both lie outside a matching region is reported once, on its defining part:

```csharp
interface I
{
    int this[int index] { get; }
}

partial class C : I
{
    #region Indexers

    public partial int {|RH7412:this|}[int index] { get; }

    public partial int this[int index] => index;

    #endregion
}
```

### RH7412-002 — Other members are not reported

The analyzer MUST NOT report an indexer that implements no interface member, an override indexer, or an interface implementation that is not an indexer declaration, such as a property.

Why: An indexer that implements nothing has no interface to be grouped by, an override is grouped by its base type (SHARED-REGGROUP-004), and the other member kinds have rules of their own.

Example:

```csharp
interface INamed
{
    string Name { get; }
}

class C : INamed
{
    #region Properties

    public string Name => "";

    #endregion

    #region Indexers

    public int this[int index] => index;

    #endregion
}
```

is not reported.
