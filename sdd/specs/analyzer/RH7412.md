# Analyzer — RH7412 Interface implementation indexers should be grouped by interface regions

| | |
|---|---|
| ID prefix | RH7412 |
| Status | Active |
| Category | Organization |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH7412InterfaceIndexersShouldBeGroupedByInterfaceRegionsAnalyzer` |
| Uses | SHARED-REGGROUP-001, SHARED-REGGROUP-002, SHARED-REGGROUP-003, SHARED-REGGROUP-005, SHARED-REGGROUP-006 |

RH7412 reports an indexer that implements an interface indexer, explicitly or implicitly, when it does not lie in a top-level region named after the interface that declares the member. It has no code fix.

## Non-goals

- Interface implementations that are methods, properties, or events — RH7409, RH7410, RH7411.
- An override that implements an interface indexer — RH7404.

## Requirements

### RH7412-001 — An interface implementation indexer outside its interface's region is reported

In every type declaration it checks (SHARED-REGGROUP-001), the analyzer MUST report each indexer declaration that comes from an interface (SHARED-REGGROUP-005) — an explicit and an implicit implementation alike — when the indexer does not lie (SHARED-REGGROUP-002) in a top-level region whose name matches (SHARED-REGGROUP-003) that interface, whether it lies in a region of another name or in no region. The diagnostic MUST be placed as SHARED-REGGROUP-006 specifies.

Why: Members that implement an interface are easier to scan when they are grouped by the interface they belong to; a generic region name such as `Indexers` hides that relationship in a type that implements several interfaces.

Example:

```csharp
interface IIndexed
{
    int this[int index] { get; }
}

interface IKeyed
{
    int this[string key] { get; }
}

interface ILongIndexed
{
    int this[long index] { get; }
}

class C : IIndexed, IKeyed, ILongIndexed
{
    #region Indexers

    public int {|RH7412:this|}[int index] => index;

    int IKeyed.{|RH7412:this|}[string key] => 0;

    #endregion

    public int {|RH7412:this|}[long index] => 0;
}
```

while implementations in the regions named after their interfaces:

```csharp
interface IIndexed
{
    int this[int index] { get; }
}

interface IKeyed
{
    int this[string key] { get; }
}

class C : IIndexed, IKeyed
{
    #region IIndexed

    public int this[int index] => index;

    #endregion

    #region IKeyed

    int IKeyed.this[string key] => 0;

    #endregion
}
```

are not reported.

### RH7412-002 — Other members are not reported

The analyzer MUST NOT report an indexer that implements no interface member, an override indexer, or an interface implementation that is not an indexer declaration, such as a property.

Why: An indexer that implements nothing has no interface to be grouped by, an override is grouped by its base type (SHARED-REGGROUP-005), and the other member kinds have rules of their own.

Example:

```csharp
interface INamed
{
    string Name { get; }
}

class C : INamed
{
    #region Properties

    public string Name => "";

    #endregion

    #region Indexers

    public int this[int index] => index;

    #endregion
}
```

is not reported.
