# Analyzer — RH7404 Override indexers should be grouped by base type regions

| | |
|---|---|
| ID prefix | RH7404 |
| Status | Active |
| Category | Organization |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH7404OverrideIndexersShouldBeGroupedByBaseTypeRegionsAnalyzer` |
| Uses | SHARED-REGGROUP-001, SHARED-REGGROUP-002, SHARED-REGGROUP-003, SHARED-REGGROUP-004, SHARED-REGGROUP-006 |

RH7404 reports an override indexer that does not lie in a top-level region named after the type that introduced the indexer. It has no code fix.

## Non-goals

- Override methods, properties, and events — RH7401, RH7402, RH7403.
- An indexer that overrides nothing but lies in a region named after a base type — RH7408.
- An interface implementation that is not an override — RH7412.

## Requirements

### RH7404-001 — An override indexer outside its base type's region is reported

In every type declaration it checks (SHARED-REGGROUP-001), the analyzer MUST report each indexer declaration that overrides an indexer when the indexer does not lie (SHARED-REGGROUP-002) in a top-level region whose name matches (SHARED-REGGROUP-003) the type it comes from (SHARED-REGGROUP-004) — whether it lies in a region of another name or in no region. This holds also for an override that implements an interface indexer. The diagnostic MUST be placed as SHARED-REGGROUP-006 specifies.

Why: Overrides are easier to scan when they are grouped by the type that introduced them; a generic region name such as `Indexers` hides that relationship. An override that also implements an interface indexer is still an override of its base type, so it is grouped there.

Example:

```csharp
interface IIndexed
{
    int this[int index] { get; }
}

abstract class B
{
    public abstract int this[int index] { get; }

    public virtual int this[string key] => 0;

    public virtual int this[long index] => 0;
}

class C : B, IIndexed
{
    #region IIndexed

    public override int {|RH7404:this|}[int index] => 1;

    #endregion

    #region Indexers

    public override int {|RH7404:this|}[string key] => 1;

    #endregion

    public override int {|RH7404:this|}[long index] => 1;
}
```

while an override in the region named after its base type:

```csharp
class B
{
    public virtual int this[int index] => 0;
}

class C : B
{
    #region B

    public override int this[int index] => 1;

    #endregion
}
```

is not reported.

### RH7404-002 — Other members are not reported

The analyzer MUST NOT report an indexer that overrides nothing, and MUST NOT report an override method, property, or event.

Why: An indexer that overrides nothing has no base type to be grouped by, and the other override kinds have rules of their own.

Example:

```csharp
class B
{
    public virtual int P => 0;
}

class C : B
{
    public override int P => 1;

    public int this[int index] => index;
}
```

is not reported.
