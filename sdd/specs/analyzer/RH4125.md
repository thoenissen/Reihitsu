# Analyzer — RH4125 Single-letter local variable names

| | |
|---|---|
| ID prefix | RH4125 |
| Status | Active |
| Category | Naming |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH4125SingleLetterLocalVariableNamesAnalyzer` |
| Uses | SHARED-SINGLE-001, SHARED-SINGLE-002 |

RH4125 reports a local variable whose name is a single letter, apart from `foreach` iteration variables and `catch` variables.

## Non-goals

- Iteration variables of a `foreach` statement — RH4126; exception variables of a `catch` declaration — RH4127.
- Parameters — RH4122 to RH4124.
- The casing of local variable names — RH4115 and RH4117.

## Requirements

### RH4125-001 — Single-letter local variable names are reported

The analyzer MUST report every local variable with a single-letter name (SHARED-SINGLE-001) that is declared by a variable declarator — of a local declaration statement, including a `const` local and a `using` declaration, of the initializer of a `for` statement, or of a `using` or `fixed` statement — or by a single variable designation, such as an `out` variable, a pattern variable, or a variable of a deconstruction. The analyzer MUST report one diagnostic per variable, located on its identifier.

Why: A local often carries the meaning of an intermediate value; a single-letter name makes calculations and control flow harder to scan and to maintain.

Example:

```csharp
using System;

class C
{
    unsafe void M(object input, int[] values, (int, int) pair)
    {
        int {|RH4125:t|} = 0, total = 1;
        const int {|RH4125:K|} = 2;
        using var {|RH4125:s|} = (IDisposable)null;

        for (int {|RH4125:i|} = 0; i < 1; i++)
        {
        }

        using (var {|RH4125:r|} = (IDisposable)null)
        {
        }

        fixed (int* {|RH4125:p|} = values)
        {
        }

        int.TryParse("1", out var {|RH4125:n|});

        if (input is int {|RH4125:x|})
        {
        }

        var ({|RH4125:a|}, {|RH4125:b|}) = pair;
        (var {|RH4125:c|}, var {|RH4125:d|}) = pair;
    }
}
```

### RH4125-002 — Iteration variables, catch variables, and fields are not checked

The analyzer MUST NOT report an iteration variable of a `foreach` statement (SHARED-SINGLE-002), the exception variable of a `catch` declaration, or a field.

Why: Iteration variables and exception variables have rules of their own (RH4126 and RH4127), so each kind can be configured separately; a field is not a local variable.

Example:

```csharp
using System;
using System.Collections.Generic;

class C
{
    private int f;

    void M(int[] values, List<(int, int)> pairs)
    {
        foreach (var x in values)
        {
        }

        foreach (var (k, v) in pairs)
        {
        }

        try
        {
        }
        catch (Exception e)
        {
        }
    }
}
```

is not reported.
