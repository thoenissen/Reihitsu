# Analyzer — RH8036 Private unions must be documented

| | |
|---|---|
| ID prefix | RH8036 |
| Status | Active |
| Category | Documentation |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH8036PrivateUnionsMustBeDocumentedAnalyzer` |
| Uses | SHARED-DOC-001, SHARED-DOC-002, SHARED-DOC-004, SHARED-DOC-005, SHARED-DOC-006, SHARED-DOC-007, SHARED-DOC-008, SHARED-DOC-019 |

RH8036 reports a union in the private group that has no `<summary>` or `<inheritdoc>` documentation.

## Non-goals

- Unions in the non-private group — RH8035.
- Structs, classes, and records — RH8001 to RH8010.
- Whether the summary has text — RH8030; the documentation of type parameters — RH8108. A union's case types have no names and are not documented with `<param>` — RH8101 does not check a union.

## Requirements

### RH8036-001 — Undocumented private unions are reported

The analyzer MUST report every union declaration, written with the `union` keyword, in the private group of SHARED-DOC-002 that is not documented, checked as SHARED-DOC-001 specifies, including generic unions and unions with a body. Whether it is documented MUST be decided as SHARED-DOC-004, SHARED-DOC-005, SHARED-DOC-006, and SHARED-DOC-007 specify, and nothing is reported when SHARED-DOC-008 applies or for a union that SHARED-DOC-019 leaves unjudged — one whose documentation comment holds a `param` or `paramref` element in any letter case, or whose documentation the compiler cannot expand — which is left to be corrected by hand.

Why: A private union is an implementation detail of its type, but the next maintainer still has to know what it stands for. It has a rule of its own, so a project can require documentation for what other code uses without requiring it here.

Example:

```csharp
/// <summary>
/// Outer
/// </summary>
public class Outer
{
    private union {|RH8036:Hidden|}(int, string);

    /// <remarks>
    /// No summary
    /// </remarks>
    union {|RH8036:Implicit|}<T>(T, string);

    /// <summary>
    /// Documented
    /// </summary>
    private union Documented(int, string);

    private protected union Shared(int, string);

    internal union Visible(int, string);

    private struct Point
    {
    }
}

/// <summary>
/// Holder
/// </summary>
public union Holder(int, string)
{
    private union {|RH8036:Nested|}(int, long);
}
```

`Shared` and `Visible` are in the non-private group, which RH8035 checks; `Point` is a struct, which RH8004 checks.

### RH8036-002 — The diagnostic is on the union name

The analyzer MUST report one diagnostic per undocumented union declaration, located on its identifier, without its type parameter list and its case types.

Why: The name is what the documentation describes; marking it identifies the declaration without marking its whole body.

Example: see RH8036-001.
