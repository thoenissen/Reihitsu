# Analyzer — RH2106 Nested records should not be used

| | |
|---|---|
| ID prefix | RH2106 |
| Status | Active |
| Category | Design |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH2106NestedRecordsShouldNotBeUsedAnalyzer` |
| Uses | SHARED-NESTED-001, SHARED-NESTED-002 |

RH2106 reports a record or record struct declared inside another type.

## Non-goals

- Nested classes, structs, interfaces, enums, and delegates — RH2101, RH2104, RH2105, RH2107, and RH2108.

## Requirements

### RH2106-001 — A nested record or record struct is reported

The analyzer MUST report a record declaration — `record`, `record class`, or `record struct` — that is nested as SHARED-NESTED-001 defines it, located as SHARED-NESTED-002 specifies.

Why: A record inside another type is harder to discover and to reuse, and the boundary of what owns it becomes unclear. A top-level record keeps it visible.

Example:

```csharp
class Outer
{
    record {|RH2106:Point|}(int X);

    record class {|RH2106:Line|}(int Length);

    record struct {|RH2106:Size|}(int Width);

    class Helper
    {
    }
}
```
