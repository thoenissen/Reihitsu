# Analyzer — RH5414 Empty interfaces should use semicolon declarations

| | |
|---|---|
| ID prefix | RH5414 |
| Status | Active |
| Category | Layout |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH5414EmptyInterfacesShouldUseSemicolonDeclarationsAnalyzer`, `RH5414EmptyInterfacesShouldUseSemicolonDeclarationsCodeFixProvider` |
| Uses | SHARED-EMPTY-001, SHARED-EMPTY-002, SHARED-EMPTY-003, SHARED-EMPTY-004 |

RH5414 reports an interface declaration with an empty brace body from C# 12 on, and offers a code fix that replaces the braces with a semicolon as SHARED-EMPTY-003 specifies, unless SHARED-EMPTY-004 withholds it.

## Non-goals

- Empty classes — RH5412; structs — RH5413; records — RH5415; record structs — RH5416.

## Requirements

### RH5414-001 — An empty interface is reported from C# 12 on

The analyzer MUST report an interface declaration as SHARED-EMPTY-001 and SHARED-EMPTY-002 specify when the project's C# version is 12 or later, also when it inherits other interfaces. Below C# 12 it MUST NOT report an interface.

Why: C# 12 is the first version in which an interface can be declared with a semicolon instead of a body. An interface that only combines others has no members of its own and is empty in the same way.

Example:

```csharp
interface {|RH5414:I|}
{
}

interface {|RH5414:J|} : I
{
}
```

Under C# 11, neither interface is reported.
