# Analyzer — RH5506 Class attribute lists must use one attribute per list

| | |
|---|---|
| ID prefix | RH5506 |
| Status | Active |
| Category | Layout |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH5506ClassAttributeListsMustFollowShapeRulesAnalyzer`, `RH5506ClassAttributeListsMustFollowShapeRulesCodeFixProvider` |
| Uses | SHARED-ATTR-001, SHARED-ATTR-013, SHARED-ATTR-016, SHARED-ATTR-017, SHARED-ATTR-019 |

RH5506 reports an attribute list of a class or record class that holds more than one attribute, and offers a code fix that gives each attribute a list of its own. The rule uses `shared/attribute-targets.md`.

## Non-goals

- Struct and record struct attributes — RH5508.
- Where a class attribute list is placed — RH5505.

## Requirements

### RH5506-001 — Class attribute lists hold one attribute

The analyzer MUST check every attribute list that resolves to the class target: the lists of a `class`, `record`, or `record class` declaration without a specifier or with `type:` (SHARED-ATTR-001), and MUST report such a list that holds more than one attribute, as SHARED-ATTR-013 specifies.

Why: Attributes on a type are independent decisions — serialization, obsolescence, test categorization — and each on a line of its own can be read, commented, or removed on its own.

Example:

```csharp
{|RH5506:[A, B]|}
class C
{
}

{|RH5506:[type: A, B]|}
record R;

[A]
[B]
class D
{
}
```

### RH5506-002 — The diagnostic is on the attribute list

The analyzer MUST report the diagnostic on the attribute list, as SHARED-ATTR-016 specifies.

Why: The list is what has the wrong shape; each list of a declaration is reported and fixed on its own.

Example: see RH5506-001.

### RH5506-003 — The fix gives each attribute a list of its own

The code fix MUST replace the list with one list per attribute, each on its own line, as SHARED-ATTR-017 specifies.

Why: The fix makes only the change the diagnostic asks for: the attributes keep their order and their specifier, and each gets a line of its own.

Example:

```csharp
{|RH5506:[A, B]|}
class C
{
}
```

```csharp
[A]
[B]
class C
{
}
```

### RH5506-004 — The fix is withheld for a comment or directive inside the list

The code fix MUST NOT be offered when SHARED-ATTR-019 withholds it. The diagnostic is still reported.

Why: A comment inside the list belongs to the attribute next to it, and only the author can tell which of the new lists it belongs to.

Example:

```csharp
{|RH5506:[A, /* c */ B]|}
class C
{
}
```

is reported, and no code fix is offered.
