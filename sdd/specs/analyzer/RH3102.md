# Analyzer — RH3102 Code must not contain empty statements

| | |
|---|---|
| ID prefix | RH3102 |
| Status | Active |
| Category | Clarity |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH3102CodeMustNotContainEmptyStatementsAnalyzer`, `RH3102CodeMustNotContainEmptyStatementsCodeFixProvider` |
| Uses | — |

RH3102 reports every empty statement — a `;` that stands alone as a statement — and offers a code fix that removes it from a block or a switch section.

## Non-goals

- The semicolons of a `for` header, which are not statements.
- A semicolon that ends another statement or a declaration, such as the one after a type declaration.

## Requirements

### RH3102-001 — Every empty statement is reported

The analyzer MUST report every empty statement, in a block, in a switch section, as the body of an `if`, a loop, or another embedded statement, and after a label.

Why: An empty statement does nothing. It is usually a leftover from editing, and as the body of a loop or an `if` it hides that the body is empty.

Example:

```csharp
class C
{
    void M(int a, bool b)
    {
        {|RH3102:;|}
        while (b) {|RH3102:;|}
        L: {|RH3102:;|}
    }
}
```

### RH3102-002 — The diagnostic is on the semicolon

The analyzer MUST report one diagnostic per empty statement, on its `;` token.

Why: The semicolon is the whole statement.

Example: see RH3102-001.

### RH3102-003 — The fix removes the statement from its block or switch section

The code fix MUST remove an empty statement that is a statement of a block or of a switch section. When the statement stands on a line of its own, the code fix MUST remove that whole line.

Why: Nothing depends on the statement, so the block keeps its meaning; removing the line it stood on leaves no blank line behind.

Example:

```csharp
class C
{
    void M(int a)
    {
        {|RH3102:;|}
        a++;
        switch (a)
        {
            case 1:
                {|RH3102:;|}
                break;
        }
    }
}
```

```csharp
class C
{
    void M(int a)
    {
        a++;
        switch (a)
        {
            case 1:
                break;
        }
    }
}
```

### RH3102-004 — The fix is withheld for an embedded or labeled statement and for a statement with comments

The code fix MUST NOT be offered for an empty statement that is not a statement of a block or a switch section — the body of an `if`, a loop, or another embedded statement, or the statement of a label — nor for one that carries a comment or a preprocessor directive. The diagnostic is still reported.

Why: An embedded statement or a label needs a statement; removing the `;` would not compile. A comment on the statement would be lost with it.

Example:

```csharp
class C
{
    void M(bool b)
    {
        while (b) {|RH3102:;|}
        for (;;) {|RH3102:;|}
    }

    void N()
    {
        L: {|RH3102:;|}
        {|RH3102:;|} // done
    }
}
```

is reported, and no code fix is offered.
