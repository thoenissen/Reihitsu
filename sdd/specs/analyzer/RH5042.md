# Analyzer — RH5042 Comments must not be placed around an assignment operator

| | |
|---|---|
| ID prefix | RH5042 |
| Status | Active |
| Category | Layout |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH5042CommentsMustNotBePlacedAroundAssignmentOperatorAnalyzer` |
| Uses | SHARED-COMMENT-001, SHARED-COMMENT-002, SHARED-COMMENT-003 |

RH5042 reports a comment placed directly before or directly after the `=` of an initializer or an assignment operator.

## Non-goals

- How an assignment is wrapped — the line-break rules.
- A comment elsewhere in the assigned value — the rules for the construct the comment is in.

## Requirements

### RH5042-001 — A comment around an assignment operator is reported

The analyzer MUST report every ordinary comment (SHARED-COMMENT-001, SHARED-COMMENT-002) directly before or directly after the `=` of the initializer of a local, a field, an event field, a property, an enum member, or a parameter default value, or directly before or after the operator of an assignment expression — `=`, a compound assignment such as `+=`, and `??=` — including the member assignments of an object initializer and of a `with` expression, and a deconstructing assignment, as SHARED-COMMENT-003 specifies. A comment before the whole statement or declaration MUST NOT be reported.

Why: An assignment reads as one unit from the target to the value. A comment around the operator separates the target from its value.

Example:

```csharp
class C
{
    public int Value { get; } =
        {|RH5042:// default|}
        1;

    private int[] _values =
        {|RH5042:// defaults|}
        { 1, 2 };

    public int A;

    public event System.Action Changed =
        {|RH5042:// none|}
        null;

    void M(int value = {|RH5042:/* default */|} 1)
    {
        var timeout =
            {|RH5042:// default|}
            30;
        timeout += {|RH5042:/* increment */|} 1;
        _values
            {|RH5042:// reset|}
            = [];
        _ = new C { A = {|RH5042:/* first */|} 1 };
        _ = (1, 2) with { Item1 = {|RH5042:/* first */|} 3 };

        // total
        var total = timeout + value;
        _ = total;
    }
}

enum E
{
    First = {|RH5042:/* start */|} 1,
}
```

### RH5042-002 — The `=` of a name is not checked

The analyzer MUST NOT report a comment around the `=` that names a member of an anonymous object, a named argument of an attribute, or a `using` alias.

Why: That `=` gives a name to an element of the construct around it, or to a type, rather than assigning a value to a target, so the construct's own rules decide where a comment may go.

Example:

```csharp
using System;
using Text =
    // alias
    System.String;

class C
{
    [Obsolete("Use N", DiagnosticId =
        // identifier
        "ID1")]
    void M()
    {
        _ = new { First =
            // value
            1 };
    }
}
```

is not reported.
