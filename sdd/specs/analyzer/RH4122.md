# Analyzer — RH4122 Single-letter parameter names

| | |
|---|---|
| ID prefix | RH4122 |
| Status | Active |
| Category | Naming |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH4122SingleLetterParameterNamesAnalyzer` |
| Uses | SHARED-SINGLE-001 |

RH4122 reports a parameter of a method, constructor, operator, delegate, or indexer whose name is a single letter.

## Non-goals

- Parameters of local functions — RH4123; of lambdas and anonymous methods — RH4124.
- The casing of parameter names — RH4105 and RH4120.

## Requirements

### RH4122-001 — Single-letter parameter names are reported

The analyzer MUST report every parameter with a single-letter name (SHARED-SINGLE-001) of a method, constructor, operator, conversion operator, delegate, or indexer, and of the primary constructor of a class or struct. Members of interfaces and implicit implementations of interface members MUST be checked too. The analyzer MUST report one diagnostic per declared parameter, located on its identifier, so each part of a partial method gets its own diagnostic.

Why: A parameter describes an input of an operation. A single-letter name makes the signature and the call sites harder to understand, especially when several parameters have the same type. An implicit interface implementation is found through its class, so callers that use named arguments there use its own names.

Example:

```csharp
using System.Collections.Generic;

public delegate void D(int {|RH4122:a|});

public interface I
{
    void M(int {|RH4122:b|});
}

public class C(int {|RH4122:c|}) : IComparer<int>
{
    public C(int {|RH4122:d|}, int count)
        : this(d + count)
    {
    }

    public int this[int {|RH4122:i|}] => i;

    public int Compare(int {|RH4122:x|}, int {|RH4122:y|}) => 0;

    public static C operator +(C {|RH4122:l|}, C right) => l;

    public static implicit operator int(C {|RH4122:v|}) => 0;
}

public struct S(int {|RH4122:s|});
```

Example — a partial method, reported on each part:

```csharp
public partial class P
{
    public partial void M(int {|RH4122:a|});
}

public partial class P
{
    public partial void M(int {|RH4122:a|})
    {
    }
}
```

### RH4122-002 — Overrides and explicit interface implementations are not checked

The analyzer MUST NOT report a parameter of an overriding method or indexer, or of an explicit interface implementation.

Why: Such a member implements a signature declared elsewhere, and callers that use named arguments through the base type or the interface use the names declared there. The declaration that introduces the signature is reported instead.

Example:

```csharp
public interface I
{
    void M(int value);
}

public abstract class B
{
    public abstract void N(int value);

    public abstract int this[int index] { get; }
}

public class C : B, I
{
    void I.M(int v)
    {
    }

    public override void N(int v)
    {
    }

    public override int this[int i] => i;
}
```

is not reported.

### RH4122-003 — Record, local function, lambda, and anonymous method parameters are not checked

The analyzer MUST NOT report a parameter of the primary constructor of a record — `record`, `record class`, or `record struct` — nor a parameter of a local function, a lambda, or an anonymous method.

Why: A record's primary constructor parameter declares a public property, whose name follows the property conventions instead, so that a record such as `Point(int X, int Y)` keeps its natural names. Local function, lambda, and anonymous method parameters have rules of their own (RH4123 and RH4124), so each kind can be configured separately.

Example:

```csharp
using System;

public record Point(int X, int Y);

public record class Line(int A);

public record struct Size(int W, int H);

public class C
{
    public void M()
    {
        int Local(int a) => a;
        Func<int, int> f = b => b;
        Action<int> g = delegate (int c) { };
    }
}
```

is not reported.
