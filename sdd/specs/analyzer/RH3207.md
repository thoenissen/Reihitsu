# Analyzer — RH3207 Expression style finalizers should not be used

| | |
|---|---|
| ID prefix | RH3207 |
| Status | Active |
| Category | Clarity |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH3207ExpressionStyleFinalizersShouldNotBeUsedAnalyzer`, `RH3207ExpressionStyleFinalizersShouldNotBeUsedCodeFixProvider` |
| Uses | SHARED-BODY-001, SHARED-BODY-002, SHARED-BODY-003, FMT-STRUCT-005 |

RH3207 reports an expression-bodied finalizer and offers a code fix that converts it to a block body, as the formatter does under FMT-STRUCT-005. Which finalizers are left alone, where the diagnostic is, and what the fix produces are SHARED-BODY-001, SHARED-BODY-002, and SHARED-BODY-003.

## Non-goals

- Expression-bodied methods (RH3202), constructors (RH3203), operators (RH3205), conversion operators (RH3206), and local functions (RH3208).

## Requirements

### RH3207-001 — Every expression-bodied finalizer is reported

The analyzer MUST report every finalizer that has an expression body, unless SHARED-BODY-001 applies. A finalizer with a block body MUST NOT be reported.

Why: The house style uses block bodies for finalizers, as for constructors; the other function kinds have rules of their own, so each kind can be configured separately.

Example:

```csharp
class C
{
    ~C() {|RH3207:=> Release()|};

    private void Release()
    {
    }
}

class D
{
    ~D()
    {
    }
}
```
