# Analyzer — RH5526 Delegate attribute lists must use one attribute per list

| | |
|---|---|
| ID prefix | RH5526 |
| Status | Active |
| Category | Layout |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH5526DelegateAttributeListsMustFollowShapeRulesAnalyzer`, `RH5526DelegateAttributeListsMustFollowShapeRulesCodeFixProvider` |
| Uses | SHARED-ATTR-001, SHARED-ATTR-013, SHARED-ATTR-016, SHARED-ATTR-017, SHARED-ATTR-019 |

RH5526 reports an attribute list of a delegate that holds more than one attribute, and offers a code fix that gives each attribute a list of its own. The rule uses `shared/attribute-targets.md`.

## Non-goals

- The `return:` attributes of a delegate — RH5528.
- Attributes of a delegate's parameters — RH5524.
- Where a delegate attribute list is placed — RH5525.

## Requirements

### RH5526-001 — Delegate attribute lists hold one attribute

The analyzer MUST check every attribute list that resolves to the delegate target: the lists of a `delegate` declaration without a specifier or with `type:` (SHARED-ATTR-001), and MUST report such a list that holds more than one attribute, as SHARED-ATTR-013 specifies.

Why: Attributes on a delegate are independent decisions; one per line lets a diff that adds or removes one attribute leave the others alone.

Example:

```csharp
{|RH5526:[A, B]|}
delegate void D();

class C
{
    {|RH5526:[type: A, B]|}
    delegate void E();
}
```

### RH5526-002 — The diagnostic is on the attribute list

The analyzer MUST report the diagnostic on the attribute list, as SHARED-ATTR-016 specifies.

Why: The list is what has the wrong shape; each list of a declaration is reported and fixed on its own.

Example: see RH5526-001.

### RH5526-003 — The fix gives each attribute a list of its own

The code fix MUST replace the list with one list per attribute, each on its own line, as SHARED-ATTR-017 specifies.

Why: The fix makes only the change the diagnostic asks for: the attributes keep their order and their specifier, and each gets a line of its own.

Example:

```csharp
{|RH5526:[A, B]|}
delegate void D();
```

```csharp
[A]
[B]
delegate void D();
```

### RH5526-004 — The fix is withheld for a comment or directive inside the list

The code fix MUST NOT be offered when SHARED-ATTR-019 withholds it. The diagnostic is still reported.

Why: A comment inside the list belongs to the attribute next to it, and only the author can tell which of the new lists it belongs to.

Example:

```csharp
{|RH5526:[A, /* c */ B]|}
delegate void D();
```

is reported, and no code fix is offered.
