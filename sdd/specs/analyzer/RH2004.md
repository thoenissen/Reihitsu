# Analyzer — RH2004 Access modifier must be declared

| | |
|---|---|
| ID prefix | RH2004 |
| Status | Active |
| Category | Design |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH2004AccessModifierMustBeDeclaredAnalyzer`, `RH2004AccessModifierMustBeDeclaredCodeFixProvider` |
| Uses | SHARED-DIAG-011 |

RH2004 reports a type or member declaration that does not state its accessibility, and offers a code fix that adds the accessibility the declaration has by default.

## Non-goals

- Partial type declarations — RH7104.
- Declarations that cannot carry an accessibility modifier: destructors, enum members, local functions, namespaces, and extension blocks.
- Whether the declared accessibility is the right one. The fix states the default; narrowing or widening it is the author's decision.
- The order of the modifiers after the fix — RH7105.

## Requirements

### RH2004-001 — A declaration without an accessibility modifier is reported

The analyzer MUST report a declaration of a class, struct, interface, enum, record, record struct, delegate, method, property, field, event, constructor, indexer, operator, or conversion operator that carries none of the modifiers `public`, `protected`, `internal`, `private`, and `file`.

This requirement covers an operator or a conversion operator only when it is not an explicit interface implementation, and a constructor only when it is not `partial`.

Why: Without a modifier, the reader has to know the language default for the declaration's context to learn who can use it, and the default differs between a namespace, a type, and an interface. A stated modifier makes the public surface and the implementation details visible at a glance.

Example:

```csharp
using System;

delegate void {|RH2004:Handler|}();

enum {|RH2004:Mode|}
{
    On,
}

class {|RH2004:C|}
{
    int {|RH2004:_count|};

    event Action {|RH2004:Changed|};

    {|RH2004:C|}()
    {
    }

    int {|RH2004:Count|} { get; set; }

    int {|RH2004:this|}[int index] => index;

    static void {|RH2004:Run|}()
    {
    }

    struct {|RH2004:Nested|}
    {
    }
}

file class Local
{
}

public class D
{
    private int _value;

    protected internal void M()
    {
    }
}
```

### RH2004-002 — Partial types and partial methods are not reported

The analyzer MUST NOT report a type declaration that carries the `partial` modifier, in any of its parts, and MUST NOT report a method that carries the `partial` modifier.

Why: The accessibility of a partial type may be stated on any of its parts, and RH7104 decides how it is stated across them. A partial method without a modifier is valid only because it relies on the default; adding one changes which rules the method has to follow.

Example:

```csharp
partial class C
{
    partial void OnChanged();
}

partial class C
{
    partial void OnChanged()
    {
    }
}
```

is not reported.

### RH2004-003 — Static constructors and explicit interface implementations are not reported

The analyzer MUST NOT report a static constructor, or an explicit interface implementation of a method, property, indexer, or event.

Why: Neither can carry an accessibility modifier; adding one does not compile, so the rule does not ask for one there (SHARED-DIAG-011).

Example:

```csharp
using System;

public class C : IDisposable
{
    static C()
    {
    }

    void IDisposable.Dispose()
    {
    }
}
```

is not reported.

### RH2004-004 — Interface members are not reported, nested types in interfaces are

The analyzer MUST NOT report a member declared directly in an interface, other than a type or a delegate. A type or delegate declared directly in an interface MUST be reported, and so MUST the members of a type nested in an interface.

Why: The members of an interface are its contract and are public by default, which every reader of an interface expects. A type nested in an interface is an ordinary type declaration, whose members follow the defaults of their own type.

Example:

```csharp
public interface I
{
    void M();

    int P { get; }

    static int Create() => 0;

    class {|RH2004:Nested|}
    {
        void {|RH2004:Run|}()
        {
        }
    }

    delegate void {|RH2004:Callback|}();
}
```

### RH2004-005 — Where the diagnostic is

The analyzer MUST report one diagnostic per declaration, located on:

- the identifier of a type, delegate, method, property, event, or constructor;
- the identifier of the first declarator of a field or of an event field;
- the `this` keyword of an indexer;
- the operator token of an operator, and the `operator` keyword of a conversion operator.

Why: The name is where the reader looks for the declaration; an indexer and an operator have no name, so their keyword or token stands for it. The accessibility belongs to the whole declaration, so a field declaration with several declarators is reported once.

Example:

```csharp
public struct S
{
    int {|RH2004:a|}, b;

    event System.Action {|RH2004:First|}, Second;

    int {|RH2004:this|}[int index] => index;
}
```

### RH2004-006 — The fix adds the default accessibility

The code fix MUST add the accessibility the declaration has by default as the first modifier, keeping the other modifiers in their order and the declaration's documentation comment in front of it:

- `internal` for a type or delegate declared directly in a namespace or at file level;
- `public` for a type or delegate declared directly in an interface;
- `private` for a member, type, or delegate declared directly in a class, struct, record, or record struct, and for a member declared in an extension block.

This requirement covers a declaration that is neither an operator nor a conversion operator, does not carry the `partial` modifier, and carries no attribute list.

Why: Stating the default makes the existing accessibility visible without changing who can use the declaration, so the fix cannot break any caller.

Example:

```csharp
namespace N
{
    class {|RH2004:C|}
    {
        /// <summary>Runs.</summary>
        static void {|RH2004:Run|}()
        {
        }

        readonly int {|RH2004:_value|};

        class {|RH2004:Nested|}
        {
        }
    }

    interface {|RH2004:I|}
    {
        class {|RH2004:Nested|}
        {
        }
    }

    static class {|RH2004:Extensions|}
    {
        extension(int number)
        {
            int {|RH2004:Twice|}() => number * 2;
        }
    }
}
```

```csharp
namespace N
{
    internal class C
    {
        /// <summary>Runs.</summary>
        private static void Run()
        {
        }

        private readonly int _value;

        private class Nested
        {
        }
    }

    internal interface I
    {
        public class Nested
        {
        }
    }

    internal static class Extensions
    {
        extension(int number)
        {
            private int Twice() => number * 2;
        }
    }
}
```
