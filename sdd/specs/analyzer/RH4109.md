# Analyzer — RH4109 Public field casing

| | |
|---|---|
| ID prefix | RH4109 |
| Status | Active |
| Category | Naming |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH4109PublicFieldCasingAnalyzer`, `RH4109PublicFieldCasingCodeFixProvider` |
| Uses | SHARED-CASING-001, SHARED-CASING-004, SHARED-CASING-006, SHARED-CASING-007, SHARED-CASING-008, SHARED-CASING-009, SHARED-CASING-010 |

RH4109 reports a public field whose name is not in PascalCase and offers a code fix that renames the field and every reference to it.

## Non-goals

- `const` fields of any accessibility — RH4110.
- Fields of the private, protected, and internal groups — RH4106, RH4107, and RH4108.
- Whether a field should be public at all — RH2005.

## Requirements

### RH4109-001 — Public field names are in PascalCase

The analyzer MUST report every variable declarator of a field declaration that is not `const`, belongs to the public group of SHARED-CASING-004, and whose name is not in PascalCase as SHARED-CASING-001 defines it. Static and readonly fields MUST be checked too. The analyzer MUST report one diagnostic per declarator, located on its identifier.

Why: A public field is part of the type's surface for every caller, so it is named like the other public members.

Example:

```csharp
public class C
{
    public int CacheCount;
    public int {|RH4109:itemCount|}, {|RH4109:pageSize|};
    public readonly int {|RH4109:cacheLimit|} = 10;
    public static int {|RH4109:instances|};
    public const int limit = 2;
    int cacheValue;
}
```

### RH4109-002 — The fix renames the field to PascalCase

The code fix MUST rename the field and every reference to it (SHARED-CASING-007) to the PascalCase name that SHARED-CASING-006 derives from its old name. It is withheld as SHARED-CASING-008 and SHARED-CASING-009 specify, and its Fix All skips colliding names as SHARED-CASING-010 specifies.

Why: The fix makes exactly the change the diagnostic asks for, and a field is referenced wherever its type is used.

Example:

```csharp
public class Invoice
{
    public int Amount;

    public int {|RH4109:amount|};

    public int {|RH4109:taxRate|};

    public int Total => Amount + amount + taxRate;
}
```

```csharp
public class Invoice
{
    public int Amount;

    public int {|RH4109:amount|};

    public int TaxRate;

    public int Total => Amount + amount + TaxRate;
}
```

`amount` keeps its diagnostic: its new name `Amount` is already taken (SHARED-CASING-009).
