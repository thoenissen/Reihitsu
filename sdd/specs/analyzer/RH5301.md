# Analyzer — RH5301 Object initializer should be formatted correctly

| | |
|---|---|
| ID prefix | RH5301 |
| Status | Active |
| Category | Layout |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH5301ObjectInitializerShouldBeFormattedCorrectlyAnalyzer`, `RH5301ObjectInitializerShouldBeFormattedCorrectlyCodeFixProvider` |
| Uses | SHARED-INIT-001, FMT-BREAK-021, FMT-INDENT-022 |

RH5301 reports the object initializer of an object creation whose braces are not in the column of `new` or whose member assignments are not one level deeper, and offers a code fix that lays out the object creation the way the formatter does.

## Non-goals

- Collection initializers of an object creation — RH5303; collection initializers assigned to a member — RH5304.
- Anonymous object creations (`new { A = 1 }`) and the initializer of a `with` expression.
- The layout of a member's value after its first token.

## Requirements

### RH5301-001 — Braces outside the column of `new` are reported

The analyzer MUST report an object creation with an object initializer — `new T { … }`, `new T(…) { … }`, or a target-typed `new() { … }` — when its opening or its closing brace does not start at the column of the `new` keyword, the line's anchor decided by SHARED-INIT-001. A brace on the line of `new`, as in an initializer written on one line, therefore is reported. An object creation whose braces both start at the column of `new` MUST NOT be reported under this requirement.

Why: The initializer completes the expression that creates the object, which can start anywhere on its line; braces in the column of `new` keep the initializer with that expression, the way the formatter lays it out (FMT-BREAK-021, FMT-INDENT-022).

Example:

```csharp
class C
{
    int P { get; set; }

    void M()
    {
        var a = {|RH5301:new C { P = 1 }|};
        C b = {|RH5301:new()
            {
                P = 1
            }|};
        var c = new C
                {
                    P = 1
                };
    }
}
```

### RH5301-002 — Members outside their column are reported

When both braces start at the column of `new`, the analyzer MUST report each member assignment of the initializer whose first token does not start four columns to the right of the `new` keyword, the line's anchor decided by SHARED-INIT-001. When a brace is reported under RH5301-001, the members of that initializer MUST NOT be reported.

Why: Every member is one level inside the braces, so the members line up with each other and the extent of the initializer stays visible. Once a brace is out of place, the whole initializer is laid out again, and a diagnostic per member would only repeat that.

Example:

```csharp
class C
{
    int P { get; set; }
    int Q { get; set; }

    void M()
    {
        var a = new C
                {
            {|RH5301:P = 1|},
                    Q = 2
                };
        var b = {|RH5301:new C
            {
            P = 1,
               Q = 2
            }|};
    }
}
```

### RH5301-003 — The diagnostic is on the creation or on the member

The analyzer MUST report one diagnostic per object creation, located on the whole object creation expression, when a brace is out of place; otherwise one diagnostic per misplaced member, located on the whole member assignment.

Why: A misplaced brace concerns the initializer as a whole; a misplaced member concerns only that member, and reporting it there keeps several misplaced members apart.

Example: see RH5301-001 and RH5301-002.

### RH5301-004 — The fix lays out the object creation

The code fix MUST format the reported object creation as the formatter formats it in place: the braces start their own lines at the column of `new`, and every member starts its own line one level deeper (FMT-BREAK-021, FMT-INDENT-022). A comment behind a member stays behind it.

Why: The formatter owns the layout of object initializers; delegating to it applies that layout instead of a second one.

Example:

```csharp
class C
{
    int P { get; set; }
    int Q { get; set; }

    void M()
    {
        var a = {|RH5301:new C { P = 1, // one
            Q = 2 }|};
    }
}
```

```csharp
class C
{
    int P { get; set; }
    int Q { get; set; }

    void M()
    {
        var a = new C
                {
                    P = 1, // one
                    Q = 2
                };
    }
}
```
