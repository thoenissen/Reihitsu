# Analyzer — RH5503 Module attributes must be on their own line

| | |
|---|---|
| ID prefix | RH5503 |
| Status | Active |
| Category | Layout |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH5503ModuleAttributesMustFollowPlacementRulesAnalyzer`, `RH5503ModuleAttributesMustFollowPlacementRulesCodeFixProvider` |
| Uses | SHARED-ATTR-002, SHARED-ATTR-004, SHARED-ATTR-005, SHARED-ATTR-006, SHARED-ATTR-007, SHARED-ATTR-008, SHARED-ATTR-009, SHARED-ATTR-011, SHARED-ATTR-012 |

RH5503 reports a module attribute list that shares its line with the token after it, and offers a code fix that moves that token onto the next line. The rule uses `shared/attribute-targets.md`.

## Non-goals

- Assembly attributes — RH5501.

## Requirements

### RH5503-001 — Module attribute lists are on their own line

The analyzer MUST check every attribute list with the `module:` specifier that is not attached to a parameter or type parameter (SHARED-ATTR-002), and MUST report such a list whose closing bracket shares its line with the first token after it, as SHARED-ATTR-004, SHARED-ATTR-005, and SHARED-ATTR-006 specify for a list that must be on its own line.

Why: A module attribute applies to the whole module, not to the declaration written after it; on the same line it reads like a decoration of that declaration.

Example:

```csharp
[module: A]
{|RH5503:[module: B]|} {|RH5503:[module: C]|} class D
{
}
```

### RH5503-002 — The diagnostic is on the attribute list

The analyzer MUST report the diagnostic on the attribute list, as SHARED-ATTR-007 specifies.

Why: The list is what is misplaced; each list of a declaration is reported and fixed on its own.

Example: see RH5503-001.

### RH5503-003 — The fix moves what follows onto the next line

The code fix MUST put the first token after the list on a new line, as SHARED-ATTR-008 and SHARED-ATTR-009 specify.

Why: The fix makes only the change the diagnostic asks for: what follows the list starts on its own line.

Example:

```csharp
{|RH5503:[module: A]|} class C
{
}
```

```csharp
[module: A]
class C
{
}
```

### RH5503-004 — The fix is withheld for comments, directives, and missing braces

The code fix MUST NOT be offered when SHARED-ATTR-011 or SHARED-ATTR-012 withholds it. The diagnostic is still reported.

Why: A comment inside the list belongs to the attribute next to it, and an unclosed scope leaves no indentation to compute; both are left to the author.

Example:

```csharp
{|RH5503:[module: A /* c */]|} class C
{
}
```

is reported, and no code fix is offered.
