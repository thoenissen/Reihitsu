# Analyzer — RH7406 Non-override properties should not be placed in override regions

| | |
|---|---|
| ID prefix | RH7406 |
| Status | Active |
| Category | Organization |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH7406NonOverridePropertiesShouldNotBePlacedInOverrideRegionsAnalyzer` |
| Uses | SHARED-DIAG-004, SHARED-DIAG-012, SHARED-REGGROUP-001, SHARED-REGGROUP-005, SHARED-REGGROUP-006, SHARED-TYPEREGION-006 |

RH7406 reports a property that overrides nothing when the innermost region it lies in is named after the type that one of the type's overrides comes from. It has no code fix.

## Non-goals

- Where an override property belongs — RH7402.
- Methods, events, and indexers that override nothing — RH7405, RH7407, RH7408.

## Requirements

### RH7406-001 — A property that overrides nothing in an override region is reported

In every type declaration it checks (SHARED-REGGROUP-001), the analyzer MUST report each property declaration that overrides no property — a static, `new`, `virtual`, or `abstract` property and an interface implementation alike — when the innermost region that encloses it (SHARED-REGGROUP-001, SHARED-TYPEREGION-006) is an override region (SHARED-REGGROUP-006). The diagnostic MUST be placed as SHARED-REGGROUP-005 specifies.

A `partial` property is one property (SHARED-DIAG-004): it is reported at most once, on the part SHARED-DIAG-012 selects. It is reported when any of its parts, judged on its own by the region it lies in, would be reported: no part may lie in an override region.

Why: A region named after a base type groups the members that override that type's members. A property of the type's own placed among them blurs which members belong to the override surface.

Example:

```csharp
class B
{
    public virtual int P => 0;
}

class C : B
{
    #region B

    public override int P => 1;

    public int {|RH7406:Q|} => 0;

    #endregion
}
```

Example — a `partial` property that overrides nothing and whose parts both lie in an override region is reported once, on its defining part:

```csharp
class B
{
    public virtual int Size => 0;
}

partial class C : B
{
    #region B

    public override int Size => 1;

    public partial int {|RH7406:P|} { get; }

    public partial int P => 1;

    #endregion
}
```

### RH7406-002 — Other members and other regions are not reported

The analyzer MUST NOT report a property that lies in no region, or whose innermost enclosing region (SHARED-REGGROUP-001) is not an override region, also when a region around that one is. It MUST NOT report an override property or a member that is not a property declaration, such as an indexer.

Why: Outside an override region a property that overrides nothing is where it belongs, an override in an override region is where RH7402 asks it to be, and an indexer has a rule of its own (RH7408).

Example:

```csharp
class B
{
    public virtual int P => 0;
}

class C : B
{
    #region B

    public override int P => 1;

    #endregion

    #region Properties

    public int Q => 0;

    #endregion
}
```

is not reported.
