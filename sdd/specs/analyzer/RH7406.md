# Analyzer — RH7406 Non-override properties should not be placed in override regions

| | |
|---|---|
| ID prefix | RH7406 |
| Status | Active |
| Category | Organization |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH7406NonOverridePropertiesShouldNotBePlacedInOverrideRegionsAnalyzer` |
| Uses | SHARED-REGGROUP-001, SHARED-REGGROUP-002, SHARED-REGGROUP-006, SHARED-REGGROUP-007 |

RH7406 reports a property that overrides nothing when it lies in a top-level region named after the type that one of the type's override properties comes from. It has no code fix.

## Non-goals

- Where an override property belongs — RH7402.
- Methods, events, and indexers that override nothing — RH7405, RH7407, RH7408.

## Requirements

### RH7406-001 — A property that overrides nothing in an override region is reported

In every type declaration it checks (SHARED-REGGROUP-001), the analyzer MUST report each property declaration that overrides no property — a static, `new`, `virtual`, or `abstract` property and an interface implementation alike — when it lies (SHARED-REGGROUP-002) in a top-level region that is an override region of properties (SHARED-REGGROUP-007). The diagnostic MUST be placed as SHARED-REGGROUP-006 specifies.

Why: A region named after a base type groups the members that override that type's members. A property of the type's own placed among them blurs which members belong to the override surface.

Example:

```csharp
class B
{
    public virtual int P => 0;
}

class C : B
{
    #region B

    public override int P => 1;

    public int {|RH7406:Q|} => 0;

    #endregion
}
```

### RH7406-002 — Other members and other regions are not reported

The analyzer MUST NOT report a property that lies in a region that is not an override region, an override property, or a member that is not a property declaration, such as an indexer.

Why: Outside an override region a property that overrides nothing is where it belongs, an override in an override region is where RH7402 asks it to be, and an indexer has a rule of its own (RH7408).

Example:

```csharp
class B
{
    public virtual int P => 0;
}

class C : B
{
    #region B

    public override int P => 1;

    #endregion

    #region Properties

    public int Q => 0;

    #endregion
}
```

is not reported.
