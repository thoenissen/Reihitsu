# Analyzer — RH7408 Non-override indexers should not be placed in override regions

| | |
|---|---|
| ID prefix | RH7408 |
| Status | Active |
| Category | Organization |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH7408NonOverrideIndexersShouldNotBePlacedInOverrideRegionsAnalyzer` |
| Uses | SHARED-DIAG-004, SHARED-DIAG-012, SHARED-REGGROUP-001, SHARED-REGGROUP-005, SHARED-REGGROUP-006, SHARED-TYPEREGION-006 |

RH7408 reports an indexer that overrides nothing when it lies in a top-level region named after the type that one of the type's override indexers comes from. It has no code fix.

## Non-goals

- Where an override indexer belongs — RH7404.
- Methods, properties, and events that override nothing — RH7405, RH7406, RH7407.

## Requirements

### RH7408-001 — An indexer that overrides nothing in an override region is reported

In every type declaration it checks (SHARED-REGGROUP-001), the analyzer MUST report each indexer declaration that overrides no indexer — a `new`, `virtual`, or `abstract` indexer and an interface implementation alike — when it lies in a top-level region (SHARED-TYPEREGION-006), and in no region nested in it, that is an override region of indexers (SHARED-REGGROUP-006). The diagnostic MUST be placed as SHARED-REGGROUP-005 specifies.

A `partial` indexer is one indexer (SHARED-DIAG-004): it is reported at most once, on the part SHARED-DIAG-012 selects. This requirement covers a `partial` indexer only when each of its parts, judged on its own, would be reported; whether a `partial` indexer is reported when only some of its parts would be is not covered.

Why: A region named after a base type groups the members that override that type's members. An indexer of the type's own placed among them obscures which members take part in the override surface.

Example:

```csharp
class B
{
    public virtual int this[int index] => 0;
}

class C : B
{
    #region B

    public override int this[int index] => 1;

    public int {|RH7408:this|}[string key] => 0;

    #endregion
}
```

Example — a `partial` indexer that overrides nothing and whose parts both lie in an override region is reported once, on its defining part:

```csharp
class B
{
    public virtual int this[int index] => index;
}

partial class C : B
{
    #region B

    public override int this[int index] => index;

    public partial int {|RH7408:this|}[string key] { get; }

    public partial int this[string key] => 0;

    #endregion
}
```

### RH7408-002 — Other members and other regions are not reported

The analyzer MUST NOT report an indexer that lies in no region, or in a top-level region that is not an override region and in no region nested in it. It MUST NOT report an override indexer or a member that is not an indexer declaration, such as a property.

Why: Outside an override region an indexer that overrides nothing is where it belongs, an override in an override region is where RH7404 asks it to be, and a property has a rule of its own (RH7406).

Example:

```csharp
class B
{
    public virtual int this[int index] => 0;
}

class C : B
{
    #region B

    public override int this[int index] => 1;

    #endregion

    #region Indexers

    public int this[string key] => 0;

    #endregion
}
```

is not reported.
