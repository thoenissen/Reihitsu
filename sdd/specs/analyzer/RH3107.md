# Analyzer — RH3107 Unnecessary attribute constructor parentheses should be removed

| | |
|---|---|
| ID prefix | RH3107 |
| Status | Active |
| Category | Clarity |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH3107UnnecessaryAttributeConstructorParenthesesShouldBeRemovedAnalyzer`, `RH3107UnnecessaryAttributeConstructorParenthesesShouldBeRemovedCodeFixProvider` |
| Uses | SHARED-PARENS-001, SHARED-PARENS-002 |

RH3107 reports the empty argument list of an attribute, `[Obsolete()]`, and offers a code fix that removes it. Where the diagnostic is and what the fix produces are SHARED-PARENS-001 and SHARED-PARENS-002.

## Non-goals

- Attribute lists, targets, and placement — the layout rules of the RH55## range.

## Requirements

### RH3107-001 — An empty argument list of an attribute is reported

The analyzer MUST report an attribute whose argument list is empty, in any attribute list. An attribute without an argument list or with arguments MUST NOT be reported.

Why: `[Obsolete()]` applies the same attribute as `[Obsolete]`; the parentheses pass no arguments.

Example:

```csharp
using System;
using System.Diagnostics;

[Obsolete{|RH3107:()|}]
class C
{
    [Obsolete{|RH3107:()|}, DebuggerStepThrough{|RH3107:()|}]
    void M()
    {
    }

    [Obsolete]
    void N()
    {
    }

    [Obsolete("x")]
    void O()
    {
    }
}
```
