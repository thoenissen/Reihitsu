# Analyzer — RH2109 Razor code blocks should not be used

| | |
|---|---|
| ID prefix | RH2109 |
| Status | Active |
| Category | Design |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH2109RazorCodeBlocksShouldNotBeUsedAnalyzer` |
| Uses | — |

RH2109 reports every `@code` block in a Razor component file, so the component's logic moves to a code-behind file.

## Non-goals

- How a `.razor` file reaches the compiler. It is read only when it is an additional file of the project.
- Razor views and pages (`.cshtml`).
- The code that a `@code` block contains, and the C# that the Razor compiler generates from the component.
- A code fix. Moving a block into a `.razor.cs` partial class creates a file and needs the component's namespace and class name.

## Requirements

### RH2109-001 — A `@code` block in a `.razor` file is reported

The analyzer MUST report every `@code` directive that is followed by an opening brace `{`, with or without white space or line breaks between them, in an additional file whose path ends in `.razor`, compared case-insensitively.

This requirement covers a `@code` directive that starts a line, after optional white space, outside a Razor, HTML, or C# comment and outside a C# literal.

Why: A `@code` block puts the component's behavior into its markup file. A code-behind partial class keeps rendering and behavior apart and gives the logic the full C# tooling of a `.cs` file.

Example — `Counter.razor`:

```razor
@page "/counter"
<h1>@CurrentCount</h1>
@code {
    private int CurrentCount;
}
@code
{
}
```

reports both `@code` directives.

### RH2109-002 — Other files are not reported

The analyzer MUST NOT report a file whose path does not end in `.razor`, such as a `.razor.cs` code-behind file or a `.cshtml` file, and MUST NOT report a `.razor` file without a `@code` block.

Why: The rule is about the code blocks of Razor components; a code-behind file is where their logic belongs.

Example — `Counter.razor.cs`:

```csharp
public partial class Counter
{
    private int CurrentCount;
}
```

is not reported, and neither is `Counter.razor` with the content

```razor
@page "/counter"
<h1>Counter</h1>
```

### RH2109-003 — The diagnostic covers `@code`

The analyzer MUST report one diagnostic per `@code` block, located in the `.razor` file on the five characters `@code`.

Why: The directive is what the user removes; the block it opens can be long.

Example: see RH2109-001.
