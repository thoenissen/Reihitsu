# Analyzer — RH5028 Code must not contain blank lines at the start of the file

| | |
|---|---|
| ID prefix | RH5028 |
| Status | Active |
| Category | Layout |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH5028CodeMustNotContainBlankLinesAtStartOfFileAnalyzer`, `RH5028CodeMustNotContainBlankLinesAtStartOfFileCodeFixProvider` |
| Uses | SHARED-WS-001 |

RH5028 reports the blank lines in front of the first line of a file that holds anything but whitespace, and offers a code fix that deletes them as SHARED-WS-001 specifies.

In the examples, the reported blank lines are marked from the start of the file to the end of the last line break in front of the first content line, so the markup encloses the line breaks themselves.

## Non-goals

- Blank lines further down the file, including a run of them directly below the first content line — RH5023.
- Whitespace in front of the first token on the first content line.

## Requirements

### RH5028-001 — Blank lines at the start of a file are reported

The analyzer MUST report a file whose first line holds nothing but whitespace, with one diagnostic that spans from the start of the file to the start of the first line holding anything else — code, a comment, or a directive. A file that holds nothing but whitespace and line breaks MUST be reported with one diagnostic that spans the whole file.

Why: Leading blank lines push the content down without separating it from anything; the file's start is already a boundary.

Example:

```csharp
{|RH5028:


|}class C
{
}
```

### RH5028-002 — A file that starts with content is not reported

The analyzer MUST NOT report a file whose first line holds anything but whitespace, even when blank lines follow it, and MUST NOT report an empty file.

Why: Only lines in front of the first content are leading blank lines; a blank line after a header comment separates that comment from the code and is RH5023's concern when it repeats.

Example:

```csharp
// header

class C
{
}
```

is not reported.

### RH5028-003 — The fix deletes the leading blank lines

The code fix MUST delete the reported span as SHARED-WS-001 specifies, so the file starts with its first content line; a file that holds nothing but whitespace becomes empty. It is offered for every reported file.

Why: The reported span holds nothing but whitespace and line breaks, so deleting it can never touch a comment, a directive, or a token.

Example:

```csharp
{|RH5028:

|}class C
{
}
```

```csharp
class C
{
}
```
