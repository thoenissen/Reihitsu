# Analyzer — RH3202 Expression style methods should not be used

| | |
|---|---|
| ID prefix | RH3202 |
| Status | Active |
| Category | Clarity |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH3202ExpressionStyleMethodsShouldNotBeUsedAnalyzer`, `RH3202ExpressionStyleMethodsShouldNotBeUsedCodeFixProvider` |
| Uses | FMT-STRUCT-004, SHARED-BODY-001, SHARED-BODY-002, SHARED-BODY-003, SHARED-BODY-004, SHARED-FIX-007 |

RH3202 reports an expression-bodied method and offers a code fix that converts it to a block body by formatting the method with the formatter. The rule and the formatter's FMT-STRUCT-004 are two views of one style decision. Which methods are left alone, where the diagnostic is, what the fix produces, and when it is withheld are SHARED-BODY-001, SHARED-BODY-002, SHARED-BODY-003, and SHARED-BODY-004. The fix is deliberately withheld for an `async` method whose return type is not written as a task type (an alias, a custom task type): the method stays reported, and the author converts it by hand (SHARED-BODY-004).

## Non-goals

- Expression-bodied local functions (RH3208), constructors (RH3203), operators (RH3205), conversion operators (RH3206), and finalizers (RH3207).
- Expression-bodied properties, indexers, accessors, and lambdas, which stay expression-bodied (FMT-STRUCT-008).
- Which statement the converted body contains and how its trivia is carried over — FMT-STRUCT-004 and FMT-STRUCT-006 own that; this spec only references them.

## Requirements

### RH3202-001 — Every expression-bodied method is reported

The analyzer MUST report every method declaration that has an expression body — in a class, struct, record, or interface, static or instance, `async` or not — unless SHARED-BODY-001 applies. Local functions, operators, conversion operators, properties, and indexers MUST NOT be reported.

Why: The house style keeps expression bodies for properties, indexers, and accessors and uses block bodies for methods. The other function kinds have rules of their own, so each kind can be configured separately.

Example:

```csharp
using System;

class C
{
    void Run() {|RH3202:=> Console.WriteLine()|};

    void Outer()
    {
        int Local() => 1;
    }

    public static C operator +(C a, C b) => a;

    int P => 1;
}

interface I
{
    int M() {|RH3202:=> 1|};
}
```

### RH3202-002 — The fix keeps the separators around the method

The code fix MUST keep the blank lines above and below the converted method.

A method that shares its line with another member of the same type gets a line of its own as SHARED-FIX-007 (*Shared line*) states, but only when the line on which the method starts begins with a member of that type, the method itself or one in front of it. When that line begins with other code, such as the header and opening brace of a type written on one line, the fix MUST NOT separate the method from the members on its lines: they stay where they are, and the method is converted and laid out from its column.

Why: The fix changes one member's body; the spacing between members is the author's and is not part of the diagnostic. A method separated from its neighbours starts in the column of the member that begins its line; when the line begins with the type's header, that column is the type's, not the method's, and finding the method's column would repeat the formatter's indentation in the fix. A type written on one line is rare, and RH5404 reports it.

Example:

```csharp
class C
{
    private int _value;

    public int GetValue() {|RH3202:=> _value|};
}
```

```csharp
class C
{
    private int _value;

    public int GetValue()
    {
        return _value;
    }
}
```

Example — a type written on one line; the members stay on the method's lines:

```csharp
namespace N
{
    class C { int _value; public int GetValue() {|RH3202:=> _value|}; private int _x; }
}
```

```csharp
namespace N
{
    class C { int _value; public int GetValue()
                          {
                              return _value;
                          } private int _x; }
}
```
