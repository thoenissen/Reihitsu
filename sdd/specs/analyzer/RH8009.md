# Analyzer — RH8009 Non-private record structs must be documented

| | |
|---|---|
| ID prefix | RH8009 |
| Status | Active |
| Category | Documentation |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH8009NonPrivateRecordStructsMustBeDocumentedAnalyzer` |
| Uses | SHARED-DOC-001, SHARED-DOC-002, SHARED-DOC-004, SHARED-DOC-005, SHARED-DOC-006, SHARED-DOC-007, SHARED-DOC-008 |

RH8009 reports a record struct in the non-private group that has no `<summary>` or `<inheritdoc>` documentation.

## Non-goals

- Record structs in the private group — RH8010.
- Structs declared with `struct` — RH8003; records declared with `record` or `record class` — RH8007.
- Whether the summary has text — RH8030; the documentation of type parameters and positional parameters — RH8108 and RH8101.

## Requirements

### RH8009-001 — Undocumented non-private record structs are reported

The analyzer MUST report every record struct declaration in the non-private group of SHARED-DOC-002 that is not documented, checked as SHARED-DOC-001 specifies. A record struct declaration is one written with `record struct`, positional or not, including `readonly` and generic record structs; a `struct` declaration is not one, and neither is a `record` or `record class` declaration. Whether it is documented MUST be decided as SHARED-DOC-004, SHARED-DOC-005, SHARED-DOC-006, and SHARED-DOC-007 specify, and nothing is reported when SHARED-DOC-008 applies.

Why: A record struct that other code can use is part of the contract that code builds on. Without a summary, the generated documentation and the editor's tooltip show nothing, and readers have to infer what the record struct is for from its implementation.

Example:

```csharp
public record struct {|RH8009:Point|}(int Left, int Top);

/// <remarks>
/// No summary
/// </remarks>
internal readonly record struct {|RH8009:Size|}
{
}

record struct {|RH8009:Pair|}<T>(T First, T Second);

/// <summary>
/// Documented
/// </summary>
public record struct Documented
{
    private record struct Hidden;
}

public struct Plain
{
}

public record Entity;
```

### RH8009-002 — The diagnostic is on the record struct name

The analyzer MUST report one diagnostic per undocumented record struct declaration, located on its identifier, without its type parameter list and its parameter list.

Why: The name is what the documentation describes; marking it identifies the declaration without marking its whole body.

Example: see RH8009-001.
