# Analyzer — RH6001 Keywords must be spaced correctly

| | |
|---|---|
| ID prefix | RH6001 |
| Status | Active |
| Category | Spacing |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH6001KeywordsMustBeSpacedCorrectlyAnalyzer`, `RH6001KeywordsMustBeSpacedCorrectlyCodeFixProvider` |
| Uses | FMT-SPACE-012, SHARED-BLANK-008 |

RH6001 reports a statement keyword that is directly followed by an opening parenthesis, and offers a code fix that inserts a space after the keyword.

## Non-goals

- The space after `operator` — RH6005; after `new` — the formatter (FMT-SPACE-012) and RH6022 for `new[]`.
- Keywords followed by something other than `(`, such as `return x;` or `throw;`.
- The whitespace inside the parentheses — RH6006.
- Directive keywords, such as `#if(DEBUG)`, which are not code tokens.

## Requirements

### RH6001-001 — A statement keyword glued to its parenthesis is reported

The analyzer MUST report the keywords `if`, `while` (including the `while` of a `do` statement), `for`, `foreach`, `switch`, `catch`, `fixed`, `lock`, `using`, `return`, and `throw` when the keyword is followed by `(` either directly or after one or more `/* */` comments that are not documentation comments, with no whitespace and no line break anywhere between the keyword and the `(`.

Why: Without the space, `if(x)` and `return(x)` look like calls to methods named `if` and `return`; the space shows that the parenthesis belongs to the statement. The formatter writes the same space (FMT-SPACE-012), so formatted code raises no RH6001.

Example:

```csharp
using System;

class C
{
    int M(int a, object o, IDisposable d, int[] arr)
    {
        {|RH6001:if|}(a > 0)
        {
        }

        do
        {
        }
        {|RH6001:while|}(a > 0);

        {|RH6001:foreach|}(var x in arr)
        {
        }

        {|RH6001:lock|}(o)
        {
        }

        {|RH6001:using|}(d)
        {
        }

        {|RH6001:if|}/* note */(a > 1)
        {
            {|RH6001:throw|}(new Exception());
        }

        return a;
    }
}
```

### RH6001-002 — A separated keyword and other keywords are not reported

The analyzer MUST NOT report a keyword of RH6001-001 that is followed by whitespace of any width or by a line break before its `(`, either directly or after a `/* */` comment that is not a documentation comment. A line break stands before the `(` when the `(` starts its line (SHARED-BLANK-008), also behind a `///` comment written directly behind the keyword. The keywords `typeof`, `nameof`, `sizeof`, `checked`, `unchecked`, `default`, and `new` MUST NOT be checked.

Why: Any whitespace already shows that the parenthesis is not a call; its width is the formatter's business. The other keywords take their parenthesis like a call does, and `typeof(C)` is the usual way to write them.

Example:

```csharp
class C
{
    int M(int a)
    {
        if (a > 0)
        {
        }

        while  (a > 0)
        {
        }

        if
            (a > 1)
        {
        }

        if/// stray
        (a > 2)
        {
        }

        var t = typeof(C);
        var n = nameof(a);
        var c = checked(a + 1);
        var u = unchecked(a + 1);
        var d = default(int);
        object w = new();

        return (a);
    }
}
```

is not reported.

### RH6001-003 — The diagnostic is on the keyword

The analyzer MUST report one diagnostic per keyword, located on the keyword token.

Why: The keyword is the token whose spacing is wrong, and its location does not move when the condition changes.

Example: see RH6001-001.

### RH6001-004 — The fix inserts a space after the keyword

The code fix MUST insert one space directly after the keyword, in front of a comment that follows it, and MUST NOT change anything else.

Why: The fix answers exactly what the diagnostic reports; inserting the space next to the keyword never touches the comment.

Example:

```csharp
class C
{
    int M(int a)
    {
        {|RH6001:if|}(a > 0)
        {
        }

        {|RH6001:if|}/* note */(a > 1)
        {
        }

        {|RH6001:return|}(a);
    }
}
```

```csharp
class C
{
    int M(int a)
    {
        if (a > 0)
        {
        }

        if /* note */(a > 1)
        {
        }

        return (a);
    }
}
```
