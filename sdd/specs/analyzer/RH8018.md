# Analyzer — RH8018 Private constructors must be documented

| | |
|---|---|
| ID prefix | RH8018 |
| Status | Active |
| Category | Documentation |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH8018PrivateConstructorsMustBeDocumentedAnalyzer` |
| Uses | SHARED-DOC-001, SHARED-DOC-002, SHARED-DOC-004, SHARED-DOC-005, SHARED-DOC-006, SHARED-DOC-007, SHARED-DOC-008 |

RH8018 reports a constructor in the private group, static constructors included, that has no `<summary>` or `<inheritdoc>` documentation.

## Non-goals

- Constructors in the non-private group — RH8017.
- Whether the summary has text — RH8030; the documentation of parameters — RH8101.

## Requirements

### RH8018-001 — Undocumented private constructors are reported

The analyzer MUST report every constructor declaration in the private group of SHARED-DOC-002 that is not documented, checked as SHARED-DOC-001 specifies. A constructor declaration is a constructor declared in the body of a class, struct, record, or record struct. A static constructor takes no access modifier, so it belongs to the private group. Whether it is documented MUST be decided as SHARED-DOC-004, SHARED-DOC-005, SHARED-DOC-006, and SHARED-DOC-007 specify, and nothing is reported when SHARED-DOC-008 applies.

Why: A private constructor is an implementation detail of its type, but the next maintainer still has to know what it is for. It has a rule of its own, so a project can require documentation for what other code uses without requiring it here.

Example:

```csharp
/// <summary>
/// Service
/// </summary>
public class Service
{
    private {|RH8018:Service|}()
    {
    }

    /// <remarks>
    /// No summary
    /// </remarks>
    {|RH8018:Service|}(int value)
    {
    }

    static {|RH8018:Service|}()
    {
    }

    /// <summary>
    /// Creates a service
    /// </summary>
    /// <param name="value">Value</param>
    private Service(long value)
    {
    }

    public Service(short value)
    {
    }
}

/// <summary>
/// Point
/// </summary>
public struct Point
{
    {|RH8018:Point|}(int value)
    {
    }
}
```

### RH8018-002 — The diagnostic is on the constructor name

The analyzer MUST report one diagnostic per undocumented constructor declaration, located on its identifier.

Why: The name is what the documentation describes; marking it identifies the declaration without marking its whole body.

Example: see RH8018-001.
