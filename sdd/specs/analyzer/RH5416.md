# Analyzer — RH5416 Empty record structs should use semicolon declarations

| | |
|---|---|
| ID prefix | RH5416 |
| Status | Active |
| Category | Layout |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH5416EmptyRecordStructsShouldUseSemicolonDeclarationsAnalyzer`, `RH5416EmptyRecordStructsShouldUseSemicolonDeclarationsCodeFixProvider` |
| Uses | SHARED-EMPTY-001, SHARED-EMPTY-002, SHARED-EMPTY-003, SHARED-EMPTY-004 |

RH5416 reports a record struct declaration with an empty brace body from C# 10 on, and offers a code fix that replaces the braces with a semicolon as SHARED-EMPTY-003 specifies, unless SHARED-EMPTY-004 withholds it.

## Non-goals

- Empty records — RH5415; classes — RH5412; structs — RH5413; interfaces — RH5414.

## Requirements

### RH5416-001 — An empty record struct is reported from C# 10 on

The analyzer MUST report a record struct declaration, with any modifiers such as `readonly` and with or without a parameter list, as SHARED-EMPTY-001 and SHARED-EMPTY-002 specify when the project's C# version is 10 or later. Below C# 10 it MUST NOT report a record struct. A record class MUST NOT be reported by this rule.

Why: Record structs and their semicolon declaration both exist from C# 10 on. A positional record struct declares its members through its parameter list, so its body is often empty. A record class is RH5415's.

Example:

```csharp
record struct {|RH5416:A|}
{
}

readonly record struct {|RH5416:B|}(int Value)
{
}

record C
{
}
```

Under C# 9, `A` is not reported.
