# Analyzer — RH4104 Local function name casing

| | |
|---|---|
| ID prefix | RH4104 |
| Status | Active |
| Category | Naming |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH4104LocalFunctionNameCasingAnalyzer`, `RH4104LocalFunctionNameCasingCodeFixProvider` |
| Uses | SHARED-CASING-001, SHARED-CASING-006, SHARED-CASING-007, SHARED-CASING-008, SHARED-CASING-009, SHARED-CASING-010 |

RH4104 reports a local function whose name is not in PascalCase and offers a code fix that renames the local function and every reference to it.

## Non-goals

- Methods — RH4103.
- The names of a local function's parameters — RH4105.

## Requirements

### RH4104-001 — Local function names are in PascalCase

The analyzer MUST report every local function whose name is not in PascalCase as SHARED-CASING-001 defines it, including async, static, generic, and nested local functions. The diagnostic MUST be located on the local function's identifier.

Why: A local function is called like a method, so it is named like one; a camelCase name would read like a local variable holding a delegate.

Example:

```csharp
using System.Threading.Tasks;

public class C
{
    public void M()
    {
        void ProcessItem()
        {
        }

        async Task {|RH4104:loadItem|}()
        {
            await Task.CompletedTask;
        }

        static void {|RH4104:processAll|}()
        {
            void {|RH4104:innerLocal|}()
            {
            }
        }

        T {|RH4104:createValue|}<T>()
            where T : new()
        {
            return new T();
        }
    }
}
```

### RH4104-002 — The fix renames the local function to PascalCase

The code fix MUST rename the local function and every reference to it (SHARED-CASING-007) to the PascalCase name that SHARED-CASING-006 derives from its old name. It is withheld as SHARED-CASING-008 and SHARED-CASING-009 specify, and its Fix All skips colliding names as SHARED-CASING-010 specifies. This requirement covers the renames that SHARED-CASING-007 covers.

Why: The fix makes exactly the change the diagnostic asks for, and a local function is referenced at every call site.

Example:

```csharp
public class Runner
{
    public int Run(int value)
    {
        int {|RH4104:outerHelper|}(int input)
        {
            int {|RH4104:innerHelper|}(int nested)
            {
                return nested + 1;
            }

            return innerHelper(input);
        }

        return outerHelper(value);
    }
}
```

```csharp
public class Runner
{
    public int Run(int value)
    {
        int OuterHelper(int input)
        {
            int InnerHelper(int nested)
            {
                return nested + 1;
            }

            return InnerHelper(input);
        }

        return OuterHelper(value);
    }
}
```
