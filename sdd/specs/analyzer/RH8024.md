# Analyzer — RH8024 Non-private indexers must be documented

| | |
|---|---|
| ID prefix | RH8024 |
| Status | Active |
| Category | Documentation |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH8024NonPrivateIndexersMustBeDocumentedAnalyzer` |
| Uses | SHARED-DOC-001, SHARED-DOC-002, SHARED-DOC-004, SHARED-DOC-005, SHARED-DOC-006, SHARED-DOC-007, SHARED-DOC-008, SHARED-DOC-009 |

RH8024 reports an indexer in the non-private group that has no `<summary>` or `<inheritdoc>` documentation.

## Non-goals

- Indexers in the private group — RH8025.
- Properties — RH8022 and RH8023.
- Whether the summary has text — RH8030; the documentation of parameters and return values — RH8101 and RH8105.

## Requirements

### RH8024-001 — Undocumented non-private indexers are reported

The analyzer MUST report every indexer declaration in the non-private group of SHARED-DOC-002 that is not documented, checked as SHARED-DOC-001 specifies, except an explicit interface implementation, which SHARED-DOC-009 exempts. An indexer declaration is a `this[…]` declaration in the body of a class, struct, interface, record, or record struct. The group is decided by the modifiers of the indexer, not by those of its accessors. Whether it is documented MUST be decided as SHARED-DOC-004, SHARED-DOC-005, SHARED-DOC-006, and SHARED-DOC-007 specify, and nothing is reported when SHARED-DOC-008 applies.

Why: An indexer that other code can use is part of the contract that code builds on, and its signature says nothing about what the index means or which values it accepts. Without a summary, the generated documentation and the editor's tooltip show nothing.

Example:

```csharp
/// <summary>
/// Buffer
/// </summary>
public class Buffer
{
    public int {|RH8024:this|}[int index] => index;

    /// <remarks>
    /// No summary
    /// </remarks>
    internal int {|RH8024:this|}[string key] => 0;

    /// <summary>
    /// Gets the value at a position
    /// </summary>
    /// <param name="index">Index</param>
    /// <returns>Value</returns>
    public int this[long index] => 0;

    private int this[short index] => index;
}

/// <summary>
/// Contract
/// </summary>
public interface IContract
{
    int {|RH8024:this|}[int index] { get; }
}
```

### RH8024-002 — The diagnostic is on the `this` keyword

The analyzer MUST report one diagnostic per undocumented indexer declaration, located on its `this` keyword.

Why: An indexer has no name of its own; `this` is the token that names it in the declaration.

Example: see RH8024-001.
