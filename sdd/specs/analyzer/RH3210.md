# Analyzer — RH3210 Get-only indexers should use an expression body

| | |
|---|---|
| ID prefix | RH3210 |
| Status | Active |
| Category | Clarity |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH3210GetOnlyIndexersShouldUseAnExpressionBodyAnalyzer`, `RH3210GetOnlyIndexersShouldUseAnExpressionBodyCodeFixProvider` |
| Uses | SHARED-GETONLY-001, SHARED-GETONLY-002, SHARED-GETONLY-003, SHARED-GETONLY-004, SHARED-GETONLY-005, SHARED-GETONLY-006, SHARED-GETONLY-007, SHARED-GETONLY-008 |

RH3210 reports an indexer whose accessor list holds nothing but a getter that an expression body can replace, and offers a code fix that replaces the accessor list with the expression body the formatter writes. Which indexers are reported and which are not, where the diagnostic is, what the fix produces, and when it is withheld are SHARED-GETONLY-001 to SHARED-GETONLY-008.

## Non-goals

- Properties — RH3209.
- Indexers with a `set` or `init` accessor, whose block-bodied accessors the formatter converts to expression-bodied accessors (FMT-STRUCT-009); no rule reports them.
- Expression-bodied indexers, which are the form the rule asks for (FMT-STRUCT-008).

## Requirements

### RH3210-001 — Every get-only indexer the formatter converts is reported

The analyzer MUST report every indexer declaration that SHARED-GETONLY-001 describes — in a class, a struct, a record, or an interface, an explicit interface implementation included — and no indexer that SHARED-GETONLY-002 leaves out, on its accessor list (SHARED-GETONLY-004). It MUST also report the members of SHARED-GETONLY-003, SHARED-GETONLY-006, and SHARED-GETONLY-007, for which no fix is offered. The code fix MUST write the expression-bodied indexer of SHARED-GETONLY-005, and separates it from a member on its line or withholds itself as SHARED-GETONLY-008 states.

Why: The house style writes a get-only indexer as an expression-bodied indexer, as it does a get-only property; properties have a rule of their own, so each kind can be configured separately.

Example:

```csharp
using System;

class C
{
    private readonly int[] _values = new int[3];

    public int this[int index] {|RH3210:{ get => _values[index]; }|}

    public int this[long index]
    {|RH3210:{
        get
        {
            return _values[index];
        }
    }|}

    public int this[string key] {|RH3210:{ get { throw new NotSupportedException(key); } }|}

    public int this[short index]
    {
        get => _values[index];
        set => _values[index] = value;
    }

    public int this[byte index] => _values[index];
}
```

```csharp
using System;

class C
{
    private readonly int[] _values = new int[3];

    public int this[int index] => _values[index];

    public int this[long index] => _values[index];

    public int this[string key] => throw new NotSupportedException(key);

    public int this[short index]
    {
        get => _values[index];
        set => _values[index] = value;
    }

    public int this[byte index] => _values[index];
}
```
