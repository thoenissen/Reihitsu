# Analyzer — RH4115 Local variable casing

| | |
|---|---|
| ID prefix | RH4115 |
| Status | Active |
| Category | Naming |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH4115LocalVariableCasingAnalyzer`, `RH4115LocalVariableCasingCodeFixProvider` |
| Uses | SHARED-CASING-002, SHARED-CASING-006, SHARED-CASING-007, SHARED-CASING-008, SHARED-CASING-009, SHARED-CASING-010 |

RH4115 reports a local variable whose name is not in camelCase and offers a code fix that renames the variable and every reference to it.

## Non-goals

- Parameters, including those of lambdas and local functions — RH4105.
- Names of local functions — RH4104.
- Local variable names of a single letter — RH4125 to RH4127.

## Requirements

### RH4115-001 — Local variable names are in camelCase

The analyzer MUST report every local variable whose name is not in camelCase as SHARED-CASING-002 defines it, among the variables declared by:

- a local declaration statement that is not `const`, including a `using` declaration;
- the declaration in the initializer of a `for` statement;
- the declaration of a `using` statement or of a `fixed` statement;
- a `foreach` statement that declares a single iteration variable;
- a `catch` declaration that names its exception variable;
- the variable designation of an `out` argument, or of a declaration pattern or `var` pattern that declares a single variable.

The analyzer MUST report one diagnostic per variable, located on its identifier. This requirement covers names other than `_`.

Why: camelCase is the .NET style for locals; it tells a reader at every use that the name is a value of the current block, not a member of the type.

Example:

```csharp
using System;
using System.IO;

class C
{
    unsafe void M(object input, int[] values)
    {
        int {|RH4115:Count|} = 1, total = 2;
        using var {|RH4115:Stream|} = new MemoryStream();

        for (int {|RH4115:Index|} = 0; Index < 1; Index++)
        {
        }

        foreach (var {|RH4115:Item|} in values)
        {
        }

        using (var {|RH4115:Reader|} = new StringReader(""))
        {
        }

        fixed (int* {|RH4115:Pointer|} = values)
        {
        }

        int.TryParse("1", out var {|RH4115:Parsed|});

        if (input is int {|RH4115:Number|})
        {
        }

        if (input is string { Length: var {|RH4115:Size|} })
        {
        }

        try
        {
        }
        catch (Exception {|RH4115:Error|})
        {
        }
        catch
        {
        }
    }
}
```

### RH4115-002 — Variables of a `var (…)` deconstruction are not checked

The analyzer MUST NOT report a variable declared by a deconstruction declaration `var (…)`, whether it is the target of a deconstructing assignment or the variable part of a `foreach` statement.

Why: RH4117 checks these variables, so that deconstruction can be configured apart from ordinary locals.

Example:

```csharp
using System.Collections.Generic;

class C
{
    void M((int, int) pair, List<(int, int)> pairs)
    {
        var (First, Second) = pair;

        foreach (var (Key, Value) in pairs)
        {
        }
    }
}
```

is not reported.

### RH4115-003 — The fix renames the variable to camelCase

The code fix MUST rename the variable and every reference to it (SHARED-CASING-007) to the camelCase name that SHARED-CASING-006 derives from its old name. It is withheld as SHARED-CASING-008 and SHARED-CASING-009 specify, and its Fix All skips colliding names as SHARED-CASING-010 specifies. This requirement covers the renames that SHARED-CASING-007 covers.

Why: The fix makes exactly the change the diagnostic asks for, and a local is referenced throughout its block.

Example:

```csharp
class C
{
    int M(int[] values)
    {
        var {|RH4115:Total|} = 0;

        foreach (var {|RH4115:Current_Value|} in values)
        {
            Total += Current_Value;
        }

        return Total;
    }
}
```

```csharp
class C
{
    int M(int[] values)
    {
        var total = 0;

        foreach (var currentValue in values)
        {
            total += currentValue;
        }

        return total;
    }
}
```
