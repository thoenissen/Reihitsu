# Analyzer — RH8007 Non-private records must be documented

| | |
|---|---|
| ID prefix | RH8007 |
| Status | Active |
| Category | Documentation |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH8007NonPrivateRecordsMustBeDocumentedAnalyzer` |
| Uses | SHARED-DOC-001, SHARED-DOC-002, SHARED-DOC-004, SHARED-DOC-005, SHARED-DOC-006, SHARED-DOC-007, SHARED-DOC-008 |

RH8007 reports a record in the non-private group that has no `<summary>` or `<inheritdoc>` documentation.

## Non-goals

- Records in the private group — RH8008.
- Record structs — RH8009; classes declared with `class` — RH8001.
- Whether the summary has text — RH8030; the documentation of type parameters and positional parameters — RH8108 and RH8101.

## Requirements

### RH8007-001 — Undocumented non-private records are reported

The analyzer MUST report every record declaration in the non-private group of SHARED-DOC-002 that is not documented, checked as SHARED-DOC-001 specifies. A record declaration is one written with `record` or `record class`, positional or not, including generic records; a `record struct` declaration is not one, and neither is a `class` declaration. Whether it is documented MUST be decided as SHARED-DOC-004, SHARED-DOC-005, SHARED-DOC-006, and SHARED-DOC-007 specify, and nothing is reported when SHARED-DOC-008 applies.

Why: A record that other code can use is part of the contract that code builds on. Without a summary, the generated documentation and the editor's tooltip show nothing, and readers have to infer what the record is for from its implementation.

Example:

```csharp
public record {|RH8007:Person|}(string Name);

/// <remarks>
/// No summary
/// </remarks>
internal record class {|RH8007:Order|}
{
}

record {|RH8007:Result|}<T>(T Value);

/// <summary>
/// Documented
/// </summary>
public record Documented
{
    private record Hidden;
}

public class Plain
{
}

public record struct Entry;
```

### RH8007-002 — The diagnostic is on the record name

The analyzer MUST report one diagnostic per undocumented record declaration, located on its identifier, without its type parameter list and its parameter list.

Why: The name is what the documentation describes; marking it identifies the declaration without marking its whole body.

Example: see RH8007-001.
