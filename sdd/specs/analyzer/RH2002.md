# Analyzer — RH2002 Async void methods should not be used

| | |
|---|---|
| ID prefix | RH2002 |
| Status | Active |
| Category | Design |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH2002AsyncVoidShouldNotBeUsedAnalyzer` |
| Uses | — |

RH2002 reports an `async` method, local function, or anonymous function that returns `void`.

## Non-goals

- Asynchronous code that does not use the `async` modifier, such as a method that returns `void` and starts a task it does not await.
- Which awaitable type replaces `void`. `Task`, `ValueTask`, and every other return type are not reported.
- A code fix. Changing the return type changes the method's signature for every caller, and an event handler or an override cannot change it at all.

## Requirements

### RH2002-001 — An async void method is reported

The analyzer MUST report an ordinary method declared `async` whose return type is `void`, whether it is static, virtual, an override, or has the signature of an event handler.

This requirement covers a method that is neither an explicit interface implementation nor a part of a partial method.

Why: An async void method cannot be awaited, so its caller cannot know when it completes. An exception thrown in it cannot be caught by the caller and ends the process. A method that overrides or handles an event is still such a method; the rule reports it so the risk is a visible decision.

Example:

```csharp
using System;
using System.Threading.Tasks;

class C
{
    async void {|RH2002:Run|}()
    {
        await Task.Delay(1);
    }

    static async void {|RH2002:Start|}()
    {
        await Task.Delay(1);
    }

    async void {|RH2002:OnClick|}(object sender, EventArgs e)
    {
        await Task.Delay(1);
    }

    public virtual async void {|RH2002:Load|}() => await Task.Delay(1);
}

class D : C
{
    public override async void {|RH2002:Load|}() => await Task.Delay(1);
}
```

### RH2002-002 — An async void local function is reported

The analyzer MUST report a local function declared `async` whose return type is `void`.

Why: A local function has the same awaiting and exception hazards as a method.

Example:

```csharp
using System.Threading.Tasks;

class C
{
    void M()
    {
        async void {|RH2002:Local|}()
        {
            await Task.Delay(1);
        }

        Local();
    }
}
```

### RH2002-003 — An async anonymous function bound to a void delegate is reported

The analyzer MUST report a lambda or anonymous method marked `async` whose delegate type returns `void`, such as `Action` or `EventHandler`. An async anonymous function whose delegate type returns a task, including one whose type the compiler infers, MUST NOT be reported.

Why: An async anonymous function converted to a `void`-returning delegate is an async void method without a name. Converted to a task-returning delegate, it can be awaited.

Example:

```csharp
using System;
using System.Threading.Tasks;

class C
{
    void M()
    {
        Action a = {|RH2002:async|} () => await Task.Delay(1);
        Action<int> b = {|RH2002:async|} x => await Task.Delay(x);
        EventHandler c = {|RH2002:async|} (sender, e) => await Task.Delay(1);
        Action d = {|RH2002:async|} delegate
        {
            await Task.Delay(1);
        };
        Func<Task> e = async () => await Task.Delay(1);
        var f = async () => await Task.Delay(1);
    }
}
```

### RH2002-004 — Async functions that return a task, and void functions that are not async, are not reported

The analyzer MUST NOT report an `async` method or local function whose return type is not `void`, such as `Task`, `Task<T>`, or `ValueTask`, and MUST NOT report a method, local function, or anonymous function that returns `void` without the `async` modifier.

Why: A function that returns a task can be awaited and carries its exceptions to the caller. A synchronous `void` function has neither hazard.

Example:

```csharp
using System;
using System.Threading.Tasks;

class C
{
    async Task Run()
    {
        await Task.Delay(1);
    }

    async Task<int> Count()
    {
        await Task.Delay(1);

        return 1;
    }

    async ValueTask Wait()
    {
        await Task.Delay(1);
    }

    void Plain()
    {
        void Local()
        {
        }

        Action a = () => Local();
    }
}
```

is not reported.

### RH2002-005 — The diagnostic is on the name, or on `async` of an anonymous function

The analyzer MUST report one diagnostic per reported function, located on the identifier of a method or local function, and on the `async` keyword of an anonymous function.

Why: A method and a local function are found by their name; an anonymous function has none, and its `async` keyword is what makes it an async void function.

Example: see RH2002-001 to RH2002-003.
