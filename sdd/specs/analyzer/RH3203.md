# Analyzer — RH3203 Expression style constructors should not be used

| | |
|---|---|
| ID prefix | RH3203 |
| Status | Active |
| Category | Clarity |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH3203ExpressionStyleConstructorsShouldNotBeUsedAnalyzer`, `RH3203ExpressionStyleConstructorsShouldNotBeUsedCodeFixProvider` |
| Uses | SHARED-BODY-001, SHARED-BODY-002, SHARED-BODY-003, FMT-STRUCT-005 |

RH3203 reports an expression-bodied constructor and offers a code fix that converts it to a block body, as the formatter does under FMT-STRUCT-005. Which constructors are left alone, where the diagnostic is, and what the fix produces are SHARED-BODY-001, SHARED-BODY-002, and SHARED-BODY-003.

## Non-goals

- Expression-bodied methods (RH3202), operators (RH3205), conversion operators (RH3206), finalizers (RH3207), and local functions (RH3208).

## Requirements

### RH3203-001 — Every expression-bodied constructor is reported

The analyzer MUST report every constructor declaration that has an expression body — instance or static, with or without a constructor initializer — unless SHARED-BODY-001 applies. A constructor with a block body MUST NOT be reported.

Why: The house style uses block bodies for constructors, as for methods; the other function kinds have rules of their own, so each kind can be configured separately.

Example:

```csharp
class B
{
    public B(int v)
    {
    }
}

class C : B
{
    private int _value;
    private static int s_count;

    static C() {|RH3203:=> s_count = 1|};

    public C(int value) : base(value) {|RH3203:=> _value = value|};

    public C() : this(0)
    {
    }
}
```
