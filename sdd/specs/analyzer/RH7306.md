# Analyzer — RH7306 Region descriptions should not end with implementation

| | |
|---|---|
| ID prefix | RH7306 |
| Status | Active |
| Category | Organization |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH7306RegionDescriptionsShouldNotEndWithImplementationAnalyzer`, `RH7306RegionDescriptionsShouldNotEndWithImplementationCodeFixProvider` |
| Uses | RH7301-005, SHARED-REGDESC-001, SHARED-REGDESC-002 |

RH7306 reports a `#region` or `#endregion` whose description ends with the word `implementation`, and offers a code fix that removes the word from the region's directives.

## Non-goals

- What the description of a region directive is, and which directives are checked — SHARED-REGDESC-001, SHARED-REGDESC-002.
- Whether the `#region` and `#endregion` descriptions agree — RH7301.
- Other words that add nothing to a region name, such as `Member` — RH7307.

## Requirements

### RH7306-001 — A description ending with the word `implementation` is reported

The analyzer MUST report every region directive whose description (SHARED-REGDESC-001) ends with the word `implementation` in any casing, where the word is either the whole description or preceded by whitespace. It MUST check and report the directives as SHARED-REGDESC-002 specifies.

Why: A region named after an interface or a base type already says that it holds that type's implementation; the trailing word makes the name longer without telling the reader anything.

Example:

```csharp
class C
{
    {|RH7306:#region IDisposable implementation|}

    int _a;

    #endregion

    {|RH7306:#region Implementation|}

    int _b;

    {|RH7306:#endregion // IComparable IMPLEMENTATION|}
}
```

### RH7306-002 — The word inside or before other text is not reported

The analyzer MUST NOT report a description in which `implementation` is part of a longer word or is followed by other text.

Why: Only the trailing, stand-alone word is filler; `Reimplementation` or `Implementation details` name something.

Example:

```csharp
class C
{
    #region Reimplementation

    int _a;

    #endregion // Reimplementation

    #region IDisposable implementation details

    int _b;

    #endregion // IDisposable implementation details
}
```

is not reported.

### RH7306-003 — The fix removes the trailing word

For a description that has text before the trailing word, the code fix MUST remove the word and the whitespace in front of it from the line of the reported directive, and from the line of the directive it pairs with when that line ends with the word as well. It MUST change nothing else.

Why: Removing the word is the whole correction, and doing it on both directives keeps the pair agreeing, so RH7301 does not report the result. A directive that does not end with the word is left as written.

Example:

```csharp
class C
{
    {|RH7306:#region IDisposable implementation|}

    int _a;

    {|RH7306:#endregion // IDisposable implementation|}

    {|RH7306:#region IComparable implementation|}

    int _b;

    #endregion

    #region ICloneable

    int _c;

    {|RH7306:#endregion ICloneable Implementation|}
}
```

```csharp
class C
{
    #region IDisposable

    int _a;

    #endregion // IDisposable

    #region IComparable

    int _b;

    #endregion

    #region ICloneable

    int _c;

    #endregion ICloneable
}
```

### RH7306-004 — The fix is withheld when nothing remains of the description

The code fix MUST NOT be offered for a reported directive whose description is the word `implementation` alone, in any casing. The diagnostic is still reported.

Why: Removing the word would leave a region without a name, or an `#endregion` comment without text. Which name the region should have is the user's decision, as it is when RH7301-005 withholds its fix for a region without a description.

Example:

```csharp
class C
{
    {|RH7306:#region Implementation|}

    int _a;

    {|RH7306:#endregion // Implementation|}

    #region IDisposable

    int _b;

    {|RH7306:#endregion //Implementation|}
}
```

is reported, and no code fix is offered.
