# Analyzer — RH4005 Interface name casing

| | |
|---|---|
| ID prefix | RH4005 |
| Status | Active |
| Category | Naming |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH4005InterfaceNameCasingAnalyzer`, `RH4005InterfaceNameCasingCodeFixProvider` |
| Uses | SHARED-CASING-001, SHARED-CASING-006, SHARED-CASING-007, SHARED-CASING-008, SHARED-CASING-009, SHARED-CASING-010 |

RH4005 reports an interface whose name is not an `I` followed by a PascalCase name, and offers a code fix that renames the interface and every reference to it.

## Non-goals

- Class, struct, enum, and delegate names — RH4002, RH4003, RH4004, and RH4006.

## Requirements

### RH4005-001 — Interface names are `I` followed by PascalCase

The analyzer MUST report every interface declaration whose name is not accepted. A name MUST be accepted exactly when it has at least two characters, its first character is `I`, its second character is an uppercase letter, and the whole name is in PascalCase as SHARED-CASING-001 defines it. The diagnostic MUST be located on the interface's identifier.

Why: The `I` prefix tells a reader in every signature and base list that the type is an interface. The uppercase letter after it separates the prefix from a name that merely starts with an I, such as `Index`.

Example:

```csharp
public interface IDocumentReader
{
}

public interface IHTTPClient
{
}

public interface IRepository<T>
{
}

public interface {|RH4005:iDocumentWriter|}
{
}

public interface {|RH4005:DocumentStore|}
{
}

public interface {|RH4005:Index|}
{
}

public interface {|RH4005:IOrder_Line|}
{
}

public interface {|RH4005:I|}
{
}
```

### RH4005-002 — The fix keeps an existing prefix and adds a missing one

The code fix MUST derive the new name as follows. When the old name starts with `i` or `I` followed by an uppercase letter, that first letter is the prefix and is dropped. When the old name starts with any other character than `i` or `I`, or with `i` or `I` followed by a lowercase letter, nothing is dropped. The rest is converted to the PascalCase name that SHARED-CASING-006 derives, and `I` is put in front of it. The fix MUST rename the interface and every reference to it (SHARED-CASING-007); it is withheld as SHARED-CASING-008 and SHARED-CASING-009 specify, and its Fix All skips colliding names as SHARED-CASING-010 specifies.

Why: A name such as `iDocumentReader` already carries the prefix in the wrong case; only the case is corrected. A name such as `index` or `Item` starts with a word, not with a prefix, so the prefix is added in front of the whole word.

Example:

```csharp
public interface {|RH4005:iDocumentReader|}
{
}

public interface {|RH4005:Repository|}<T>
{
}

public interface {|RH4005:index|}
{
}

public interface {|RH4005:Item|}
{
}

public interface {|RH4005:IOrder_Line|}
{
}
```

```csharp
public interface IDocumentReader
{
}

public interface IRepository<T>
{
}

public interface IIndex
{
}

public interface IItem
{
}

public interface IOrderLine
{
}
```
