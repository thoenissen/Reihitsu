# Analyzer — RH4111 Private property casing

| | |
|---|---|
| ID prefix | RH4111 |
| Status | Active |
| Category | Naming |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH4111PrivatePropertyCasingAnalyzer`, `RH4111PrivatePropertyCasingCodeFixProvider` |
| Uses | SHARED-CASING-001, SHARED-CASING-004, SHARED-CASING-006, SHARED-CASING-007, SHARED-CASING-008, SHARED-CASING-009, SHARED-CASING-010 |

RH4111 reports a private property whose name is not in PascalCase and offers a code fix that renames the property and every reference to it.

## Non-goals

- Properties of the protected, internal, and public groups — RH4112, RH4113, and RH4114.
- The properties that a record's primary constructor declares — RH4120.
- Names of fields — RH4106 to RH4110.

## Requirements

### RH4111-001 — Private property names are in PascalCase

The analyzer MUST report every property declaration that belongs to the private group of SHARED-CASING-004 and whose name is not in PascalCase as SHARED-CASING-001 defines it. Static properties and expression-bodied properties MUST be checked too. The analyzer MUST report one diagnostic per property, located on its identifier.

Why: A property is read like a member of the type at every use, whatever its accessibility, so it is named like the other members. Keeping the style independent of the accessibility also means that making a property more visible later does not require renaming it.

Example:

```csharp
public class C
{
    private int {|RH4111:count|} { get; set; }
    int {|RH4111:total|} => 0;
    private static int {|RH4111:cache_size|} { get; set; }
    private int Limit { get; set; }
    private protected int offset { get; set; }
    protected internal int scale { get; set; }
}

public struct S
{
    int {|RH4111:value|} { get; set; }
}

public interface I
{
    private int {|RH4111:hidden|} => 0;
}
```

### RH4111-002 — The fix renames the property to PascalCase

The code fix MUST rename the property and every reference to it (SHARED-CASING-007) to the PascalCase name that SHARED-CASING-006 derives from its old name. It is withheld as SHARED-CASING-008 and SHARED-CASING-009 specify, and its Fix All skips colliding names as SHARED-CASING-010 specifies. This requirement covers the renames that SHARED-CASING-007 covers.

Why: The fix makes exactly the change the diagnostic asks for, and a property is referenced throughout its type.

Example:

```csharp
public class C
{
    private int {|RH4111:count|} { get; set; }

    private int {|RH4111:max_size|} => 10;

    public int Sum => count + max_size;
}
```

```csharp
public class C
{
    private int Count { get; set; }

    private int MaxSize => 10;

    public int Sum => Count + MaxSize;
}
```
