# Analyzer — RH4108 Internal field casing

| | |
|---|---|
| ID prefix | RH4108 |
| Status | Active |
| Category | Naming |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH4108InternalFieldCasingAnalyzer`, `RH4108InternalFieldCasingCodeFixProvider` |
| Uses | SHARED-CASING-001, SHARED-CASING-004, SHARED-CASING-006, SHARED-CASING-007, SHARED-CASING-008, SHARED-CASING-009, SHARED-CASING-010 |

RH4108 reports an internal field whose name is not in PascalCase and offers a code fix that renames the field and every reference to it.

## Non-goals

- `const` fields of any accessibility — RH4110.
- Fields of the private, protected, and public groups — RH4106, RH4107, and RH4109.
- Whether a field should be internal at all — RH2005.

## Requirements

### RH4108-001 — Internal field names are in PascalCase

The analyzer MUST report every variable declarator of a field declaration that is not `const`, belongs to the internal group of SHARED-CASING-004, and whose name is not in PascalCase as SHARED-CASING-001 defines it. Static and readonly fields MUST be checked too. The analyzer MUST report one diagnostic per declarator, located on its identifier.

Why: An internal field is used by other types of the assembly like any other member, so it is named like one.

Example:

```csharp
public class C
{
    internal int CacheCount;
    internal int {|RH4108:itemCount|}, {|RH4108:pageSize|};
    internal readonly int {|RH4108:cacheLimit|} = 10;
    protected internal int {|RH4108:retryLimit|};
    internal const int limit = 2;
    int cacheValue;
}
```

### RH4108-002 — The fix renames the field to PascalCase

The code fix MUST rename the field and every reference to it (SHARED-CASING-007) to the PascalCase name that SHARED-CASING-006 derives from its old name. It is withheld as SHARED-CASING-008 and SHARED-CASING-009 specify, and its Fix All skips colliding names as SHARED-CASING-010 specifies. This requirement covers the renames that SHARED-CASING-007 covers.

Why: The fix makes exactly the change the diagnostic asks for, and a field is referenced wherever the assembly uses it.

Example:

```csharp
public class Registry
{
    internal int {|RH4108:itemCount|};
    internal int {|RH4108:page_size|} = 10;

    public int Total => itemCount * page_size;
}
```

```csharp
public class Registry
{
    internal int ItemCount;
    internal int PageSize = 10;

    public int Total => ItemCount * PageSize;
}
```
