# Analyzer — RH4012 Union name casing

| | |
|---|---|
| ID prefix | RH4012 |
| Status | Active |
| Category | Naming |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH4012UnionNameCasingAnalyzer`, `RH4012UnionNameCasingCodeFixProvider` |
| Uses | SHARED-CASING-001, SHARED-CASING-006, SHARED-CASING-007, SHARED-CASING-008, SHARED-CASING-009, SHARED-CASING-010 |

RH4012 reports a union whose name is not in PascalCase and offers a code fix that renames the union and every reference to it.

## Non-goals

- Class, struct, interface, enum, delegate, record, and record struct names — RH4002, RH4003, RH4005, RH4004, RH4006, RH4010, and RH4011.
- The names of a union's type parameters — RH4121. A union's case types are types, not names, and are not checked.
- Whether the union name matches the file name — RH4001.

## Requirements

### RH4012-001 — Union names are in PascalCase

The analyzer MUST report every union declaration, written with the `union` keyword, whose name is not in PascalCase as SHARED-CASING-001 defines it, whatever its modifiers, type parameters, case types, or nesting. The diagnostic MUST be located on the union's identifier, without its type parameter list and its case types.

Why: A union is a type, and its name is part of every signature that uses it; PascalCase is how .NET spells type names, and a reader recognizes a type by it. A union has a rule of its own, as every other type kind has, so a project can configure it on its own.

Example:

```csharp
public union Shape(int, string);

public union {|RH4012:pet|}(int, string);

public union {|RH4012:result|}<T>(T, string);

public class Outer
{
    private union {|RH4012:inner_value|}(int, string);
}

public struct point
{
}
```

`point` is a struct, which RH4003 checks, not RH4012.

### RH4012-002 — The fix renames the union to PascalCase

The code fix MUST rename the union and every reference to it (SHARED-CASING-007) to the PascalCase name that SHARED-CASING-006 derives from its old name. It is withheld as SHARED-CASING-008 and SHARED-CASING-009 specify, and its Fix All skips colliding names as SHARED-CASING-010 specifies. This requirement covers the renames that SHARED-CASING-007 covers.

Why: The fix makes exactly the change the diagnostic asks for, and a union is referenced wherever its type is used.

Example:

```csharp
public union {|RH4012:pet|}(int, string);

public union {|RH4012:shape_kind|}(pet, long);

public class C
{
    private pet _value;
}
```

```csharp
public union Pet(int, string);

public union ShapeKind(Pet, long);

public class C
{
    private Pet _value;
}
```
