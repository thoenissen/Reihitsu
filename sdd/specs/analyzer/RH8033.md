# Analyzer — RH8033 Extension declaration type parameters must be documented

| | |
|---|---|
| ID prefix | RH8033 |
| Status | Active |
| Category | Documentation |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH8033ExtensionDeclarationTypeParametersMustBeDocumentedAnalyzer` |
| Uses | SHARED-DOC-008, SHARED-DOC-011, SHARED-DOC-012 |

RH8033 reports a type parameter of a documented generic extension declaration that has no matching `<typeparam>` documentation.

## Non-goals

- Whether the extension declaration has a summary — RH8031; its parameter — RH8032.
- The type parameters of types, methods, and delegates, including the members of an extension block — RH8108.
- Whether the `<typeparam>` description has text — RH8111.

## Requirements

### RH8033-001 — An undocumented type parameter of an extension declaration is reported

The analyzer MUST report each type parameter of a generic extension declaration — `extension<…>(…)` — that is not documented as SHARED-DOC-012 specifies, unless SHARED-DOC-011 exempts the declaration. An extension declaration without type parameters MUST NOT be reported. Nothing is reported when SHARED-DOC-008 applies.

This requirement covers what SHARED-DOC-011 and SHARED-DOC-012 cover.

Why: A type parameter such as `T` says nothing about what may be substituted for it, and on an extension declaration that answer governs every member of the block. Without a description, a caller who guesses wrong learns it from a compiler error instead of from the documentation.

Example:

```csharp
using System.Collections.Generic;

/// <summary>
/// Extensions
/// </summary>
public static class Extensions
{
    /// <summary>
    /// Adds helpers to sequences
    /// </summary>
    /// <param name="values">Values</param>
    extension<{|RH8033:T|}>(IEnumerable<T> values)
    {
    }

    /// <summary>
    /// Adds helpers to lists
    /// </summary>
    /// <typeparam name="T">Element</typeparam>
    /// <param name="values">Values</param>
    extension<T>(List<T> values)
    {
    }

    /// <summary>
    /// Adds helpers to text values
    /// </summary>
    /// <param name="value">Value</param>
    extension(string value)
    {
    }
}
```

### RH8033-002 — The diagnostic is on the type parameter name

The analyzer MUST report one diagnostic per undocumented type parameter, located on its identifier.

Why: The name is what the `<typeparam>` element has to repeat, so marking it shows which type parameter is missing.

Example: see RH8033-001.
