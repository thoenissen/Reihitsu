# Analyzer — RH5412 Empty classes should use semicolon declarations

| | |
|---|---|
| ID prefix | RH5412 |
| Status | Active |
| Category | Layout |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH5412EmptyClassesShouldUseSemicolonDeclarationsAnalyzer`, `RH5412EmptyClassesShouldUseSemicolonDeclarationsCodeFixProvider` |
| Uses | SHARED-DIAG-011, SHARED-EMPTY-001, SHARED-EMPTY-002, SHARED-EMPTY-003, SHARED-EMPTY-004 |

RH5412 reports a class declaration with an empty brace body from C# 12 on, and offers a code fix that replaces the braces with a semicolon as SHARED-EMPTY-003 specifies, unless SHARED-EMPTY-004 withholds it.

## Non-goals

- Empty structs — RH5413; interfaces — RH5414; records — RH5415; record structs — RH5416.

## Requirements

### RH5412-001 — An empty class is reported from C# 12 on

The analyzer MUST report a class declaration as SHARED-EMPTY-001 and SHARED-EMPTY-002 specify when the project's C# version is 12 or later. Below C# 12 it MUST NOT report a class.

Why: C# 12 is the first version in which a class can be declared with a semicolon instead of a body; below it, the braces are the only way to write an empty class, so the rule does not ask for the semicolon there (SHARED-DIAG-011).

Example:

```csharp
class {|RH5412:A|}
{
}

static class {|RH5412:B|}
{
}
```

Under C# 11, neither class is reported.
