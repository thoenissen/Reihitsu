# Analyzer — RH5037 Comments must not be placed before a continuation clause

| | |
|---|---|
| ID prefix | RH5037 |
| Status | Active |
| Category | Layout |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH5037CommentsMustNotBePlacedBeforeContinuationClauseAnalyzer` |
| Uses | SHARED-COMMENT-001, SHARED-COMMENT-002, SHARED-COMMENT-003 |

RH5037 reports a comment placed directly before `else`, `catch`, `finally`, or the `while` of a `do` loop.

## Non-goals

- A comment between a statement header and its body — RH5036.

## Requirements

### RH5037-001 — A comment before a continuation keyword is reported

The analyzer MUST report every ordinary comment (SHARED-COMMENT-001, SHARED-COMMENT-002) directly before the `else` keyword of an `if` statement, the `catch` keyword of a catch clause, the `finally` keyword, or the `while` keyword of a `do` statement, as SHARED-COMMENT-003 specifies, whether it stands on a line of its own or behind the code before the keyword. A comment inside the clause's body, after the keyword, or before a statement that follows the whole statement MUST NOT be reported.

Why: A continuation clause belongs to the statement before it. A comment in front of it separates the clause from that statement and reads as a comment on the previous block.

Example:

```csharp
using System;

class C
{
    void M(bool a)
    {
        if (a)
        {
        } {|RH5037:// otherwise|}
        else if (!a)
        {
        }

        try
        {
        }
        {|RH5037:// on failure|}
        catch (Exception)
        {
        }
        {|RH5037:// cleanup|}
        finally
        {
        }

        do
        {
        }
        {|RH5037:// condition|}
        while (a);
    }
}
```

```csharp
class C
{
    int Run(params object[] values) => 0;

    void M(bool a)
    {
        if (a)
        {
        }
        else
        {
            // otherwise
            Run();
        }

        // next
        Run();
    }
}
```

is not reported.
