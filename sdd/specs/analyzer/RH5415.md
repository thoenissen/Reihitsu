# Analyzer — RH5415 Empty records should use semicolon declarations

| | |
|---|---|
| ID prefix | RH5415 |
| Status | Active |
| Category | Layout |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH5415EmptyRecordsShouldUseSemicolonDeclarationsAnalyzer`, `RH5415EmptyRecordsShouldUseSemicolonDeclarationsCodeFixProvider` |
| Uses | SHARED-EMPTY-001, SHARED-EMPTY-002, SHARED-EMPTY-003, SHARED-EMPTY-004 |

RH5415 reports a record declaration — a record class — with an empty brace body from C# 9 on, and offers a code fix that replaces the braces with a semicolon as SHARED-EMPTY-003 specifies, unless SHARED-EMPTY-004 withholds it.

## Non-goals

- Empty record structs — RH5416; classes — RH5412; structs — RH5413; interfaces — RH5414.

## Requirements

### RH5415-001 — An empty record is reported from C# 9 on

The analyzer MUST report a record declaration, written as `record` or as `record class`, with or without a parameter list, as SHARED-EMPTY-001 and SHARED-EMPTY-002 specify when the project's C# version is 9 or later. Below C# 9 it MUST NOT report a record. A record struct MUST NOT be reported by this rule.

Why: Records and their semicolon declaration both exist from C# 9 on. A positional record declares its members through its parameter list, so its body is often empty. A record struct is a struct, which RH5416 checks.

Example:

```csharp
record {|RH5415:A|}
{
}

record class {|RH5415:B|}(int Value)
{
}

record struct C
{
}
```

Under C# 8, `A` is not reported.
