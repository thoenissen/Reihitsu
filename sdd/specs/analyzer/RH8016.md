# Analyzer — RH8016 Private delegates must be documented

| | |
|---|---|
| ID prefix | RH8016 |
| Status | Active |
| Category | Documentation |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH8016PrivateDelegatesMustBeDocumentedAnalyzer` |
| Uses | SHARED-DOC-001, SHARED-DOC-002, SHARED-DOC-004, SHARED-DOC-005, SHARED-DOC-006, SHARED-DOC-007, SHARED-DOC-008 |

RH8016 reports a delegate in the private group that has no `<summary>` or `<inheritdoc>` documentation.

## Non-goals

- Delegates in the non-private group — RH8015.
- Whether the summary has text — RH8030; the documentation of parameters, the return value, and type parameters — RH8101, RH8105, and RH8108.

## Requirements

### RH8016-001 — Undocumented private delegates are reported

The analyzer MUST report every delegate declaration in the private group of SHARED-DOC-002 that is not documented, checked as SHARED-DOC-001 specifies. Generic delegates are delegate declarations too. Whether it is documented MUST be decided as SHARED-DOC-004, SHARED-DOC-005, SHARED-DOC-006, and SHARED-DOC-007 specify, and nothing is reported when SHARED-DOC-008 applies.

Why: A private delegate is an implementation detail of its type, but the next maintainer still has to know what it is for. It has a rule of its own, so a project can require documentation for what other code uses without requiring it here.

Example:

```csharp
/// <summary>
/// Outer
/// </summary>
public class Outer
{
    private delegate void {|RH8016:Hidden|}(int value);

    /// <remarks>
    /// No summary
    /// </remarks>
    delegate T {|RH8016:Factory|}<T>();

    /// <summary>
    /// Documented
    /// </summary>
    private delegate void Documented();

    internal delegate void Visible();
}
```

### RH8016-002 — The diagnostic is on the delegate name

The analyzer MUST report one diagnostic per undocumented delegate declaration, located on its identifier, without its type parameter list.

Why: The name is what the documentation describes; marking it identifies the declaration without marking its whole body.

Example: see RH8016-001.
