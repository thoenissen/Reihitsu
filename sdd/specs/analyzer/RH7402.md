# Analyzer — RH7402 Override properties should be grouped by base type regions

| | |
|---|---|
| ID prefix | RH7402 |
| Status | Active |
| Category | Organization |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH7402OverridePropertiesShouldBeGroupedByBaseTypeRegionsAnalyzer` |
| Uses | SHARED-REGGROUP-001, SHARED-REGGROUP-002, SHARED-REGGROUP-003, SHARED-REGGROUP-004, SHARED-REGGROUP-006 |

RH7402 reports an override property that does not lie in a top-level region named after the type that introduced the property. It has no code fix.

## Non-goals

- Override methods, events, and indexers — RH7401, RH7403, RH7404.
- A property that overrides nothing but lies in a region named after a base type — RH7406.
- An interface implementation that is not an override — RH7410.

## Requirements

### RH7402-001 — An override property outside its base type's region is reported

In every type declaration it checks (SHARED-REGGROUP-001), the analyzer MUST report each property declaration that overrides a property when the property does not lie (SHARED-REGGROUP-002) in a top-level region whose name matches (SHARED-REGGROUP-003) the type it comes from (SHARED-REGGROUP-004) — whether it lies in a region of another name or in no region. This holds also for an override that implements an interface property. The diagnostic MUST be placed as SHARED-REGGROUP-006 specifies.

Why: Overrides are easier to scan when they are grouped by the type that introduced them; a generic region name such as `Properties` hides that relationship. An override that also implements an interface property is still an override of its base type, so it is grouped there.

Example:

```csharp
interface INamed
{
    string Name { get; }
}

abstract class B
{
    public abstract string Name { get; }

    public virtual int Size => 0;

    public virtual int Count => 0;
}

class C : B, INamed
{
    #region INamed

    public override string {|RH7402:Name|} => "";

    #endregion

    #region Properties

    public override int {|RH7402:Size|} => 1;

    #endregion

    public override int {|RH7402:Count|} => 1;
}
```

while an override in the region named after its base type:

```csharp
class B
{
    public virtual int P => 0;
}

class C : B
{
    #region B

    public override int P => 1;

    #endregion
}
```

is not reported.

### RH7402-002 — Other members are not reported

The analyzer MUST NOT report a property that overrides nothing, and MUST NOT report an override method, indexer, or event.

Why: A property that overrides nothing has no base type to be grouped by, and the other override kinds have rules of their own; an indexer is not a property declaration, even though it is a property of the type.

Example:

```csharp
class B
{
    public virtual void M()
    {
    }

    public virtual int this[int i] => 0;
}

class C : B
{
    public override void M()
    {
    }

    public override int this[int i] => 1;

    public int P => 0;
}
```

is not reported.
