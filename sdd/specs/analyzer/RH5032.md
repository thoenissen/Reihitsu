# Analyzer — RH5032 Region directives should be followed by a blank line

| | |
|---|---|
| ID prefix | RH5032 |
| Status | Active |
| Category | Layout |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH5032RegionDirectivesShouldBeFollowedByABlankLineAnalyzer`, `RH5032RegionDirectivesShouldBeFollowedByABlankLineCodeFixProvider` |
| Uses | SHARED-BLANK-006, SHARED-BLANK-007, SHARED-REGION-001, SHARED-REGION-002 |

RH5032 reports a `#region` or `#endregion` directive whose line below is not blank, and offers a code fix that inserts the blank line as SHARED-REGION-002 specifies.

## Non-goals

- The blank line above a region directive — RH5031.
- A blank line directly before a closing brace — RH5024.

## Requirements

### RH5032-001 — A region directive needs a blank line below it

The analyzer MUST report an active `#region` or `#endregion` directive whose line directly below is not blank, as SHARED-BLANK-006 and SHARED-BLANK-007 specify.

Why: The blank line below the directive separates the section header or footer from the code it frames.

Example:

```csharp
class C
{
    {|RH5032:#region Fields|}
    private int _x;

    {|RH5032:#endregion // Fields|}
    int _a;

    {|RH5032:#region Methods|}
    void M()
    {
    }

    #endregion // Methods
}
```

The last `#endregion` is followed by the closing brace and is not reported, and neither is an `#endregion` on the last line of the file:

```csharp
class C
{
    int _a;

    #region R

    int _b;
}
#endregion
```

### RH5032-002 — The diagnostic is on the directive

The analyzer MUST report the diagnostic on the directive's text as SHARED-REGION-001 specifies.

Why: The diagnostic points at the region boundary that needs the separator.

Example: see RH5032-001.

### RH5032-003 — The fix inserts the blank line below the directive

The code fix MUST insert one empty line directly below the reported directive as SHARED-REGION-002 specifies.

Why: The empty line is exactly the separator the rule asks for, and nothing else needs to change.

Example:

```csharp
class C
{
    {|RH5032:#region Fields|}
    private int _x;

    {|RH5032:#endregion // Fields|}
    int _a;

    {|RH5032:#region Methods|}
    void M()
    {
    }

    #endregion // Methods
}
```

```csharp
class C
{
    #region Fields

    private int _x;

    #endregion // Fields

    int _a;

    #region Methods

    void M()
    {
    }

    #endregion // Methods
}
```
