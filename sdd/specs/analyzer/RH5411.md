# Analyzer — RH5411 Final collection initializer items must not have trailing commas

| | |
|---|---|
| ID prefix | RH5411 |
| Status | Active |
| Category | Layout |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH5411FinalCollectionInitializerItemsMustNotHaveTrailingCommasAnalyzer`, `RH5411FinalCollectionInitializerItemsMustNotHaveTrailingCommasCodeFixProvider` |
| Uses | SHARED-TRAIL-001, SHARED-TRAIL-002, SHARED-TRAIL-003 |

RH5411 reports a comma after the last element of a collection initializer, and offers a code fix that removes it as SHARED-TRAIL-003 specifies.

## Non-goals

- Trailing commas in enum declarations — RH5409; in array initializers — RH5410.
- Trailing commas in object initializers, anonymous object creations, and collection expressions (SHARED-TRAIL non-goals).

## Requirements

### RH5411-001 — A comma after the last collection element is reported

The analyzer MUST report the comma after the last element of a collection initializer as SHARED-TRAIL-001 and SHARED-TRAIL-002 specify: the initializer of an object creation (`new List<int> { … }`), of a target-typed object creation (`new() { … }`), and a collection initializer nested in an object initializer (`L = { … }`). An element written as a braced list of arguments, such as `{ 1, 2 }` of a dictionary, counts as one element.

Why: A collection initializer lists the elements added to the collection; a comma behind the last one suggests an element that does not exist.

Example:

```csharp
using System.Collections.Generic;

class D
{
    public List<int> L { get; } = new List<int>();
}

class C
{
    List<int> _a = new List<int> { 1, 2{|RH5411:,|} };
    List<int> _b = new() { 1{|RH5411:,|} };
    Dictionary<int, int> _c = new Dictionary<int, int> { { 1, 2 }, { 3, 4 }{|RH5411:,|} };
    D _d = new D { L = { 1, 2{|RH5411:,|} } };
}
```

### RH5411-002 — Other initializers are not reported

The analyzer MUST NOT report a trailing comma in an array initializer, an object initializer — one that assigns indexers (`[1] = 2`) included —, or a collection expression.

Why: These lists are not collection initializers. An array initializer is RH5410's; for the others no rule decides about the trailing comma (see the non-goals).

Example:

```csharp
using System.Collections.Generic;

class D
{
    public int P { get; set; }
}

class C
{
    int[] _a = { 1, 2, };
    D _b = new D { P = 1, };
    Dictionary<int, int> _c = new Dictionary<int, int> { [1] = 2, };
    List<int> _d = [1, 2,];
}
```

is not reported.
