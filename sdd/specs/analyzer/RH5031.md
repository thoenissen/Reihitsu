# Analyzer — RH5031 Region directives should be preceded by a blank line

| | |
|---|---|
| ID prefix | RH5031 |
| Status | Active |
| Category | Layout |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH5031RegionDirectivesShouldBePrecededByABlankLineAnalyzer`, `RH5031RegionDirectivesShouldBePrecededByABlankLineCodeFixProvider` |
| Uses | SHARED-BLANK-005, SHARED-BLANK-007, SHARED-REGION-001, SHARED-REGION-002 |

RH5031 reports a `#region` or `#endregion` directive whose line above is not blank, and offers a code fix that inserts the blank line as SHARED-REGION-002 specifies.

## Non-goals

- The blank line below a region directive — RH5032.
- A blank line directly after an opening brace — RH5022.

## Requirements

### RH5031-001 — A region directive needs a blank line above it

The analyzer MUST report an active `#region` or `#endregion` directive whose line directly above is not blank, as SHARED-BLANK-005 and SHARED-BLANK-007 specify.

Why: A region marks a section boundary in the file; without a blank line above it the directive merges with the code of the section before it.

Example:

```csharp
class C
{
    #region Fields
    private int _x;
    {|RH5031:#endregion // Fields|}
    int _a;
    // header
    {|RH5031:#region R|}

    int _b;

    #endregion // R
}
```

The first `#region` follows the opening brace and is not reported. In

```csharp
class C
{ // trailing
    {|RH5031:#region R|}
    int _x;

    #endregion // R
#if NEVER
    int _y;
    #region D
    int _z;
    #endregion
#endif
}
```

the trailing comment removes the brace exemption, and the directives inside the skipped `#if` branch are not reported.

### RH5031-002 — The diagnostic is on the directive

The analyzer MUST report the diagnostic on the directive's text as SHARED-REGION-001 specifies.

Why: The diagnostic points at the region boundary that needs the separator.

Example: see RH5031-001.

### RH5031-003 — The fix inserts the blank line above the directive

The code fix MUST insert one empty line directly above the reported directive as SHARED-REGION-002 specifies.

Why: The empty line is exactly the separator the rule asks for, and nothing else needs to change.

Example:

```csharp
class C
{ // trailing
    {|RH5031:#region R|}
    int _x;
    {|RH5031:#endregion // R|}
}
```

```csharp
class C
{ // trailing

    #region R
    int _x;

    #endregion // R
}
```
