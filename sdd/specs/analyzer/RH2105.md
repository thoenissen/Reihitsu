# Analyzer — RH2105 Nested interfaces should not be used

| | |
|---|---|
| ID prefix | RH2105 |
| Status | Active |
| Category | Design |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH2105NestedInterfacesShouldNotBeUsedAnalyzer` |
| Uses | SHARED-NESTED-001, SHARED-NESTED-002 |

RH2105 reports an interface declared inside another type.

## Non-goals

- Nested classes, structs, records, enums, and delegates — RH2101, RH2104, RH2106, RH2107, and RH2108.

## Requirements

### RH2105-001 — A nested interface is reported

The analyzer MUST report an interface declaration that is nested as SHARED-NESTED-001 defines it, located as SHARED-NESTED-002 specifies, including an interface nested in another interface.

Why: An interface inside another type is easy to miss and ties every implementation to the containing type. A top-level interface is easier to find, review, and implement.

Example:

```csharp
class Outer
{
    interface {|RH2105:IHandler|}
    {
    }
}

interface IContainer
{
    interface {|RH2105:IPart|}
    {
    }
}
```
