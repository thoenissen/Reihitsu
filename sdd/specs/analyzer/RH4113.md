# Analyzer — RH4113 Internal property casing

| | |
|---|---|
| ID prefix | RH4113 |
| Status | Active |
| Category | Naming |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH4113InternalPropertyCasingAnalyzer`, `RH4113InternalPropertyCasingCodeFixProvider` |
| Uses | SHARED-CASING-001, SHARED-CASING-004, SHARED-CASING-006, SHARED-CASING-007, SHARED-CASING-008, SHARED-CASING-009, SHARED-CASING-010 |

RH4113 reports an internal property whose name is not in PascalCase and offers a code fix that renames the property and every reference to it.

## Non-goals

- Properties of the private, protected, and public groups — RH4111, RH4112, and RH4114.
- Names of fields — RH4106 to RH4110.

## Requirements

### RH4113-001 — Internal property names are in PascalCase

The analyzer MUST report every property declaration that belongs to the internal group of SHARED-CASING-004 and whose name is not in PascalCase as SHARED-CASING-001 defines it. Static, expression-bodied, virtual, and abstract properties, and overrides whose original definition is declared in source, MUST be checked too. The analyzer MUST report one diagnostic per property declaration, located on its identifier, so each part of a partial property gets its own diagnostic.

This requirement covers a property whose original definition is declared in source: following the properties it overrides, through every level, and the interface properties it implicitly implements never leads to a property declared in a referenced assembly.

Why: An internal property is used throughout the assembly and is read like any other member of the type, so it is named like the other members.

Example:

```csharp
public class C
{
    internal int {|RH4113:count|} { get; set; }
    protected internal int {|RH4113:scale|} { get; set; }
    internal static int {|RH4113:instance_count|} => 0;
    internal int Limit { get; set; }
    private protected int offset { get; set; }
    int total { get; set; }
}
```

Example — a partial property, reported on each part:

```csharp
public partial class C
{
    internal partial int {|RH4113:count|} { get; }
}

public partial class C
{
    internal partial int {|RH4113:count|} => 0;
}
```

### RH4113-002 — The fix renames the property to PascalCase

The code fix MUST rename the property and every reference to it (SHARED-CASING-007) to the PascalCase name that SHARED-CASING-006 derives from its old name. Renaming a property also renames, in source, the properties it overrides and the properties that override it. It is withheld as SHARED-CASING-008 and SHARED-CASING-009 specify, and its Fix All skips colliding names as SHARED-CASING-010 specifies. This requirement covers the renames that SHARED-CASING-007 covers, for the properties that RH4113-001 covers. It further covers only a property whose name is not also the name of a parameter of its record's primary constructor.

Why: The fix makes exactly the change the diagnostic asks for, and an internal property is referenced anywhere in its assembly.

Example:

```csharp
public class Settings
{
    internal int {|RH4113:retry_count|} { get; set; }

    protected internal int {|RH4113:timeout|} => 0;

    public int Sum => retry_count + timeout;
}
```

```csharp
public class Settings
{
    internal int RetryCount { get; set; }

    protected internal int Timeout => 0;

    public int Sum => RetryCount + Timeout;
}
```

Example — an override in source:

```csharp
public class BaseStore
{
    internal virtual int {|RH4113:row_count|} => 0;
}

public class FileStore : BaseStore
{
    internal override int {|RH4113:row_count|} => 1;
}
```

```csharp
public class BaseStore
{
    internal virtual int RowCount => 0;
}

public class FileStore : BaseStore
{
    internal override int RowCount => 1;
}
```
