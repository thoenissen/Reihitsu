# Analyzer — RH5038 Comments must not be placed inside an argument list

| | |
|---|---|
| ID prefix | RH5038 |
| Status | Active |
| Category | Layout |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH5038CommentsMustNotBePlacedInsideArgumentListAnalyzer` |
| Uses | SHARED-COMMENT-001, SHARED-COMMENT-002, SHARED-COMMENT-003, SHARED-COMMENT-004, SHARED-COMMENT-005, SHARED-COMMENT-006, SHARED-COMMENT-008, SHARED-COMMENT-009 |

RH5038 reports a comment placed inside the argument list of a call, an object creation, a constructor initializer, an element access, or an attribute.

## Non-goals

- A comment before the first call of a wrapped fluent chain outside an argument list — RH5048.
- How an argument list is laid out — the line-break rules.

## Requirements

### RH5038-001 — A comment inside an argument list is reported

The analyzer MUST report every ordinary comment (SHARED-COMMENT-001, SHARED-COMMENT-002) inside an argument list, as SHARED-COMMENT-003, SHARED-COMMENT-004, SHARED-COMMENT-005, SHARED-COMMENT-006, SHARED-COMMENT-008, and SHARED-COMMENT-009 specify for a region. The regions are the argument list from `(` to `)` of an invocation, an object creation (a target-typed `new(…)` included), a constructor initializer, and the base type of a primary constructor; the argument list from `[` to `]` of an element access, a conditional element access, and an indexer assignment inside an object initializer; and the argument list from `(` to `)` of an attribute. The size of an array creation, such as `new int[1]`, is not an argument list and MUST NOT be checked.

Why: A comment inside an argument list leaves it unclear which argument it describes, and it splits the call across lines. A comment above the statement describes the call as a whole.

Example:

```csharp
using System;
using System.Collections.Generic;

class B(int value)
{
    public int Value => value;
}

class C(int value) : B(
    {|RH5038:// the value|}
    value)
{
    int Run(params object[] values) => 0;

    [Obsolete(
        {|RH5038:// reason|}
        "Use N")]
    void M(int[] items)
    {
        var list = new List<int>(
            {|RH5038:// capacity|}
            4);
        _ = items[
            {|RH5038:// first|}
            0];
        Run(1, {|RH5038:// first|}
            2);
        List<int> other = new(
            {|RH5038:// capacity|}
            4);
        var map = new Dictionary<int, int> { [
            {|RH5038:// key|}
            0] = 1 };
        _ = other.Count + map.Count;
        _ = new int[/* size */ 1];
        _ = list;
    }
}
```

The array size comment is not reported.
