# Analyzer — RH8025 Private indexers must be documented

| | |
|---|---|
| ID prefix | RH8025 |
| Status | Active |
| Category | Documentation |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH8025PrivateIndexersMustBeDocumentedAnalyzer` |
| Uses | SHARED-DOC-001, SHARED-DOC-002, SHARED-DOC-004, SHARED-DOC-005, SHARED-DOC-006, SHARED-DOC-007, SHARED-DOC-008, SHARED-DOC-009 |

RH8025 reports an indexer in the private group that has no `<summary>` or `<inheritdoc>` documentation.

## Non-goals

- Indexers in the non-private group — RH8024.
- Properties — RH8022 and RH8023.
- Whether the summary has text — RH8030; the documentation of parameters and return values — RH8101 and RH8105.

## Requirements

### RH8025-001 — Undocumented private indexers are reported

The analyzer MUST report every indexer declaration in the private group of SHARED-DOC-002 that is not documented, checked as SHARED-DOC-001 specifies, except an explicit interface implementation, which SHARED-DOC-009 exempts although it has no access modifier. An indexer declaration is a `this[…]` declaration in the body of a class, struct, interface, record, or record struct. Whether it is documented MUST be decided as SHARED-DOC-004, SHARED-DOC-005, SHARED-DOC-006, and SHARED-DOC-007 specify, and nothing is reported when SHARED-DOC-008 applies.

Why: A private indexer is usable only inside its type, and its signature says nothing about what the index means or which values it accepts. The summary is the one place where that is recorded. It has a rule of its own, so a project can require documentation for what other code uses without requiring it here.

Example:

```csharp
/// <summary>
/// Store
/// </summary>
public interface IStore
{
    /// <summary>
    /// Gets a value
    /// </summary>
    /// <param name="index">Index</param>
    int this[int index] { get; }
}

/// <summary>
/// Buffer
/// </summary>
public class Buffer : IStore
{
    private int {|RH8025:this|}[string key] => 0;

    /// <remarks>
    /// No summary
    /// </remarks>
    int {|RH8025:this|}[long index] => 0;

    /// <summary>
    /// Gets the value for a flag
    /// </summary>
    /// <param name="flag">Flag</param>
    private int this[bool flag] => 0;

    public int this[short index] => index;

    int IStore.this[int index] => index;
}
```

### RH8025-002 — The diagnostic is on the `this` keyword

The analyzer MUST report one diagnostic per undocumented indexer declaration, located on its `this` keyword.

Why: An indexer has no name of its own; `this` is the token that names it in the declaration.

Example: see RH8025-001.
