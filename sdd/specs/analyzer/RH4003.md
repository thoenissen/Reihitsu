# Analyzer — RH4003 Struct name casing

| | |
|---|---|
| ID prefix | RH4003 |
| Status | Active |
| Category | Naming |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH4003StructNameCasingAnalyzer`, `RH4003StructNameCasingCodeFixProvider` |
| Uses | SHARED-CASING-001, SHARED-CASING-006, SHARED-CASING-007, SHARED-CASING-008, SHARED-CASING-009, SHARED-CASING-010 |

RH4003 reports a struct whose name is not in PascalCase and offers a code fix that renames the struct and every reference to it.

## Non-goals

- Record structs, declared as `record struct` — RH4011.
- Class, interface, enum, and delegate names — RH4002, RH4005, RH4004, and RH4006.

## Requirements

### RH4003-001 — Struct names are in PascalCase

The analyzer MUST report every struct declaration whose name is not in PascalCase as SHARED-CASING-001 defines it, including `readonly` and `ref` structs and generic structs. The diagnostic MUST be located on the struct's identifier.

Why: A struct is a type like any other; PascalCase is how .NET spells type names, and a reader recognizes a type by it.

Example:

```csharp
public struct Coordinate
{
}

public readonly struct {|RH4003:immutablePoint|}
{
}

public ref struct {|RH4003:bufferView|}
{
}

public struct {|RH4003:valuePair|}<T1, T2>
{
}
```

### RH4003-002 — The fix renames the struct to PascalCase

The code fix MUST rename the struct and every reference to it (SHARED-CASING-007) to the PascalCase name that SHARED-CASING-006 derives from its old name. It is withheld as SHARED-CASING-008 and SHARED-CASING-009 specify, and its Fix All skips colliding names as SHARED-CASING-010 specifies. This requirement covers the renames that SHARED-CASING-007 covers.

Why: The fix makes exactly the change the diagnostic asks for, and a struct is referenced wherever its type is used.

Example:

```csharp
public struct {|RH4003:pointValue|}
{
    public rangeValue Range;
}

public struct {|RH4003:rangeValue|}
{
}
```

```csharp
public struct PointValue
{
    public RangeValue Range;
}

public struct RangeValue
{
}
```
