# Analyzer — RH7204 Using alias directives must be ordered alphabetically by alias name

| | |
|---|---|
| ID prefix | RH7204 |
| Status | Active |
| Category | Organization |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH7204UsingAliasDirectivesMustBeOrderedAlphabeticallyByAliasNameAnalyzer`, `RH7204UsingAliasDirectivesMustBeOrderedAlphabeticallyByAliasNameCodeFixProvider` |
| Uses | SHARED-USING-004, SHARED-USING-007, SHARED-USING-009, SHARED-USING-011, FMT-USING-001, FMT-USING-002, FMT-USING-003, FMT-USING-005, FMT-USING-006, FMT-USING-007, FMT-USING-008, FMT-USING-009, FMT-USING-010, FMT-USING-011, FMT-USING-012 |

RH7204 reports an alias directive whose alias name sorts before the alias of an earlier directive of its group, and offers a code fix that organizes the whole using block.

## Non-goals

- The position of aliases after the other directives — RH7202 — and the order of the alias groups — RH7207.
- The canonical order and grouping of using directives — SHARED-USING — and how the formatter lays out a reordered block — FMT-USING.

## Requirements

### RH7204-001 — An alias sorted before an earlier alias of its group is reported

The analyzer MUST report every alias directive of a namespace or type name whose alias name sorts before the alias name of any earlier alias directive of a name of the same group (SHARED-USING-004) in the block, whatever directives of other groups or kinds lie between them, compared as SHARED-USING-007 specifies. The group of an alias is decided by the root namespace of its target, taken from the target's value (SHARED-USING-004).

Why: When aliases are sorted by the name they introduce, the one a reader needs is easy to find. Grouping them by their target keeps an alias next to the library it points into.

Example:

```csharp
using b = System.Text;
using {|RH7204:A|} = System.IO;

using Beta = Microsoft.CodeAnalysis.SyntaxNode;
using {|RH7204:Alpha|} = Microsoft.CodeAnalysis.SyntaxToken;

class C
{
}
```

and an alias is compared with every earlier alias of its group, whatever lies between them:

```csharp
using B = Microsoft.CodeAnalysis.SyntaxNode;
using C2 = System.Text;
using {|RH7204:A|} = Microsoft.CodeAnalysis.SyntaxToken;

class C
{
}
```

```csharp
using C2 = System.Text;
using {|RH7204:A|} = System.IO;
using {|RH7204:B|} = System.Linq;

class C
{
}
```

```csharp
using B = System.Text;
using P = int;
using {|RH7204:A|} = System.IO;

class C
{
}
```

and the target's value decides the group, not its spelling:

```csharp
using B = System.Text;
using {|RH7204:A|} = System . IO;

class C
{
}
```

```csharp
using B = System.Text;
using {|RH7204:A|} = @System.IO;

class C
{
}
```

and the global section is checked on its own:

```csharp
global using B = System.Text;
global using {|RH7204:A|} = System.IO;

using C2 = System.Text;

class C
{
}
```

and a block with a preprocessor directive among its directives is reported as well, without a code fix (SHARED-USING-009); in a build that does not define `DEBUG`:

```csharp
using B = System.Text;
#if DEBUG
using System.Diagnostics;
#endif
using {|RH7204:A|} = System.IO;

class C
{
}
```

### RH7204-002 — Aliases of other groups and other kinds are not reported

The analyzer MUST NOT report an alias directive because of an alias of another group, MUST NOT report an alias directive whose alias name sorts before the alias name of no earlier alias of its group, and MUST NOT report a regular or `using static` directive.

Why: The order of the alias groups is RH7207's decision, and the other kinds are ordered by RH7203 and RH7206.

Example:

```csharp
using X = Microsoft.CodeAnalysis.SyntaxNode;
using A = System.IO;

using System.Linq;
using System;

class C
{
}
```

is not reported by RH7204, and neither is an alias of a type that is not a name, which forms a group of its own (SHARED-USING-004):

```csharp
using B = System.Text;
using A = int;

class C
{
}
```

### RH7204-003 — The diagnostic is on the alias name

The analyzer MUST report one diagnostic per reported directive, located on its alias identifier.

Why: The alias name is the sort key, and one diagnostic per directive shows each one that is out of order.

Example: see RH7204-001.

### RH7204-004 — The fix organizes the whole block

The code fix MUST rewrite the whole using block that contains the reported directive as the formatter's using-directive phase does: into the canonical order (FMT-USING-001), with exactly one blank line between two groups and none inside a group other than the one kept above a comment that leads a directive (FMT-USING-002, FMT-USING-010), with one directive per line (FMT-USING-003), and with comments placed as FMT-USING-005, FMT-USING-006, FMT-USING-007, FMT-USING-008, and FMT-USING-009 specify, with the leading trivia of the block's original first directive kept at its top when that trivia holds a preprocessor directive (FMT-USING-012), and at the indentation FMT-USING-011 specifies. It MUST NOT change anything outside the block. No code fix is offered for a diagnostic in a block that SHARED-USING-009 forbids to reorder: a block with a preprocessor directive between two of its directives or between the tokens of one, or with a conditional directive (`#if`, `#elif`, `#else`, `#endif`) in front of its first directive. A block whose preprocessor directives all stand in front of its first directive, none of them a conditional directive, is fixed.

Why: The formatter and the seven using-ordering rules RH7201–RH7207 organize a block the same way; where the organized form leaves a choice to the author, such as the blank line above a comment that leads a directive (SHARED-USING-011), they keep the author's. Producing it in one step corrects every diagnostic those rules report in the block at once, so their fixes never undo each other. The code after the block is not the finding.

Example:

```csharp
using b = System.Text;
using {|RH7204:A|} = System.IO;

class C
{
}
```

```csharp
using A = System.IO;
using b = System.Text;

class C
{
}
```

and a block with a preprocessor directive in front of its first directive is fixed, with the directive at the top:

```csharp
#nullable enable
using B = System.Text;
using {|RH7204:A|} = System.IO;

class C
{
}
```

```csharp
#nullable enable
using A = System.IO;
using B = System.Text;

class C
{
}
```
