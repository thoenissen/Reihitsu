# Analyzer — RH4002 Class name casing

| | |
|---|---|
| ID prefix | RH4002 |
| Status | Active |
| Category | Naming |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH4002ClassNameCasingAnalyzer`, `RH4002ClassNameCasingCodeFixProvider` |
| Uses | SHARED-CASING-001, SHARED-CASING-006, SHARED-CASING-007, SHARED-CASING-008, SHARED-CASING-009, SHARED-CASING-010 |

RH4002 reports a class whose name is not in PascalCase and offers a code fix that renames the class and every reference to it.

## Non-goals

- Record classes, declared as `record` or `record class` — RH4010.
- Struct, interface, enum, and delegate names — RH4003, RH4005, RH4004, and RH4006.
- Whether the class name matches the file name — RH4001.

## Requirements

### RH4002-001 — Class names are in PascalCase

The analyzer MUST report every class declaration whose name is not in PascalCase as SHARED-CASING-001 defines it, whatever its modifiers, type parameters, or nesting. The diagnostic MUST be located on the class's identifier.

Why: A type name is part of every signature that uses it; PascalCase is how .NET spells type names, and a reader recognizes a type by it.

Example:

```csharp
public class OrderProcessor
{
    public class {|RH4002:nestedHelper|}
    {
    }
}

public static class {|RH4002:helperUtils|}
{
}

public class {|RH4002:container|}<T>
{
}

internal class InternalHelper
{
}
```

### RH4002-002 — The fix renames the class to PascalCase

The code fix MUST rename the class and every reference to it (SHARED-CASING-007) to the PascalCase name that SHARED-CASING-006 derives from its old name. It is withheld as SHARED-CASING-008 and SHARED-CASING-009 specify, and its Fix All skips colliding names as SHARED-CASING-010 specifies.

Why: The fix makes exactly the change the diagnostic asks for, and a class is referenced wherever its type is used.

Example:

```csharp
public class {|RH4002:orderProcessor|}
{
    private readonly paymentGateway _gateway = new paymentGateway();

    public int Total => _gateway.Amount;
}

public class {|RH4002:paymentGateway|}
{
    public int Amount { get; set; }
}
```

```csharp
public class OrderProcessor
{
    private readonly PaymentGateway _gateway = new PaymentGateway();

    public int Total => _gateway.Amount;
}

public class PaymentGateway
{
    public int Amount { get; set; }
}
```
