# Analyzer — RH5406 Braces must not be omitted from multi-line child statements

| | |
|---|---|
| ID prefix | RH5406 |
| Status | Active |
| Category | Layout |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH5406BracesMustNotBeOmittedFromMultiLineChildStatementsAnalyzer`, `RH5406BracesMustNotBeOmittedFromMultiLineChildStatementsCodeFixProvider` |
| Uses | SHARED-BRACE-001, SHARED-BRACE-002 |

RH5406 reports an `if` or `else` body without braces that spans several lines, and offers the code fix of SHARED-BRACE-002, which wraps the body in braces.

## Non-goals

- A body without braces that is on one line — RH5405.
- An `if` statement whose branches mix bodies with and without braces — RH5407.

## Requirements

### RH5406-001 — An unbraced body on several lines is reported

The analyzer MUST report a body that SHARED-BRACE-001 names when it is not a block and spans several lines, whether it starts on the line of its `if` or `else` or on a later one. A body that is a block, and a body without braces on one line, MUST NOT be reported.

Why: A body without braces that runs over several lines looks like a block, so the line below it is easily read as part of the branch. A body on one line is RH5405's, so the two rules never report the same body.

Example:

```csharp
class C
{
    void M(bool a, int b)
    {
        if (a)
            {|RH5406:M(a,
              b);|}
        else {|RH5406:M(a,
                    b);|}
        if (a)
            M(a, b);
    }
}
```

### RH5406-002 — The diagnostic is on the body

The analyzer MUST report one diagnostic per body, located on the whole body statement.

Why: The body is what the fix wraps in braces.

Example: see RH5406-001.
