# Analyzer — RH3209 Get-only properties should use an expression body

| | |
|---|---|
| ID prefix | RH3209 |
| Status | Active |
| Category | Clarity |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH3209GetOnlyPropertiesShouldUseAnExpressionBodyAnalyzer`, `RH3209GetOnlyPropertiesShouldUseAnExpressionBodyCodeFixProvider` |
| Uses | SHARED-GETONLY-001, SHARED-GETONLY-002, SHARED-GETONLY-003, SHARED-GETONLY-004, SHARED-GETONLY-005, SHARED-GETONLY-006 |

RH3209 reports a property whose accessor list holds nothing but a getter that the formatter lifts to an expression body, and offers a code fix that replaces the accessor list with that expression body. Which properties are reported and which are not, where the diagnostic is, what the fix produces, and when it is withheld are SHARED-GETONLY-001 to SHARED-GETONLY-006.

## Non-goals

- Indexers — RH3210.
- Properties with a `set` or `init` accessor, whose block-bodied accessors the formatter converts to expression-bodied accessors (FMT-STRUCT-009); no rule reports them.

## Requirements

### RH3209-001 — Every get-only property the formatter converts is reported

The analyzer MUST report every property declaration that SHARED-GETONLY-001 describes — in a class, a struct, a record, or an interface, static or not, an explicit interface implementation included — and no property that SHARED-GETONLY-002, SHARED-GETONLY-003, or SHARED-GETONLY-006 leaves out, on its accessor list (SHARED-GETONLY-004). The code fix MUST write the expression-bodied property of SHARED-GETONLY-005.

Why: The house style writes a get-only property with a computed value as an expression-bodied property; indexers have a rule of their own, so each kind can be configured separately.

Example:

```csharp
interface I
{
    int P {|RH3209:{ get => 1; }|}

    int Q { get; }
}

struct S : I
{
    private static int s_count;

    public static int Count {|RH3209:{ get { return s_count; } }|}

    int I.P {|RH3209:{ get { return 2; } }|}

    public int Q => 3;
}
```

```csharp
interface I
{
    int P => 1;

    int Q { get; }
}

struct S : I
{
    private static int s_count;

    public static int Count => s_count;

    int I.P => 2;

    public int Q => 3;
}
```
