# Analyzer — RH7305 Types should be organized with regions

| | |
|---|---|
| ID prefix | RH7305 |
| Status | Active |
| Category | Organization |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH7305TypesShouldBeOrganizedWithRegionsAnalyzer` |
| Uses | SHARED-TYPEREGION-001, SHARED-TYPEREGION-002, SHARED-TYPEREGION-003, SHARED-TYPEREGION-004 |

RH7305 reports a top-level type that declares members but is not organized with regions, whatever kinds of member it declares. It has no code fix.

## Non-goals

- Types whose members are all of one kind. RH7305 reports them; RH7305A is the alternative rule that leaves them alone.
- Which types are checked, which members count, and when a member is inside a region — SHARED-TYPEREGION-001 to SHARED-TYPEREGION-003.

## Requirements

### RH7305-001 — A type with a member outside every region is reported

The analyzer MUST report every type declaration it checks (SHARED-TYPEREGION-001) that declares at least one member it counts (SHARED-TYPEREGION-002) and is not organized with regions (SHARED-TYPEREGION-003), also when all its members are of one kind. The diagnostic MUST be placed as SHARED-TYPEREGION-004 specifies.

Why: RH7305 is the rule for users who want an outline in every type. A type that holds only methods is still read by scrolling when it has no regions, and one member left outside the regions makes the outline incomplete.

Example:

```csharp
class {|RH7305:C|}
{
    public int P { get; set; }
}
```

and a type with regions that leaves one member out:

```csharp
class {|RH7305:C|}
{
    #region Methods

    void M()
    {
    }

    #endregion

    void N()
    {
    }
}
```

### RH7305-002 — An organized type is not reported

The analyzer MUST NOT report a type declaration in which every counted member lies inside a region (SHARED-TYPEREGION-003).

Why: Such a type already has the outline the rule asks for; the names and the grouping of its regions are other rules' decisions.

Example:

```csharp
class C
{
    #region Fields

    private int _a;

    #endregion // Fields

    #region Methods

    public void M()
    {
    }

    #endregion // Methods
}
```

is not reported.
