# Analyzer — RH5510 Enum attribute lists must use one attribute per list

| | |
|---|---|
| ID prefix | RH5510 |
| Status | Active |
| Category | Layout |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH5510EnumAttributeListsMustFollowShapeRulesAnalyzer`, `RH5510EnumAttributeListsMustFollowShapeRulesCodeFixProvider` |
| Uses | SHARED-ATTR-001, SHARED-ATTR-013, SHARED-ATTR-016, SHARED-ATTR-017, SHARED-ATTR-019 |

RH5510 reports an attribute list of an enum that holds more than one attribute, and offers a code fix that gives each attribute a list of its own. The rule uses `shared/attribute-targets.md`.

## Non-goals

- Attributes of enum members — RH5518.
- Where an enum attribute list is placed — RH5509.

## Requirements

### RH5510-001 — Enum attribute lists hold one attribute

The analyzer MUST check every attribute list that resolves to the enum target: the lists of an `enum` declaration without a specifier or with `type:` (SHARED-ATTR-001), and MUST report such a list that holds more than one attribute, as SHARED-ATTR-013 specifies.

Why: An attribute such as `[Flags]` changes how every member of the enum is read; merged into a list with an unrelated attribute it is easy to miss.

Example:

```csharp
{|RH5510:[A, B]|}
enum E
{
    [A, B]
    X
}
```

The list of the enum member `X` is checked by RH5518, not by RH5510.

### RH5510-002 — The diagnostic is on the attribute list

The analyzer MUST report the diagnostic on the attribute list, as SHARED-ATTR-016 specifies.

Why: The list is what has the wrong shape; each list of a declaration is reported and fixed on its own.

Example: see RH5510-001.

### RH5510-003 — The fix gives each attribute a list of its own

The code fix MUST replace the list with one list per attribute, each on its own line, as SHARED-ATTR-017 specifies.

Why: The fix makes only the change the diagnostic asks for: the attributes keep their order and their specifier, and each gets a line of its own.

Example:

```csharp
{|RH5510:[A, B]|}
enum E
{
}
```

```csharp
[A]
[B]
enum E
{
}
```

### RH5510-004 — The fix is withheld for a comment or directive inside the list

The code fix MUST NOT be offered when SHARED-ATTR-019 withholds it. The diagnostic is still reported.

Why: A comment inside the list belongs to the attribute next to it, and only the author can tell which of the new lists it belongs to.

Example:

```csharp
{|RH5510:[A, /* c */ B]|}
enum E
{
}
```

is reported, and no code fix is offered.
