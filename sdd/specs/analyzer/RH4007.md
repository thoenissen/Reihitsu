# Analyzer — RH4007 File-scoped namespace casing

| | |
|---|---|
| ID prefix | RH4007 |
| Status | Active |
| Category | Naming |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH4007FileScopedNamespaceCasingAnalyzer` |
| Uses | SHARED-CASING-001, SHARED-CASING-005 |

RH4007 reports each segment of a file-scoped namespace declaration that is not in PascalCase.

## Non-goals

- Block-scoped namespace declarations — RH4008.
- Which namespaces a project may declare — RH4009.

## Requirements

### RH4007-001 — File-scoped namespace names are in PascalCase

The analyzer MUST check the name of every file-scoped namespace declaration segment by segment, as SHARED-CASING-005 specifies, and report each segment that is not in PascalCase as SHARED-CASING-001 defines it.

Why: PascalCase is how .NET spells namespaces; a namespace written otherwise reads like a type or a member in every `using` directive and qualified name.

Example:

```csharp
namespace Company.{|RH4007:product|}.{|RH4007:_Internal|};
```

The same name declared as `namespace Company.Product.Internal;` is not reported.
