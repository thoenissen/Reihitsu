# Analyzer — RH8006 Private interfaces must be documented

| | |
|---|---|
| ID prefix | RH8006 |
| Status | Active |
| Category | Documentation |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH8006PrivateInterfacesMustBeDocumentedAnalyzer` |
| Uses | SHARED-DOC-001, SHARED-DOC-002, SHARED-DOC-004, SHARED-DOC-005, SHARED-DOC-006, SHARED-DOC-007, SHARED-DOC-008 |

RH8006 reports an interface in the private group that has no `<summary>` or `<inheritdoc>` documentation.

## Non-goals

- Interfaces in the non-private group — RH8005.
- Whether the summary has text — RH8030; the documentation of type parameters — RH8108.

## Requirements

### RH8006-001 — Undocumented private interfaces are reported

The analyzer MUST report every interface declaration in the private group of SHARED-DOC-002 that is not documented, checked as SHARED-DOC-001 specifies. Generic interfaces are interface declarations too. Whether it is documented MUST be decided as SHARED-DOC-004, SHARED-DOC-005, SHARED-DOC-006, and SHARED-DOC-007 specify, and nothing is reported when SHARED-DOC-008 applies.

Why: A private interface is an implementation detail of its type, but the next maintainer still has to know what it is for. It has a rule of its own, so a project can require documentation for what other code uses without requiring it here.

Example:

```csharp
/// <summary>
/// Outer
/// </summary>
public class Outer
{
    private interface {|RH8006:IHidden|}
    {
    }

    /// <remarks>
    /// No summary
    /// </remarks>
    interface {|RH8006:IHelper|}<T>
    {
    }

    /// <summary>
    /// Documented
    /// </summary>
    private interface IDocumented
    {
    }

    protected interface IVisible
    {
    }
}
```

### RH8006-002 — The diagnostic is on the interface name

The analyzer MUST report one diagnostic per undocumented interface declaration, located on its identifier, without its type parameter list.

Why: The name is what the documentation describes; marking it identifies the declaration without marking its whole body.

Example: see RH8006-001.
