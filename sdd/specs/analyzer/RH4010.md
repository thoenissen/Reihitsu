# Analyzer — RH4010 Record name casing

| | |
|---|---|
| ID prefix | RH4010 |
| Status | Active |
| Category | Naming |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH4010RecordNameCasingAnalyzer`, `RH4010RecordNameCasingCodeFixProvider` |
| Uses | SHARED-CASING-001, SHARED-CASING-006, SHARED-CASING-007, SHARED-CASING-008, SHARED-CASING-009, SHARED-CASING-010 |

RH4010 reports a record class whose name is not in PascalCase and offers a code fix that renames the record and every reference to it.

## Non-goals

- Record structs, declared as `record struct` — RH4011.
- Classes declared with `class` — RH4002.
- The names of the record's primary constructor parameters — RH4120.

## Requirements

### RH4010-001 — Record class names are in PascalCase

The analyzer MUST report every record declared as `record` or `record class` whose name is not in PascalCase as SHARED-CASING-001 defines it. A `record struct` MUST NOT be reported. The diagnostic MUST be located on the record's identifier.

Why: A record is a type; PascalCase is how .NET spells type names. Record structs are value types with their own rule, so each record is checked by exactly one rule.

Example:

```csharp
public record OrderRecord(int Value);

public record {|RH4010:orderLine|}(int Value);

public record class {|RH4010:customerAggregate|}(int Value);

public record struct pointValue(int X);
```

### RH4010-002 — The fix renames the record to PascalCase

The code fix MUST rename the record and every reference to it (SHARED-CASING-007) to the PascalCase name that SHARED-CASING-006 derives from its old name. It is withheld as SHARED-CASING-008 and SHARED-CASING-009 specify, and its Fix All skips colliding names as SHARED-CASING-010 specifies.

Why: The fix makes exactly the change the diagnostic asks for, and a record is referenced wherever its type is used.

Example:

```csharp
public record {|RH4010:orderRecord|}(int Id);

public record {|RH4010:customerRecord|}(orderRecord Order);

public record {|RH4010:orderrecord2|}(int Value);
```

```csharp
public record OrderRecord(int Id);

public record CustomerRecord(OrderRecord Order);

public record Orderrecord2(int Value);
```

`orderrecord2` becomes `Orderrecord2`: a name without a separator or an uppercase letter is one word.
