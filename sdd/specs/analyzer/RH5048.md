# Analyzer — RH5048 Comments must not be placed before the first call of a wrapped chain

| | |
|---|---|
| ID prefix | RH5048 |
| Status | Active |
| Category | Layout |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH5048CommentsMustNotBePlacedBeforeFirstCallOfWrappedChainAnalyzer` |
| Uses | SHARED-COMMENT-001, SHARED-COMMENT-002, SHARED-COMMENT-003, SHARED-CHAIN-001, SHARED-CHAIN-003, SHARED-CHAIN-004 |

RH5048 reports a comment directly in front of the first link of a member-access chain when that link starts a line.

## Non-goals

- A comment in front of a later link of a chain, and a comment inside a region such as an argument list — the comment-placement rules (SHARED-COMMENT).
- Moving the comment. Only the author can decide what it refers to.

## Requirements

### RH5048-001 — A comment before a first link that starts a line is reported

The analyzer MUST report every ordinary comment (SHARED-COMMENT-001) in the gap directly in front of the operator of a chain's first link (SHARED-CHAIN-001) — behind the last token of the root and of the attached parts that belong to it, on that token's line or on a line of its own — when the first link starts a line, whether the first link is a call, a property read, or a conditional or null-forgiving access. Each comment is reported on its own, located on the comment, as SHARED-COMMENT-003 specifies. A comment in front of a first link that stays on the root's line MUST NOT be reported, and neither MUST a comment inside an attached part of the root, such as an argument list, a comment in front of a later link, a comment between the tokens of a link operator, a comment that is part of a preprocessor directive line (SHARED-COMMENT-002), or a comment in disabled text.

Why: The first link belongs on the root's line (SHARED-CHAIN-003). A comment in front of it keeps it apart from its receiver, and neither the formatter nor RH5112 can join it (SHARED-CHAIN-004), so the comment is what has to move.

Example:

```csharp
#nullable enable
using System.Linq;

class C
{
    C? Next { get; set; }

    C Self() => this;

    void M(int[] items, C c)
    {
        var a = items {|RH5048:// only positive|}
            .Where(x => x > 0)
            .ToList();
        var b = c
            {|RH5048:// next|}
            .Next;
        var d = items /* inline */ .Where(x => x > 0)
                                   // materialize
                                   .ToList();
        var e = c.Next
                 // self
                 ?.Self();
        var f = items
#if DEBUG // debug
            .Where(x => x > 0)
#endif
            .ToList();
        var g = c
            ? // conditional
            .Self();
        var h = items {|RH5048:/* source */|}
            {|RH5048:// only positive|}
            .Where(x => x > 0);
        var i = Get(/* value */ 1)
            .Where(x => x > 0);
    }

    int[] Get(int x) => [x];
}
```
