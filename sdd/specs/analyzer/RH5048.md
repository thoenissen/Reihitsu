# Analyzer — RH5048 Comments must not be placed before the first call of a wrapped chain

| | |
|---|---|
| ID prefix | RH5048 |
| Status | Active |
| Category | Layout |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH5048CommentsMustNotBePlacedBeforeFirstCallOfWrappedChainAnalyzer` |
| Uses | SHARED-COMMENT-001, SHARED-COMMENT-002, SHARED-CHAIN-001, SHARED-CHAIN-003, SHARED-CHAIN-004 |

RH5048 reports a comment between the root of a member-access chain and its first link when that link starts a line.

## Non-goals

- A comment in front of a later link of a chain, and a comment inside a region such as an argument list — the comment-placement rules (SHARED-COMMENT).
- Moving the comment. Only the author can decide what it refers to.

## Requirements

### RH5048-001 — A comment before a first link that starts a line is reported

The analyzer MUST report every ordinary comment (SHARED-COMMENT-001) that sits between the root of a chain and its first link (SHARED-CHAIN-001) — behind the root on its line or on a line of its own — when the first link starts a line, whether the first link is a call, a property read, or a conditional or null-forgiving access. A comment between the root and a first link that stays on the root's line MUST NOT be reported, and neither MUST a comment in front of a later link, a comment between the tokens of a link operator, a comment that is part of a preprocessor directive line (SHARED-COMMENT-002), or a comment in disabled text.

Why: The first link belongs on the root's line (SHARED-CHAIN-003). A comment in front of it keeps it apart from its receiver, and neither the formatter nor RH5112 can join it (SHARED-CHAIN-004), so the comment is what has to move.

Example:

```csharp
#nullable enable
using System.Linq;

class C
{
    C? Next { get; set; }

    C Self() => this;

    void M(int[] items, C c)
    {
        var a = items {|RH5048:// only positive|}
            .Where(x => x > 0)
            .ToList();
        var b = c
            {|RH5048:// next|}
            .Next;
        var d = items /* inline */ .Where(x => x > 0)
                                   // materialize
                                   .ToList();
        var e = c.Next
                 // self
                 ?.Self();
        var f = items
#if DEBUG // debug
            .Where(x => x > 0)
#endif
            .ToList();
        var g = c
            ? // conditional
            .Self();
    }
}
```

### RH5048-002 — Each comment is reported on its own

The analyzer MUST report one diagnostic per reported comment, located on that comment. Two comments in front of the same first link MUST be reported separately.

Why: Each comment has to be moved on its own, and the author may want to keep one and delete the other.

Example:

```csharp
using System.Linq;

class C
{
    void M(int[] items)
    {
        var a = items {|RH5048:/* source */|}
            {|RH5048:// only positive|}
            .Where(x => x > 0)
            .ToList();
    }
}
```
