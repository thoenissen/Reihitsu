# Analyzer — RH5410 Final array initializer items must not have trailing commas

| | |
|---|---|
| ID prefix | RH5410 |
| Status | Active |
| Category | Layout |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH5410FinalArrayInitializerItemsMustNotHaveTrailingCommasAnalyzer`, `RH5410FinalArrayInitializerItemsMustNotHaveTrailingCommasCodeFixProvider` |
| Uses | SHARED-TRAIL-001, SHARED-TRAIL-002, SHARED-TRAIL-003 |

RH5410 reports a comma after the last element of an array initializer, and offers a code fix that removes it as SHARED-TRAIL-003 specifies.

## Non-goals

- Trailing commas in enum declarations — RH5409; in collection initializers — RH5411.
- Trailing commas in object initializers, anonymous object creations, and collection expressions (SHARED-TRAIL non-goals).

## Requirements

### RH5410-001 — A comma after the last array element is reported

The analyzer MUST report the comma after the last element of an array initializer as SHARED-TRAIL-001 and SHARED-TRAIL-002 specify: the initializer of an array variable or field (`= { … }`), of an array creation (`new int[] { … }`, `new[] { … }`), and of a `stackalloc` expression (`stackalloc int[] { … }`, `stackalloc[] { … }`). Each nested initializer of a multi-dimensional array MUST be checked on its own.

Why: An array initializer lists the array's elements; a comma behind the last one suggests an element that does not exist.

Example:

```csharp
using System;

class C
{
    int[] _a = { 1, 2{|RH5410:,|} };
    int[] _b = new int[] { 1{|RH5410:,|} };
    int[] _c = new[] { 1{|RH5410:,|} };
    int[,] _d = { { 1, 2{|RH5410:,|} }, { 3, 4 }{|RH5410:,|} };

    void M()
    {
        Span<int> s = stackalloc int[] { 1{|RH5410:,|} };
        Span<int> t = stackalloc[] { 1{|RH5410:,|} };
    }
}
```

### RH5410-002 — Other initializers are not reported

The analyzer MUST NOT report a trailing comma in a collection initializer, an object initializer, an anonymous object creation, or a collection expression.

Why: These lists are not array initializers. A collection initializer is RH5411's; for the others no rule decides about the trailing comma (see the non-goals).

Example:

```csharp
using System.Collections.Generic;

class D
{
    public int P { get; set; }
}

class C
{
    List<int> _a = new List<int> { 1, 2, };
    D _b = new D { P = 1, };
    int[] _c = [1, 2,];
    object _d = new { A = 1, };
}
```

is not reported.
