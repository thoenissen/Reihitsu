# Analyzer — RH3106 Unnecessary delegate parentheses should be removed

| | |
|---|---|
| ID prefix | RH3106 |
| Status | Active |
| Category | Clarity |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH3106UnnecessaryDelegateParenthesesShouldBeRemovedAnalyzer`, `RH3106UnnecessaryDelegateParenthesesShouldBeRemovedCodeFixProvider` |
| Uses | SHARED-PARENS-001, SHARED-PARENS-002, SHARED-PARENS-003 |

RH3106 reports the empty parameter list of an anonymous method, `delegate () { }`, and offers a code fix that removes it. Where the diagnostic is and what the fix produces are SHARED-PARENS-001 and SHARED-PARENS-002.

## Non-goals

- Rewriting the anonymous method as a lambda — RH3004 reports every anonymous method with a parameter list, the empty one included.
- Empty parameter lists of methods, local functions, and lambdas, which the language requires.

## Requirements

### RH3106-001 — An empty parameter list of an anonymous method is reported

The analyzer MUST report the empty parameter list of an anonymous method wherever it stands, unless RH3106-003 applies: as the initializer of a variable whose type is a delegate type, as an argument (RH3106-002), as a value assigned or returned, and in any other expression. An anonymous method without a parameter list or with parameters MUST NOT be reported.

Why: `delegate () { }` says nothing that `delegate { }` does not; the parentheses describe parameters that do not exist.

Example:

```csharp
using System;
using System.Threading.Tasks;

class C
{
    void M()
    {
        Action a = delegate{|RH3106:()|} { };
        Func<Task> b = async delegate {|RH3106:()|} { await Task.Yield(); };
        Action c = delegate { };
        Action<int> d = delegate (int x) { };
    }
}
```

### RH3106-002 — An argument whose binding depends on the parameter list keeps its parentheses

The analyzer MUST report the empty parameter list of an anonymous method that is an argument whose target is chosen by overload resolution or type inference: an argument of an invocation, of an object creation, also a target-typed `new(…)`, of a constructor initializer (`base(…)` or `this(…)`), or of an element access, unless RH3106-003 applies. The code fix MUST NOT be offered when, without the parameter list, the call would not bind to the same method, constructor, or indexer: when it would bind to another one, would be ambiguous (CS0121), or would fail, as when the type arguments of a generic method can no longer be inferred (CS0411). Where it binds to the same one, this requirement does not withhold the fix.

Why: Without a parameter list, an anonymous method converts to a delegate of any parameter list and has no natural type, so an overload that `delegate () { }` did not match can become applicable, and a type parameter that its natural type inferred has nothing to infer from (SHARED-FIX-003). The compile error comes from the other overloads or from the generic signature, not from the position of the anonymous method, so the report stays (SHARED-DIAG-011).

Example:

```csharp
using System;

class C
{
    void Run(Action a)
    {
    }

    void Run(Action<int> a)
    {
    }

    void M()
    {
        Run(delegate {|RH3106:()|} { });
    }
}
```

is reported, and no code fix is offered. Neither is one offered for a constructor initializer with two applicable constructors, nor where a type argument is inferred from the anonymous method:

```csharp
using System;

class B
{
    public B(Action a)
    {
    }

    public B(Action<int> a)
    {
    }
}

class D : B
{
    public D()
        : base(delegate {|RH3106:()|} { })
    {
    }

    static T Run<T>(T t) => t;

    void M()
    {
        Run(delegate {|RH3106:()|} { });
    }
}
```

is reported, and no code fix is offered. With one applicable overload, the fix removes the list:

```csharp
using System;

class C
{
    void Run(Action a)
    {
    }

    void M()
    {
        Run(delegate {|RH3106:()|} { });
    }
}
```

```csharp
using System;

class C
{
    void Run(Action a)
    {
    }

    void M()
    {
        Run(delegate { });
    }
}
```

### RH3106-003 — An anonymous method that takes its natural type is not reported

The analyzer MUST NOT report the empty parameter list of an anonymous method that takes its natural type, because no delegate type is its target and no overload resolution or type inference chooses one: the initializer of an implicitly typed local (`var`), and a variable, an assignment, a return value, or a cast whose type is not a delegate type, such as `object` or `System.Delegate`; and an argument whose parameter type is not a delegate type when no other overload is a candidate for the call and no type argument is inferred from the argument, such as the argument of `Run(object o)` as the only `Run`. An anonymous method whose target is a delegate type, also through a conditional expression, MUST be reported as RH3106-001 states, and an argument whose binding competing overloads or type inference decide as RH3106-002 states.

Why: An anonymous method has a natural type, from C# 10, only with a parameter list; `delegate { }` has none, so `var a = delegate { };` does not compile (CS8917), nor does its conversion to `object` or `System.Delegate`, also as the argument of a parameter of such a type. The position rules the change out (SHARED-DIAG-011).

Example:

```csharp
using System;

class C
{
    static void Run(object o)
    {
    }

    object M(bool b)
    {
        var a = delegate () { };
        Delegate d = delegate () { };
        object o = delegate () { };
        Run(delegate () { });
        return delegate () { };
    }
}
```

is not reported. Where the target is a delegate type, the list is reported:

```csharp
using System;

class C
{
    void M(bool b)
    {
        Action a = b ? delegate {|RH3106:()|} { } : null;
    }
}
```
