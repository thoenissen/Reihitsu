# Analyzer — RH3106 Unnecessary delegate parentheses should be removed

| | |
|---|---|
| ID prefix | RH3106 |
| Status | Active |
| Category | Clarity |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH3106UnnecessaryDelegateParenthesesShouldBeRemovedAnalyzer`, `RH3106UnnecessaryDelegateParenthesesShouldBeRemovedCodeFixProvider` |
| Uses | SHARED-PARENS-001, SHARED-PARENS-002, SHARED-PARENS-003 |

RH3106 reports the empty parameter list of an anonymous method, `delegate () { }`, and offers a code fix that removes it. Where the diagnostic is and what the fix produces are SHARED-PARENS-001 and SHARED-PARENS-002.

## Non-goals

- Rewriting the anonymous method as a lambda — RH3004 reports every anonymous method with a parameter list, the empty one included.
- Empty parameter lists of methods, local functions, and lambdas, which the language requires.

## Requirements

### RH3106-001 — An empty parameter list of an anonymous method is reported

The analyzer MUST report the empty parameter list of an anonymous method that is the initializer of a variable whose declared type is a delegate type. An anonymous method without a parameter list or with parameters MUST NOT be reported.

Why: `delegate () { }` says nothing that `delegate { }` does not; the parentheses describe parameters that do not exist.

Example:

```csharp
using System;
using System.Threading.Tasks;

class C
{
    void M()
    {
        Action a = delegate{|RH3106:()|} { };
        Func<Task> b = async delegate {|RH3106:()|} { await Task.Yield(); };
        Action c = delegate { };
        Action<int> d = delegate (int x) { };
    }
}
```

### RH3106-002 — An argument whose overload depends on the parameter list keeps its parentheses

The analyzer MUST report the empty parameter list of an anonymous method that is an argument of an invocation or an object creation. The code fix MUST NOT be offered when, without the parameter list, the invocation or the creation would bind to another method or constructor, or would be ambiguous. Where it binds to the same one, this requirement does not withhold the fix.

Why: Without a parameter list, an anonymous method converts to a delegate of any parameter list, so an overload that `delegate () { }` did not match can become applicable: the call either becomes ambiguous (CS0121) or binds to another overload (SHARED-FIX-003). The compile error comes from the other overloads, not from the position of the anonymous method, so the report stays (SHARED-DIAG-011).

Example:

```csharp
using System;

class C
{
    void Run(Action a)
    {
    }

    void Run(Action<int> a)
    {
    }

    void M()
    {
        Run(delegate {|RH3106:()|} { });
    }
}
```

is reported, and no code fix is offered. With one applicable overload, the fix removes the list:

```csharp
using System;

class C
{
    void Run(Action a)
    {
    }

    void M()
    {
        Run(delegate {|RH3106:()|} { });
    }
}
```

```csharp
using System;

class C
{
    void Run(Action a)
    {
    }

    void M()
    {
        Run(delegate { });
    }
}
```
