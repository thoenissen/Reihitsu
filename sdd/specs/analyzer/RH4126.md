# Analyzer — RH4126 Single-letter foreach iteration variable names

| | |
|---|---|
| ID prefix | RH4126 |
| Status | Active |
| Category | Naming |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | None |
| Code owners | `RH4126SingleLetterForeachIterationVariableNamesAnalyzer` |
| Uses | SHARED-SINGLE-001, SHARED-SINGLE-002 |

RH4126 reports an iteration variable of a `foreach` statement whose name is a single letter.

## Non-goals

- Other local variables, including those declared in the loop body — RH4125.
- The casing of iteration variable names — RH4115 and RH4117.

## Requirements

### RH4126-001 — Single-letter iteration variable names are reported

The analyzer MUST report every iteration variable of a `foreach` statement (SHARED-SINGLE-002) whose name is a single-letter name (SHARED-SINGLE-001), including each variable of a deconstructing `foreach` statement. The analyzer MUST report one diagnostic per variable, located on its identifier.

Why: The iteration variable names the element the loop processes; a descriptive name makes the loop body easier to understand.

Example:

```csharp
using System.Collections.Generic;

class C
{
    void M(int[] values, List<(int, int)> pairs)
    {
        foreach (var {|RH4126:x|} in values)
        {
        }

        foreach (var ({|RH4126:k|}, {|RH4126:v|}) in pairs)
        {
        }

        foreach (var (key, _) in pairs)
        {
        }
    }
}
```

### RH4126-002 — Variables that are not iteration variables are not checked

The analyzer MUST NOT report a variable declared in the collection expression or in the body of a `foreach` statement, nor any other local variable.

Why: Those variables are ordinary locals, which RH4125 checks, so each kind can be configured separately.

Example:

```csharp
class C
{
    void M()
    {
        var a = 0;

        foreach (var item in Get(out var z))
        {
            var y = item;
        }
    }

    int[] Get(out int count)
    {
        count = 0;

        return [];
    }
}
```

is not reported.
