# Analyzer — RH4103 Method name casing

| | |
|---|---|
| ID prefix | RH4103 |
| Status | Active |
| Category | Naming |
| Severity | Warning |
| Enabled by default | Yes |
| Code fix | Fix All |
| Code owners | `RH4103MethodNameCasingAnalyzer`, `RH4103MethodNameCasingCodeFixProvider` |
| Uses | SHARED-CASING-001, SHARED-CASING-006, SHARED-CASING-007, SHARED-CASING-008, SHARED-CASING-009, SHARED-CASING-010 |

RH4103 reports a method whose name is not in PascalCase and offers a code fix that renames the method and every reference to it.

## Non-goals

- Local functions — RH4104.
- The names of a method's parameters — RH4105, and of its type parameters — RH4121.

## Requirements

### RH4103-001 — Method names are in PascalCase

The analyzer MUST report a method declaration whose name is not in PascalCase as SHARED-CASING-001 defines it. Static, async, abstract, virtual, and generic methods, methods of an interface, and overrides and implicit interface implementations whose original definition is declared in source MUST be checked too. The diagnostic MUST be located on the method's identifier.

This requirement covers a method whose original definition is declared in source — following the methods it overrides, through every level, and the interface methods it implicitly implements never leads to a method declared in a referenced assembly — and that is neither `extern` nor marked with `[LibraryImport]`.

Why: Methods are members that callers name at every call site; .NET names them in PascalCase.

Example:

```csharp
using System.Threading.Tasks;

public interface IProcessor
{
    void {|RH4103:execute|}();
}

public abstract class C
{
    public void ProcessData()
    {
    }

    public static void {|RH4103:calculateTotal|}()
    {
    }

    public async Task {|RH4103:loadDataAsync|}()
    {
        await Task.CompletedTask;
    }

    public abstract void {|RH4103:compute|}();

    public T {|RH4103:createInstance|}<T>()
        where T : new()
    {
        return new T();
    }

    public virtual void {|RH4103:run|}()
    {
    }
}

public class Derived : C, IProcessor
{
    public override void {|RH4103:compute|}()
    {
    }

    public override void {|RH4103:run|}()
    {
    }

    public void {|RH4103:execute|}()
    {
    }
}
```

### RH4103-002 — An explicit interface implementation is not reported

The analyzer MUST NOT report a method declaration that is an explicit interface implementation.

Why: Its name is the name of the interface method, which is reported where it is declared; the fix for that diagnostic renames the implementation with it.

Example:

```csharp
public interface IProcessor
{
    void {|RH4103:process|}();
}

public class Processor : IProcessor
{
    void IProcessor.process()
    {
    }
}
```

```csharp
public interface IProcessor
{
    void Process();
}

public class Processor : IProcessor
{
    void IProcessor.Process()
    {
    }
}
```

### RH4103-003 — The fix renames the method to PascalCase

The code fix MUST rename the method and every reference to it (SHARED-CASING-007) to the PascalCase name that SHARED-CASING-006 derives from its old name, for the methods that RH4103-001 covers. Renaming a method also renames the methods that override it and the implementations of it. It is withheld as SHARED-CASING-008 and SHARED-CASING-009 specify, and its Fix All skips colliding names as SHARED-CASING-010 specifies. This requirement covers the renames that SHARED-CASING-007 covers.

Why: The fix makes exactly the change the diagnostic asks for, and a method is referenced at every call site.

Example:

```csharp
public class C
{
    public void {|RH4103:testmethod|}()
    {
    }

    public void {|RH4103:run_all|}()
    {
        testmethod();
    }
}
```

```csharp
public class C
{
    public void Testmethod()
    {
    }

    public void RunAll()
    {
        Testmethod();
    }
}
```

`testmethod` becomes `Testmethod`: a name without a separator or an uppercase letter is one word.

Example — an override and an implementation in source:

```csharp
public interface IProcessor
{
    void {|RH4103:execute|}();
}

public class Processor : IProcessor
{
    public void {|RH4103:execute|}()
    {
    }
}

public class Base
{
    public virtual void {|RH4103:run|}()
    {
    }
}

public class Derived : Base
{
    public override void {|RH4103:run|}()
    {
    }
}
```

```csharp
public interface IProcessor
{
    void Execute();
}

public class Processor : IProcessor
{
    public void Execute()
    {
    }
}

public class Base
{
    public virtual void Run()
    {
    }
}

public class Derived : Base
{
    public override void Run()
    {
    }
}
```
