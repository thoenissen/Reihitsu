## Architecture findings

**A component copies another's decision (finding 1).** `BraceBlankLinePolicy` (blank-line phase) decides whether a complex element initializer's `{` keeps a glued or own-line comment without a blank line. It copies `LineBreakInitializerRewriter.VisitInitializerExpression`'s condition (`SpansMultipleLines(OpenBraceToken, CloseBraceToken)`), and its own remarks say so ("follow the line-break layout of their braces"). The copy reads the fact before the line-break phase rewrites the initializer's elements; the original reads it after. The input `/* c */ { 2, () => { Console.WriteLine(); } }` (and the object-initializer, collection-initializer, and anonymous-object members) shows the two disagreeing. The run introduced the copy as part of its own structural change; it is inside the components the run changes. The issue's purpose (one owner per decision) is the reason this matters: the blank-line phase now predicts a line-break layout instead of owning a decision of its own.
