## Needs maintainer / new principle candidates

- **N1 - A report that has no possible correction.** The fix part is decided by P1, but the report part is open in #1229 Q3, #1231 Q1/Q2, #1233 Q2, #1234 Q1, #1245 Q2 cont. (constant patterns). AGENTS.md allows a diagnostic without a fix, but for these inputs the reported code cannot be corrected in the language (or the code is not "unnecessary", e.g. `var a = delegate () {}; a();`), which is a report problem rather than a missing fix. Candidate principle: "A rule reports only code its correction can legally replace; where the correction exists for some inputs and breaks others, the fix is withheld (P1) and the report stays; where no input has a correction (`typeof(Nullable<>)`, `var` + `delegate ()`), the rule does not report it". Related: #1127 Q1 (location-less diagnostic, round 5, P8 extension), #1257 should record the choice. Recommend adopting it.
- **N2 - "The code the fix changes": node versus whole member.** #1236 Q1 and #1237 Q1 pit P9 against P10 for the whole shared expression-body family (RH3202, RH3203, RH3205-RH3208). Needs a clarification of P9/P10 (#1138): the formatted region is the node the fix replaces plus its own trivia, not the surrounding member. Changes the SHARED-FIX-003 example "layout, for RH3202". Also decides #1226 Q1-like questions? No (separate: modifiers).
- **N3 - Line-ending drift in fixes** (#1228 Q1, also #1142 for attribute splits). Recurring across rule families; candidate shared requirement: "a fix writes only the document's own line ending" (a SHARED-FIX requirement, bug against it for each instance, like P7's per-rule model).
- **N4 - Fix output that another rule reports** (#1245 Q3 versus RH3002, widened by #1224 Q1): already P7 / SHARED-FIX-004; the maintainer should confirm that Simplifier-left parentheses count as "undo".
- **N5 - User-written modifiers in a rewrite** (#1226 Q1): single instance, not yet a pattern; watch for `async delegate`.
- Order dependency: #1224 Q1 (RH3002 reports attribute arguments, lambda bodies, switch arms) and #1245 Q3 (RH3001 fix output) interact; decide #1245 Q3 after #1224's issue exists.
