**1 · RH7203 · Using directives must be ordered alphabetically by namespace (also RH7207 · Using directives should be organized into groups, and the formatter) — header directive in front of the first using**

Input:
```csharp
#nullable enable
using System.Linq;
using System;

class C
{
    void M()
    {
    }
}
```

Before (`main`, verified): RH7203 and RH7207 reported, no fix offered; Fix All and `reihitsu-format` leave the using block unchanged.

After, A (recommended) — the fixes, Fix All, and the formatter reorder the block; the directive stays on top:
```csharp
#nullable enable
using System;
using System.Linq;

class C
{
    void M()
    {
    }
}
```

After, B: as on `main` — reported, no fix; the formatter keeps the block.

Why A: this header is the most common reason a using block is reported without a fix, and sorting below it moves no using across a directive. (A block with a directive between or after its usings stays reported without a fix under both options.)
