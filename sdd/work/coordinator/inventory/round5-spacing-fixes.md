## Decided by principle

Grouped by shared cause.

- **No-op fix (P7, SHARED-FIX-005):** #1106 Q2. #1076 covers only blank-line fixes, so a new issue is needed: every fix that delegates to the formatter is withheld when the formatter returns the input unchanged (syntax error, generated-code marker that only the formatter recognizes). Alternatively, rename and extend #1076.
- **Fix All needs more than one pass (existing SHARED-FIX-002, no principle needed; P7 covers only single fixes):** #1106 Q3, #1107 Q2, #1110 Q1, #1113 Q2. A new cross-cutting bug issue is needed. It covers overlapping edits and the audit of every test class that sets `NumberOfFixAllIterations = 2`. It is not decided by a principle in the P1–P8 sense. The maintainer only needs to confirm that reading B of #1113 Q2 (allow a second pass) is rejected.
- **SHARED-FIX-003 readings:** #1110 Q2 is answered in part. The recorded decision C and the spec text ("repeats the name"; a changed word is content) make the `cat` → `cAt` substring rewrite a bug. The a/b choice for a comment that contains the name among other words is still open. #1109 Q1 is not answered by the readings: re-indenting comment and directive lines is layout under the recorded readings, so it is not a SHARED-FIX-003 violation as written. Relocating a comment (`/* c */ [A, B]`) is the open extension #1136.
- **LF drift in #1109 Q1:** already a bug against SHARED-ATTR-017 / FMT-PIPE-007, whatever reading is chosen. It goes into the issue that implements the #1109 decision.

## Needs maintainer

- **Fix scope of formatting-aware fixes (new principle P9?):** #1113 Q1, #1106 Q1, #1109 Q1. One decision: a fix changes only the code its diagnostic is about (B, matching #969), or it may format the node it needs (A, matching #1094's "match the formatter"). Suggest B, with #1109 as reading A and #1106 as reading (a).
- **#1107 Q1:** RH6016 vs FMT-SPACE-006 on `I . M`. P4, case by case. Suggest (a): the formatter tightens the explicit-interface dot too.
- **#1108 Q1:** colon glued to a comment. Suggest (a): not reported, by extending #1078 to the missing-space direction.
- **#1110 Q2:** `#endregion // end of members`, exact-name (a) vs whole-word (b). Suggest (a). `cAt` is a bug either way.
- **#1110 Q3:** Fix All with a guard that releases a fix only after another fix has run. Suggest (b): a clarification that SHARED-FIX-002 covers the fixes available on the starting document.
- **#1113 Q2 reading B:** confirm that it is rejected, so the whole Fix All group becomes one bug issue.
