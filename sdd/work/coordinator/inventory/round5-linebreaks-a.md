## Decided by principle

- **P1 / SHARED-FIX-003 — line-based fix edits inside a literal or comment.** #1117 Q1. Same class as #1075 (blank-line rules). New issue needed for RH5104 (or widen #1075's scope to every line-based fix; RH5104 is a comment rule, not a blank-line rule).
- **P6 — `/** */` documenting nothing.** #1117 Q2 → extend #1077.
- **P5 / SHARED-DIAG-003 — what follows a literal is code.** #1117 Q5 → shares its cause with the #1075 comment-2 instance (whole interpolated-string span exempted). New issue needed for RH5104, or one issue for the "literal span over-exemption" helper class (RH5023, RH5104, and the other `GetStringLineIndices` users).
- **#1136 (SHARED-FIX-003 extension, not yet merged)** — #1117 Q4 reorder part; the main defect (reported at all) is a plain bug against RH5104-001.

## Recurring patterns (candidate principles)

- **NEW:fix-output-misformatted → candidate P9 "a fix that lays out code gives the layout the formatter gives, in one application".** Already decided case by case three times (#1094, #1096/#1000 Q1, #1062 via #1075); now #1112 Q1 (three rules) and #1116 Q4. A principle would turn these into bugs without a round.
- **P4 / NEW:analyzer-scope-narrower — the analyzer checks fewer syntax shapes than the formatter it cites.** #1114 Q1, #1115 Q1, #1116 Q1, #1116 Q3 (and #1093, #1064 earlier). Every earlier P4 decision sided with the formatter (#1064, #1080, #1093, #1065 Q1). Candidate: "where a rule's spec says it reports what FMT-X produces, the analyzer covers every shape FMT-X changes" — a behavior-change principle, so new diagnostics need the maintainer's ok once.
- **NEW:comment-kind-asymmetry** — `//`, `/* */`, `/** */`, `///` treated differently where the rule means "a comment": #1117 Q3, Q6, plus #1077 instances. Candidate: "a rule treats every ordinary comment kind alike; a doc-comment form that documents nothing is an ordinary comment in every documentation mode" (extends P6 to `///`).
- **NEW:list-boundary-wrap** — a wrap only at a list boundary is joined, not expanded: #1111 Q1 with #956 and FMT-BREAK-011 precedent. Probably a one-off clarification.
