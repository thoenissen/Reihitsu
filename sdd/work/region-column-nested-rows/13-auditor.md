## Hints
- `PrecheckPhase.FindRegionDirectiveInsideMember` calls `StandsBetweenMembers` (an ancestor walk calling `GetFirstToken` at each level) for every token with leading trivia, before it looks for a region directive in that trivia. Checking the trivia first, or returning early when `node.ContainsDirectives` is false, avoids the walk for nearly every token. The cost is small and the code is correct either way.
- When the brace rule leaves a comment alone on its line in front of a brace, the existing comment blank-line rule puts a blank line above it: `new[]⏎/* c */ {` → `new[]` / blank / `/* c */` / `{`; `},⏎/* c */ { 3, 4 }` → `},` / blank / `/* c */` / `{ 3, 4 }`. The base does the same for `new List⏎/* c */⏎{`, so this is existing policy reached by more shapes, not a defect of the run.
- `MoveTokenBelowItsLine` and `ChainLineBreakRewriter.EnsureLineBreak` hold the same private two-line edit (08 names it). A shared helper in `LineBreakTriviaUtilities` would keep them from drifting.
