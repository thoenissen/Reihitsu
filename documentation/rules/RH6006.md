# RH6006 — Opening parenthesis must be spaced correctly

| Property | Value |
|----------|-------|
| **ID** | RH6006 |
| **Category** | Spacing |
| **Severity** | Warning |
| **Code Fix** | ✓ |

## Description

No space may appear immediately after an opening parenthesis.

## Why is this a problem?

A leading space inside parentheses is non-standard and draws the eye inward, making it harder to identify the start of the enclosed expression.

## How to fix it

Remove the space immediately after the opening parenthesis. The code fix applies this change automatically,
unless a comment or preprocessor directive shares the token gap the whitespace run sits in. Deleting the
whitespace in that case would glue the comment to the parenthesis or drop the directive, so the diagnostic is
still reported but no fix is offered.

## Examples

### Violation

```cs
internal class TestClass
{
    int Method()
    {
        return ( 0);
    }
}
```

### Correction

```cs
internal class TestClass
{
    int Method()
    {
        return (0);
    }
}
```
