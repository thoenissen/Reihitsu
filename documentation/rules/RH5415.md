# RH5415 — Empty records should use semicolon declarations

| Property | Value |
|----------|-------|
| **ID** | RH5415 |
| **Category** | Layout |
| **Severity** | Warning |
| **Code Fix** | ✓ |

## Description

This rule prefers semicolon declarations for empty records.

Brace-based empty record bodies add noise when the declaration contains no members.

The rule reports only when the project's C# language version allows the semicolon form (C# 9 or later for an empty record).

## Why is this a problem?

An empty record often serves as a concise data marker or inheritance shell. Extra braces make that declaration heavier than necessary.

Using a semicolon declaration keeps the intent obvious while reducing structural clutter.

## How to fix it

Replace the empty brace body with a trailing semicolon. The code fix applies this change automatically.

## Examples

### Violation

```cs
internal record Example
{
}
```

### Correction

```cs
internal record Example;
```
