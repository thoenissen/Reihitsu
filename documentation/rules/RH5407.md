# RH5407 — Use braces consistently

| Property | Value |
|----------|-------|
| **ID** | RH5407 |
| **Category** | Layout |
| **Severity** | Warning |
| **Code Fix** | ✓ |

## Description

When one branch of an `if`-`else` statement uses braces, all other branches must also use braces. The diagnostic is reported on the branch that is missing them.

This rule is about the mismatch between the branches: it is reported only when an `if`-`else` mixes the two styles. A brace-less branch is reported by [RH5405](RH5405.md) or [RH5406](RH5406.md) in its own right, so a mixed statement can carry a diagnostic from both rules — correcting it once satisfies all of them.

## Why is this a problem?

Mixing braced and brace-less branches in the same `if`-`else` chain is inconsistent and makes it easy to add statements to the wrong branch by misjudging which clause the indentation belongs to.

## How to fix it

Add braces to all branches so every clause uses them consistently. The code fix applies this change automatically.

## Examples

### Violation

```cs
internal class TestClass
{
    void Method()
    {
        if (true)
        {
            return;
        }
        else
            return;
    }
}
```

### Correction

```cs
internal class TestClass
{
    void Method()
    {
        if (true)
        {
            return;
        }
        else
        {
            return;
        }
    }
}
```
