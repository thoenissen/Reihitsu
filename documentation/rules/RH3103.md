# RH3103 — Use shorthand for nullable types

| Property | Value |
|----------|-------|
| **ID** | RH3103 |
| **Category** | Clarity |
| **Severity** | Warning |
| **Code Fix** | ✓ |

## Description

This rule prefers the C# nullable shorthand `T?` over `Nullable<T>` or `System.Nullable<T>`.

## Why is this a problem?

The shorthand is the standard C# notation for nullable value types. It is shorter, easier to read, and more idiomatic.

## How to fix it

Replace `Nullable<T>` with `T?`.

No code fix is offered for a dotted `Nullable<T>` (also behind `global::`) written as the argument of `nameof`, such as `nameof(System.Nullable<int>)` — `nameof(int?)` does not compile, so leave it as written.

## Examples

### Violation

```cs
using System;

internal class Example
{
    private Nullable<int> _count;
}
```

### Correction

```cs
using System;

internal class Example
{
    private int? _count;
}
```
