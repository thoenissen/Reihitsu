# RH5107 — Comma must be on same line as previous parameter

| Property | Value |
|----------|-------|
| **ID** | RH5107 |
| **Category** | Layout |
| **Severity** | Warning |
| **Code Fix** | ✓ |

## Description

In a multi-line parameter list, the comma separating two parameters must appear at the end of the line that contains the preceding parameter, not at the start of the following line. The commas of an argument list are not checked.

## Why is this a problem?

A leading comma on the next line is non-standard in C# and makes it harder to read parameter lists by moving the separator away from the element it follows.

## How to fix it

Move the comma to the end of the preceding line. When another parameter stayed on the comma's own line, it is aligned under the first parameter of the list; when nothing did, the now-empty line is removed instead of left behind. The code fix applies this change automatically.

## Examples

### Violation

```cs
internal class TestClass
{
    void Method(int first
               ,int second)
    {
    }
}
```

### Correction

```cs
internal class TestClass
{
    void Method(int first,
                int second)
    {
    }
}
```
