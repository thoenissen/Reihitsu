# RH8030 — Element documentation must have summary text

| Property | Value |
|----------|-------|
| **ID** | RH8030 |
| **Category** | Documentation |
| **Severity** | Warning |
| **Code Fix** | ❌ |

## Description

This rule requires every &lt;summary&gt; tag to contain meaningful text.

The rules that require a declaration to be documented at all — RH8001 to RH8029 — are satisfied as soon as a &lt;summary&gt; tag is present. This rule is the one that requires the tag to actually say something, so an empty summary added only to silence those rules is still reported.

## Why is this a problem?

An empty summary is worse than no summary at all. A reader who opens the declaration or hovers over a use site sees an explanation slot that has been filled in and moved on, so the missing description stays invisible instead of standing out as work still to do.

## How to fix it

Write a short, useful description inside the &lt;summary&gt; tag.

## Examples

### Violation

```cs
/// <summary>
/// </summary>
internal class Worker
{
}
```

### Correction

```cs
/// <summary>
/// Performs background work for the queue
/// </summary>
internal class Worker
{
}
```
