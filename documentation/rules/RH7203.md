# RH7203 — Using directives must be ordered alphabetically by namespace

| Property | Value |
|----------|-------|
| **ID** | RH7203 |
| **Category** | Organization |
| **Severity** | Warning |
| **Code Fix** | ✓ |

## Description

This rule requires regular `using` directives to be sorted alphabetically by namespace within their group. Imports are grouped by their root namespace — the first segment before the first dot, such as `System`, `Microsoft` or `Reihitsu` — and only directives sharing a root namespace are compared with each other. [RH7207](RH7207.md) governs the order of the groups themselves.

## Why is this a problem?

Alphabetical ordering makes it easier to find imports quickly and keeps file headers consistent.

## How to fix it

Sort the regular `using` directives by namespace name.

## Examples

### Violation

```cs
using System.Linq;
using System.Collections.Generic;
```

### Correction

```cs
using System.Collections.Generic;
using System.Linq;
```
