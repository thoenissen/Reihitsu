# RH6018 — Negative signs must be spaced correctly

| Property | Value |
|----------|-------|
| **ID** | RH6018 |
| **Category** | Spacing |
| **Severity** | Warning |
| **Code Fix** | ✓ |

## Description

The unary minus operator used as a sign must not be followed by a space.

## Why is this a problem?

A space after a unary minus makes it ambiguous whether the operator is unary or binary, reducing readability.

## How to fix it

Remove the space immediately after the unary minus sign. The code fix applies this change automatically,
unless a comment or preprocessor directive shares the token gap the whitespace run sits in. Deleting the
whitespace in that case would glue the comment to the operand or drop the directive, so the diagnostic is still
reported but no fix is offered.

## Exceptions

The rule does not report when the space is the only thing keeping two symbols apart. In `- -value`, closing the gap would produce `--value`, a pre-decrement with a different meaning, so that space is left in place.

## Examples

### Violation

```cs
internal class TestClass
{
    void Method()
    {
        int value = - 1;
    }
}
```

### Correction

```cs
internal class TestClass
{
    void Method()
    {
        int value = -1;
    }
}
```
