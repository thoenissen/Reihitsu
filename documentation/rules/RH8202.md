# RH8202 — `<value>` tag must not be used

| Property | Value |
|----------|-------|
| **ID** | RH8202 |
| **Category** | Documentation |
| **Severity** | Warning |
| **Code Fix** | ✓ |

## Description

This rule forbids the `<value>` tag in XML documentation.

## Why is this a problem?

In practice a `<value>` tag repeats what the property's `<summary>` already says, so the same information has to be maintained in two places and the two drift apart. A single `<summary>` is shorter to read and keeps every property in the code base documented the same way.

## How to fix it

Remove the `<value>` tag. If it carries information the `<summary>` does not, fold that information into the `<summary>` first — the code fix only deletes the tag, so anything worth keeping has to be moved by hand.

No code fix is offered when the `<value>` tag was never closed. Delete the opening tag and its text yourself there.

## Examples

### Violation

```cs
/// <summary>Gets the current count</summary>
/// <value>The current count</value>
internal int Count { get; }
```

### Correction

```cs
/// <summary>Gets the current count</summary>
internal int Count { get; }
```
