# RH5526 — Delegate attribute lists must use one attribute per list

| Property | Value |
|----------|-------|
| **ID** | RH5526 |
| **Category** | Layout |
| **Severity** | Warning |
| **Code Fix** | ✓ |

## Description

Delegate attribute lists must contain exactly one attribute.

## Why is this a problem?

Attributes on a delegate are independent decisions, and `[First, Second]` is the syntax that says they are not.
Splitting them gives each its own line, so a diff that adds or removes one attribute does not restate the rest, and
any of them can be given its own explanatory comment.

## How to fix it

Give each attribute a list of its own: replace `[First, Second]` with `[First]` on one line and `[Second]` on the
next. A code fix is offered and performs the split for you.

If a comment sits inside the list, the diagnostic is still reported but no code fix is offered, because the split
would have to decide which of the two new lists keeps your comment. Separate the attributes by hand in that case.

## Examples

### Violation

```cs
[First, Second]
internal delegate void ExampleDelegate();
```

### Correction

```cs
[First]
[Second]
internal delegate void ExampleDelegate();
```
