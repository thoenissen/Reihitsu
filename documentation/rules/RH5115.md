# RH5115 — Index access must stay on the line of its expression

| Property | Value |
|----------|-------|
| **ID** | RH5115 |
| **Category** | Layout |
| **Severity** | Warning |
| **Code Fix** | ✓ |

## Description

An index access such as `[0]` or `?[0]` must start on the line of the expression it belongs to. The rule reports one that a line break separates from that expression, wherever it stands.

## Why is this a problem?

An index belongs to the expression in front of it. On a line of its own, `[0]` reads like a collection expression or an attribute list, so the reader has to look back to see what it applies to.

## How to fix it

Remove the line break in front of the index, so that it follows the expression directly. The code fix does this for you; in a wrapped method chain, it also realigns the chain's lines.

## Examples

### Violation

```cs
internal class TestClass
{
    int Method(int[] values)
    {
        return values
            [0];
    }
}
```

### Correction

```cs
internal class TestClass
{
    int Method(int[] values)
    {
        return values[0];
    }
}
```
