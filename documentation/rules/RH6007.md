# RH6007 — Opening square brackets must be spaced correctly

| Property | Value |
|----------|-------|
| **ID** | RH6007 |
| **Category** | Spacing |
| **Severity** | Warning |
| **Code Fix** | ✓ |

## Description

No space may appear immediately after an opening square bracket `[`. The opening bracket of an attribute is covered separately by [RH6013](RH6013.md).

## Why is this a problem?

A leading space inside brackets is non-standard and makes indexer and collection expressions harder to scan.

## How to fix it

Remove the space immediately after the opening square bracket. The code fix applies this change automatically,
unless a comment or preprocessor directive shares the token gap the whitespace run sits in. Deleting the
whitespace in that case would glue the comment to the bracket or drop the directive, so the diagnostic is still
reported but no fix is offered.

## Examples

### Violation

```cs
internal class TestClass
{
    void Method()
    {
        int[] values = [0];
        _ = values[ 0];
    }
}
```

### Correction

```cs
internal class TestClass
{
    void Method()
    {
        int[] values = [0];
        _ = values[0];
    }
}
```
