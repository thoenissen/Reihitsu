# RH2003 — NotImplementedException should not be used

| Property | Value |
|----------|-------|
| **ID** | RH2003 |
| **Category** | Design |
| **Severity** | Warning |
| **Code Fix** | ❌ |

## Description

`NotImplementedException` should not be used. This rule flags explicit and target-typed creation of `NotImplementedException`.

## Why is this a problem?

The presence of `NotImplementedException` indicates incomplete implementation that was left as a placeholder. Shipping code with these exceptions leads to unexpected runtime failures and signals that the code is not production-ready.

## How to fix it

Implement the method body with the actual logic, or throw a more appropriate exception such as `NotSupportedException` if the operation is intentionally unsupported.

## Examples

### Violation

```cs
public void Process(Order order)
{
    throw new NotImplementedException();
}
```

### Correction

```cs
public void Process(Order order)
{
    _repository.Save(order);
}
```

When the operation is intentionally unsupported, say so instead of leaving a placeholder behind:

```cs
public void Process(Order order)
{
    throw new NotSupportedException("Orders are processed by the batch importer.");
}
```
