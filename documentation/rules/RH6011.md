# RH6011 — Opening generic brackets must be spaced correctly

| Property | Value |
|----------|-------|
| **ID** | RH6011 |
| **Category** | Spacing |
| **Severity** | Warning |
| **Code Fix** | ✓ |

## Description

No same-line horizontal whitespace may appear immediately before the opening angle bracket `<` of a generic type argument list (`List<int>`) or a generic type parameter list (`class Cache<TKey>`). Indentation before a bracket that begins a continuation line is left unchanged.

## Why is this a problem?

A space before the opening angle bracket separates the type name from its type arguments, making generic types look different from the rest of the language and harder to recognize at a glance.

## How to fix it

Remove the same-line space or tab immediately before the opening generic angle bracket. The code fix applies
this change automatically, unless a comment or preprocessor directive shares the token gap the whitespace run
sits in — for example a block comment on the line above a continuation-line bracket. Deleting the whitespace in
that case would glue the comment to the bracket or drop the directive, so the diagnostic is still reported but
no fix is offered.

## Examples

### Violation

```cs
using System.Collections.Generic;
internal class TestClass
{
    void Method()
    {
        _ = new List <int>();
    }
}
```

### Correction

```cs
using System.Collections.Generic;
internal class TestClass
{
    void Method()
    {
        _ = new List<int>();
    }
}
```
