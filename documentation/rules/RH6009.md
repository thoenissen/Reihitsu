# RH6009 — Opening braces must be spaced correctly

| Property | Value |
|----------|-------|
| **ID** | RH6009 |
| **Category** | Spacing |
| **Severity** | Warning |
| **Code Fix** | ✓ |

## Description

An opening brace `{` must be separated by a space from whatever precedes it on the same line. A brace that starts its own line is already separated and is not reported, and braces that belong to an interpolated string — the `{value}` in `$"{value}"` — are left alone.

## Why is this a problem?

An opening brace written directly against the preceding token merges with it visually, so the start of the block is harder to spot on a line that also carries other code.

## How to fix it

Insert a single space before the opening brace. The code fix applies this change automatically.

## Examples

### Violation

```cs
internal class TestClass
{
    int Property{ get; set; }
}
```

### Correction

```cs
internal class TestClass
{
    int Property { get; set; }
}
```
