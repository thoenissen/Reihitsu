# RH2110 — Nested unions should not be used

| Property | Value |
|----------|-------|
| **ID** | RH2110 |
| **Category** | Design |
| **Severity** | Warning |
| **Code Fix** | ❌ |

## Description

Do not declare a union inside another type.

## Why is this a problem?

Nested unions are harder to discover and reuse. They also hide declarations inside unrelated types and make ownership less obvious during maintenance.

## How to fix it

Move the nested union to a top-level declaration.

## Examples

### Violation

```cs
namespace Example;

internal class Container
{
    private union Result(int, string);
}
```

### Correction

```cs
namespace Example;

internal class Container
{
}

internal union Result(int, string);
```
