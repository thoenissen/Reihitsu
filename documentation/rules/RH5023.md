# RH5023 — Code must not contain multiple blank lines in a row

| Property | Value |
|----------|-------|
| **ID** | RH5023 |
| **Category** | Layout |
| **Severity** | Warning |
| **Code Fix** | ✓ |

## Description

At most one blank line may appear consecutively anywhere in a source file.

## Why is this a problem?

Multiple consecutive blank lines add unnecessary vertical space and push code off-screen, making it harder to read and review.

## How to fix it

Reduce any sequence of two or more blank lines to a single blank line. The code fix applies this change automatically.

## Exceptions

Blank lines that are part of the content of your file rather than layout around it are left alone, so nothing is reported for:

- empty lines inside a multiline string literal, where they are part of the string value;
- empty lines inside a `/* ... */` block comment or a `/** ... */` documentation comment;
- empty lines inside code that a `#if` directive currently excludes from the build.

## Examples

### Violation

```cs
internal class TestClass
{
    void Method()
    {
        int first = 0;


        int second = 1;
    }
}
```

### Correction

```cs
internal class TestClass
{
    void Method()
    {
        int first = 0;

        int second = 1;
    }
}
```
