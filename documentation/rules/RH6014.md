# RH6014 — Closing attribute brackets must be spaced correctly

| Property | Value |
|----------|-------|
| **ID** | RH6014 |
| **Category** | Spacing |
| **Severity** | Warning |
| **Code Fix** | ✓ |

## Description

No same-line horizontal whitespace may appear immediately before the closing bracket `]` of an attribute. Indentation before a bracket that begins a continuation line is left unchanged.

## Why is this a problem?

A trailing space inside an attribute's brackets is non-standard and makes the attribute harder to recognize as a compact annotation.

## How to fix it

Remove the same-line space or tab immediately before the closing attribute bracket. The code fix applies this
change automatically, unless a comment or preprocessor directive shares the token gap the whitespace run sits
in — for example a block comment on the line above a continuation-line bracket. Deleting the whitespace in
that case would glue the comment to the bracket or drop the directive, so the diagnostic is still reported but
no fix is offered.

## Examples

### Violation

```cs
[System.Obsolete ]
internal class TestClass
{
}
```

### Correction

```cs
[System.Obsolete]
internal class TestClass
{
}
```
