# RH5040 — Comments must not be placed around the arrow of an expression-bodied member

| Property | Value |
|----------|-------|
| **ID** | RH5040 |
| **Category** | Layout |
| **Severity** | Warning |
| **Code Fix** | ❌ |

## Description

This rule reports a comment placed directly before or directly after the `=>` of an expression-bodied member or accessor. The rule applies whether or not the comment shares a line with code.

## Why is this a problem?

The arrow joins the member signature to its body. A comment around it separates the two and makes it unclear whether it describes the signature or the expression.

## How to fix it

Move the comment above the member. No code fix is offered, because only you can decide what the comment refers to.

## Examples

### Violation

```cs
internal class Example
{
    public int Value
        // computed
        => 42;
}
```

### Correction

```cs
internal class Example
{
    // computed
    public int Value => 42;
}
```
