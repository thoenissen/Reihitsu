# RH3201 — Comments must contain text

| Property | Value |
|----------|-------|
| **ID** | RH3201 |
| **Category** | Clarity |
| **Severity** | Warning |
| **Code Fix** | ✓ |

## Description

This rule disallows empty comments such as `//` or `/* */` when they contain no useful content.

## Why is this a problem?

Empty comments add noise but provide no information. They make code look unfinished and distract from comments that actually matter.

## How to fix it

Remove the empty comment or replace it with meaningful text.

## Exceptions

An empty `//` line that sits between two other comment lines is not reported. There it is a paragraph break inside a single block of prose, not a leftover:

```cs
// Retry the request once.
//
// The service returns 503 while it is still warming up.
```

## Examples

### Violation

```cs
public void Run()
{
    //
    DoWork();
}
```

### Correction

```cs
public void Run()
{
    DoWork();
}
```
