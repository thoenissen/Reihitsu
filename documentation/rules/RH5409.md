# RH5409 — Final enum members must not have trailing commas

| Property | Value |
|----------|-------|
| **ID** | RH5409 |
| **Category** | Layout |
| **Severity** | Warning |
| **Code Fix** | ✓ |

## Description

This rule forbids a trailing comma after the final member in an enum declaration.

## Why is this a problem?

A trailing comma on the last enum member adds noise without improving readability.

Keeping the final member free of a trailing comma makes the end of the enum clearer and keeps formatting predictable.

## How to fix it

Remove the comma after the final enum member. If the member has an attached comment, keep the comment with the member and remove only the comma.

The code fix applies this automatically.

## Exceptions

A trailing comma is not reported when an `#if` block sits between it and the closing brace. The enum members inside that block can become active in another build configuration and then need the comma.

## Examples

### Violation

```cs
internal enum Status
{
    Ready,
    Completed, // final value
}
```

### Correction

```cs
internal enum Status
{
    Ready,
    Completed // final value
}
```
