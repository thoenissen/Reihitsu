# RH4125 — Single-letter local variable names should not be used

| Property | Value |
|----------|-------|
| **ID** | RH4125 |
| **Category** | Naming |
| **Severity** | Warning |
| **Code Fix** | ❌ |

## Description

Local variable declarators and out, pattern, or deconstruction variable designations should use names longer than one letter. The discard identifier `_` is exempt.

## Why is this a problem?

Local names often carry the meaning of intermediate values. Single-letter names make calculations and control flow harder to scan and maintain.

## How to fix it

Rename the variable to describe the value or role it represents.

## Examples

### Violation

```cs
var x = GetItemCount();
```

### Correction

```cs
var itemCount = GetItemCount();
```
