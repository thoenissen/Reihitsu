# RH5403 — Statement must not be on a single line

| Property | Value |
|----------|-------|
| **ID** | RH5403 |
| **Category** | Layout |
| **Severity** | Warning |
| **Code Fix** | ✓ |

## Description

A block that contains at least one statement must not be written on a single line. Each statement must appear on its own line.

The rule applies to the bodies of `if`, `else`, `while`, `do`, `for`, `foreach`, `using`, `lock`, and `fixed` statements. An empty body such as `while (Wait()) { }` is not reported, because there is no statement to move onto a line of its own.

## Why is this a problem?

Collapsing a block onto one line hides its content and makes it difficult to read, step through in a debugger, or set a breakpoint on an individual statement.

## How to fix it

Split the block so each statement is on its own line. The code fix applies this change automatically.

## Examples

### Violation

```cs
internal class TestClass
{
    void Method()
    {
        if (true) { return; }
    }
}
```

### Correction

```cs
internal class TestClass
{
    void Method()
    {
        if (true)
        {
            return;
        }
    }
}
```
