# RH7201 — System using directives must be placed before other using directives

| Property | Value |
|----------|-------|
| **ID** | RH7201 |
| **Category** | Organization |
| **Severity** | Warning |
| **Code Fix** | ✓ |

## Description

This rule requires `System` namespace imports to appear before other regular `using` directives.

## Why is this a problem?

Keeping framework imports together at the top makes the using block easier to scan. It also creates a predictable structure across files.

## How to fix it

Move `using System...` directives above other regular `using` directives.

## Exceptions

No diagnostic is reported for a `using` block that contains a preprocessor directive such as `#if`, `#region` or `#pragma`. Reordering imports across a directive could change which imports the build actually sees, so the whole block is left exactly as written — sort it by hand there.

## Examples

### Violation

```cs
using MyProject.Common;
using System.Linq;
```

### Correction

```cs
using System.Linq;
using MyProject.Common;
```
