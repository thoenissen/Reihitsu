# RH7302 — #region description should start with an uppercase letter

| Property | Value |
|----------|-------|
| **ID** | RH7302 |
| **Category** | Organization |
| **Severity** | Warning |
| **Code Fix** | ✓ |

## Description

This rule checks that the description text following a `#region` directive starts with an uppercase letter. Consistent casing in region descriptions improves readability and maintains a professional code style.

## Why is this a problem?

Region descriptions that start with a lowercase letter are inconsistent with common C# naming conventions. Since regions are used to organize code sections, their descriptions should follow a consistent capitalization style to make file navigation easier.

## How to fix it

Capitalize the first letter of the `#region` description. The code fix does this for you and updates the matching `#endregion` comment in the same step, so the pair keeps agreeing.

The rule only looks at the first character that is a letter. A description that starts with a digit, a symbol, or an already-capitalized word is left alone.

## Examples

### Violation

```cs
internal class Example
{
    #region methods

    public void DoWork()
    {
    }

    #endregion // methods
}
```

### Correction

```cs
internal class Example
{
    #region Methods

    public void DoWork()
    {
    }

    #endregion // Methods
}
```
