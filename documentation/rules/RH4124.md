# RH4124 — Single-letter lambda, anonymous method, and query range variable names should not be used

| Property | Value |
|----------|-------|
| **ID** | RH4124 |
| **Category** | Naming |
| **Severity** | Warning |
| **Code Fix** | ❌ |

## Description

Lambda and anonymous method parameters, and the range variables of a query expression introduced by `from`, `let`, `join`, and `into`, should use names longer than one letter. The discard identifier `_` is exempt.

## Why is this a problem?

Descriptive parameter and range variable names make inline transformations, predicates, and queries easier to understand without tracing the variable's type and usage.

## How to fix it

Rename the parameter or range variable to describe the value or role it represents.

## Examples

### Violation

```cs
var activeItems = items.Where(i => i.IsActive);
```

### Correction

```cs
var activeItems = items.Where(item => item.IsActive);
```
