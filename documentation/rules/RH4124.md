# RH4124 — Single-letter lambda and anonymous method parameter names should not be used

| Property | Value |
|----------|-------|
| **ID** | RH4124 |
| **Category** | Naming |
| **Severity** | Warning |
| **Code Fix** | ❌ |

## Description

Lambda and anonymous method parameters should use names longer than one letter. The discard identifier `_` is exempt.

## Why is this a problem?

Descriptive parameter names make inline transformations and predicates easier to understand without tracing the parameter's type and usage.

## How to fix it

Rename the parameter to describe the value or role it represents.

## Examples

### Violation

```cs
var activeItems = items.Where(i => i.IsActive);
```

### Correction

```cs
var activeItems = items.Where(item => item.IsActive);
```
