# RH5402 — Braces for multi-line statements must not share line

| Property | Value |
|----------|-------|
| **ID** | RH5402 |
| **Category** | Layout |
| **Severity** | Warning |
| **Code Fix** | ✓ |

## Description

The opening brace of a multi-line block must appear on its own line, not on the same line as the statement it belongs to. The rule applies to the bodies of `if`, `else`, `while`, `do`, `for`, `foreach`, `using`, `lock`, and `fixed` statements.

## Why is this a problem?

An opening brace parked at the end of the condition is easy to miss, so the reader has to re-read the line to see where the body starts. Keeping the brace on its own line makes the opening and the closing brace line up in the same column, which is what tells you at a glance how far the block reaches.

## How to fix it

Move the opening brace to its own line immediately after the statement header. The code fix applies this change automatically.

## Examples

### Violation

```cs
internal class TestClass
{
    void Method()
    {
        if (true) {
            int value = 0;
        }
    }
}
```

### Correction

```cs
internal class TestClass
{
    void Method()
    {
        if (true)
        {
            int value = 0;
        }
    }
}
```
