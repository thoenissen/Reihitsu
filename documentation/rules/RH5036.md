# RH5036 — Comments must not be placed between a statement header and its body

| Property | Value |
|----------|-------|
| **ID** | RH5036 |
| **Category** | Layout |
| **Severity** | Warning |
| **Code Fix** | ❌ |

## Description

This rule reports a comment placed between the header of an `if`, `while`, `for`, `foreach`, `using`, `lock`, or `fixed` statement and its body. The rule applies whether or not the comment shares a line with code.

## Why is this a problem?

A comment between the header and the body separates the two and makes it unclear whether it describes the condition or the body.

## How to fix it

Move the comment above the statement, or into the body above the statement it describes. No code fix is offered, because only you can decide what the comment refers to.

## Examples

### Violation

```cs
internal class Example
{
    void Method(bool a)
    {
        if (a)
            // explanation
        {
        }
    }
}
```

### Correction

```cs
internal class Example
{
    void Method(bool a)
    {
        // explanation
        if (a)
        {
        }
    }
}
```
