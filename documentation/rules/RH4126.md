# RH4126 — Single-letter foreach iteration variable names should not be used

| Property | Value |
|----------|-------|
| **ID** | RH4126 |
| **Category** | Naming |
| **Severity** | Warning |
| **Code Fix** | ❌ |

## Description

`foreach` iteration variables should use names longer than one letter. The discard identifier `_` is exempt.

## Why is this a problem?

The iteration variable identifies the element processed by the loop. A descriptive name makes the loop body easier to understand.

## How to fix it

Rename the iteration variable to describe each element in the sequence.

## Examples

### Violation

```cs
foreach (var i in items)
{
    Process(i);
}
```

### Correction

```cs
foreach (var item in items)
{
    Process(item);
}
```
