# RH2007 — Debug.Fail must provide message text

| Property | Value |
|----------|-------|
| **ID** | RH2007 |
| **Category** | Design |
| **Severity** | Warning |
| **Code Fix** | ❌ |

## Description

Calls to `Debug.Fail` must provide nonempty message text. Constant `null`, empty, and whitespace-only messages are treated as missing text.

## Why is this a problem?

`Debug.Fail` marks a path that should never be reached. When it fires without a message, the only information left is a stack trace, and whoever hits it has to reconstruct from the surrounding code what the unreachable case was supposed to be.

## How to fix it

Pass a descriptive non-empty, non-whitespace message to `Debug.Fail`.

## Examples

### Violation

```cs
System.Diagnostics.Debug.Fail(null);
```

### Correction

```cs
System.Diagnostics.Debug.Fail("Reached unreachable branch in switch.");
```
