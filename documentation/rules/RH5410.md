# RH5410 — Final array initializer items must not have trailing commas

| Property | Value |
|----------|-------|
| **ID** | RH5410 |
| **Category** | Layout |
| **Severity** | Warning |
| **Code Fix** | ✓ |

## Description

This rule forbids a trailing comma after the final item in an array initializer.

## Why is this a problem?

A trailing comma on the last array item adds visual noise without making the initializer easier to read, and it leaves the reader looking for an item that is not there.

## How to fix it

Remove the comma after the final array item. If the item has an attached comment, keep the comment with the item and remove only the comma.

The code fix and formatter can apply this automatically.

## Conditional-compilation exemption

This rule does not report a trailing comma when a preprocessor conditional directive (`#if`, `#elif`, `#else`,
`#endif`) or disabled text sits between the comma and the closing brace. Removing the comma there is only safe
for the preprocessor symbols in effect when the file was analyzed; under a different symbol configuration, code
inside the conditional block can become active and follow the "final" item without a separator, which no longer
compiles. The exemption fires on the presence of a conditional boundary alone — it does not evaluate the
condition or reason about which branch is reachable, so it also withholds in cases where the comma happens to be
removable in every configuration.

```cs
var values = new[]
{
    1,
#if SYMBOL
    2,
#endif
};
```

The comma after `1` is not flagged, regardless of whether `SYMBOL` is defined. A `#region`/`#endregion` or
`#pragma` directive in the same position does not trigger the exemption, since neither can introduce a further
list item.

## Examples

### Violation

```cs
internal class Example
{
    private static readonly int[] Values = new int[]
    {
        1,
        2, // final value
    };
}
```

### Correction

```cs
internal class Example
{
    private static readonly int[] Values = new int[]
    {
        1,
        2 // final value
    };
}
```
