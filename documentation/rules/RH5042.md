# RH5042 — Comments must not be placed around an assignment operator

| Property | Value |
|----------|-------|
| **ID** | RH5042 |
| **Category** | Layout |
| **Severity** | Warning |
| **Code Fix** | ❌ |

## Description

This rule reports a comment placed directly before or directly after an assignment operator, including `=` in a variable, field, property, or parameter initializer and the compound assignment operators. The rule applies whether or not the comment shares a line with code.

## Why is this a problem?

An assignment reads as one unit from the target to the value. A comment around the operator separates the target from its value.

## How to fix it

Move the comment above the statement or declaration. No code fix is offered, because only you can decide what the comment refers to.

## Examples

### Violation

```cs
internal class Example
{
    int Method()
    {
        var timeout =
            // default
            30;

        return timeout;
    }
}
```

### Correction

```cs
internal class Example
{
    int Method()
    {
        // default
        var timeout = 30;

        return timeout;
    }
}
```
