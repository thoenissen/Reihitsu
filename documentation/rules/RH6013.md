# RH6013 — Opening attribute brackets must be spaced correctly

| Property | Value |
|----------|-------|
| **ID** | RH6013 |
| **Category** | Spacing |
| **Severity** | Warning |
| **Code Fix** | ✓ |

## Description

No space may appear immediately after the opening bracket `[` of an attribute.

## Why is this a problem?

A leading space inside an attribute's brackets is non-standard and makes the attribute harder to recognize as a compact annotation.

## How to fix it

Remove the space immediately after the opening attribute bracket. The code fix applies this change
automatically, unless a comment or preprocessor directive shares the token gap the whitespace run sits in.
Deleting the whitespace in that case would glue the comment to the bracket or drop the directive, so the
diagnostic is still reported but no fix is offered.

## Examples

### Violation

```cs
[ System.Obsolete]
internal class TestClass
{
}
```

### Correction

```cs
[System.Obsolete]
internal class TestClass
{
}
```
