# RH5047 — Comments must not be placed inside an auto-property accessor list

| Property | Value |
|----------|-------|
| **ID** | RH5047 |
| **Category** | Layout |
| **Severity** | Warning |
| **Code Fix** | ❌ |

## Description

This rule reports a comment placed inside the accessor list of a property or indexer whose accessors have no body, including a comment between the property signature and the opening brace. The rule applies whether or not the comment shares a line with code.

## Why is this a problem?

An auto-property is a single short declaration. A comment inside its accessor list splits it across lines and describes only part of it.

## How to fix it

Move the comment above the property. No code fix is offered, because only you can decide what the comment refers to.

## Exceptions

- An accessor with a body is a declaration of its own, so a comment above it is not reported.

## Examples

### Violation

```cs
internal class Example
{
    public int Value
        // storage
        { get; set; }
}
```

### Correction

```cs
internal class Example
{
    // storage, read and write
    public int Value { get; set; }
}
```
