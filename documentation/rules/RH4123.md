# RH4123 — Single-letter local function parameter names should not be used

| Property | Value |
|----------|-------|
| **ID** | RH4123 |
| **Category** | Naming |
| **Severity** | Warning |
| **Code Fix** | ❌ |

## Description

Local function parameters should use names longer than one letter. The discard identifier `_` is exempt.

## Why is this a problem?

Even within a local function, descriptive parameter names make the function's purpose and calculations easier to follow.

## How to fix it

Rename the parameter to describe the value or role it represents.

## Examples

### Violation

```cs
static int Double(int n)
{
    return n * 2;
}
```

### Correction

```cs
static int Double(int value)
{
    return value * 2;
}
```
