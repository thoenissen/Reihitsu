# RH5502 — Assembly attribute lists must use one attribute per list

| Property | Value |
|----------|-------|
| **ID** | RH5502 |
| **Category** | Layout |
| **Severity** | Warning |
| **Code Fix** | ✓ |

## Description

Assembly attribute lists must contain exactly one attribute.

## Why is this a problem?

Assembly attributes have nothing to do with one another — one sets a title, another marks the assembly as
CLS-compliant, a third suppresses a diagnostic. `[assembly: First, Second]` is the syntax that says they belong
together, and it forces a change to any one of them to edit the line that carries all the others. One attribute per
list gives each its own line, so the block reads as a list and a change that names one attribute changes exactly one
line.

## How to fix it

Give each attribute a list of its own: replace `[First, Second]` with `[First]` on one line and `[Second]` on the
next. A code fix is offered and performs the split for you.

## Examples

### Violation

```cs
[assembly: First, Second]
internal class Example;
```

### Correction

```cs
[assembly: First]
[assembly: Second]
internal class Example;
```
