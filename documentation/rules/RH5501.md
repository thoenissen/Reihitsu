# RH5501 — Assembly attributes must be on their own line

| Property | Value |
|----------|-------|
| **ID** | RH5501 |
| **Category** | Layout |
| **Severity** | Warning |
| **Code Fix** | ✓ |

## Description

Assembly attributes must be placed on their own line.

## Why is this a problem?

An assembly attribute applies to the whole assembly, not to whatever happens to be written after it. When it shares a
line with the next declaration it reads like a decoration on that declaration, and only the `assembly:` target tells
the reader otherwise. Giving each assembly attribute its own line also keeps the block of them at the top of a file
scannable as a list, and lets a change to one of them touch a single line.

## How to fix it

Move the declaration that follows onto the line after the attribute list, leaving the attribute alone on its own
line. A code fix is offered and performs that edit for you.

## Examples

### Violation

```cs
[assembly: First] internal class Example;
```

### Correction

```cs
[assembly: First]
internal class Example;
```
