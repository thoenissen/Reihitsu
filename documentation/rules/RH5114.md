# RH5114 — Using directives must be placed on separate lines

| Property | Value |
|----------|-------|
| **ID** | RH5114 |
| **Category** | Layout |
| **Severity** | Warning |
| **Code Fix** | ✓ |

## Description

This rule checks whether a using directive shares a line.

## Why is this a problem?

Using directives that share a line are easy to overlook, make the list of imported namespaces harder to scan, and turn a change to one directive into a change to its neighbors in reviews and merges.

## How to fix it

Place each using directive on its own line.

## Examples

### Violation

```cs
using System.Collections.Generic; using System.Linq;

internal class TestClass
{
}
```

### Correction

```cs
using System.Collections.Generic;
using System.Linq;

internal class TestClass
{
}
```
