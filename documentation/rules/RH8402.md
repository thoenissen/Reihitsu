# RH8402 — Files must start with configured copyright header

| Property | Value |
|----------|-------|
| **ID** | RH8402 |
| **Category** | Documentation |
| **Severity** | Warning |
| **Code Fix** | ✓ |

## Description

When a copyright header is configured in the `reihitsu.json` configuration file, every analyzed source file has to start with that header.

The rule is inactive until you configure it. Without a `reihitsu.json`, or without a `copyright` section in it, nothing is reported.

## Why is this a problem?

A file without the agreed header leaves its ownership and its licence terms unstated. When only some files carry the header, nobody can tell whether a missing one is deliberate, and the licensing question has to be answered file by file instead of once for the whole project.

## How to fix it

Add the configured header to the top of the file. The code fix inserts it for you, with the placeholders already filled in for that file.

## Configuration

Add a `reihitsu.json` file to your project and describe the header you expect. `copyrightText` is the header itself, written exactly as it should appear at the top of each file, with `\n` between its lines:

```json
{
  "copyright": {
    "copyrightText": "// <copyright file=\"{fileName}\" company=\"{companyName}\">\n// Copyright (c) {companyName}. All rights reserved.\n// Licensed under the {licenseName} license. See {licenseFile}.\n// </copyright>",
    "companyName": "Example Software",
    "licenseName": "MIT",
    "licenseFile": "LICENSE"
  }
}
```

`{fileName}` is replaced with the name of the file being checked. Every other placeholder is replaced with the value of the entry of the same name in the `copyright` section, so you can name them whatever suits your header. A header that needs no placeholders at all — a single `// Copyright (c) Example Software. All rights reserved.` line, for example — is equally valid.

## Examples

### Violation

```cs
namespace Example.Orders;

internal sealed class InvoicePrinter
{
}
```

### Correction

```cs
// <copyright file="InvoicePrinter.cs" company="Example Software">
// Copyright (c) Example Software. All rights reserved.
// Licensed under the MIT license. See LICENSE.
// </copyright>
namespace Example.Orders;

internal sealed class InvoicePrinter
{
}
```
