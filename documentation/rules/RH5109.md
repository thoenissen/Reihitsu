# RH5109 — Parameters must be on same line or separate lines

| Property | Value |
|----------|-------|
| **ID** | RH5109 |
| **Category** | Layout |
| **Severity** | Warning |
| **Code Fix** | ✓ |

## Description

In a parameter list, all parameters must either fit on one line or each parameter must be on its own line. Once the parameters span multiple lines — when they start on different lines, or when a single parameter's type wraps across lines — every parameter must start on its own line. A line break directly after the opening parenthesis or before the closing parenthesis alone does not make the list multi-line. Mixing parameters that share a line with parameters on separate lines is not allowed.

## Why is this a problem?

Partially split parameter lists are harder to scan because the reader cannot quickly determine how many parameters there are or align them visually.

## How to fix it

Either keep all parameters on one line or put each parameter on its own line. The code fix applies the one-parameter-per-line form.

## Examples

### Violation

```cs
internal class TestClass
{
    void Method(int first, int second,
                int third)
    {
    }
}
```

### Correction

```cs
internal class TestClass
{
    void Method(int first,
                int second,
                int third)
    {
    }
}
```
