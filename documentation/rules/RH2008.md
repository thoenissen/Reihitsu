# RH2008 — Methods should not exceed the line limit

| Property | Value |
|----------|-------|
| **ID** | RH2008 |
| **Category** | Design |
| **Severity** | Warning |
| **Code Fix** | ❌ |

## Description

Reports a method whose body holds more lines of code than the limit you configure in the `reihitsu.json` configuration file. Constructors, finalizers, operators, local functions, and property, indexer, and event accessors are checked in the same way.

Only lines that hold code are counted. The signature, the braces around the body, blank lines, comment-only lines, and preprocessor directive lines are not. Local functions and lambdas count toward the method that contains them, and a local function is also checked on its own.

The rule is inactive until you configure it. Without a `reihitsu.json`, or without `maximumMethodLines` in it, nothing is reported.

## Why is this a problem?

A long method usually does more than one thing. It is harder to read, to test, and to change safely, and it tends to keep growing once it has passed a certain size. A limit makes that size visible in every build instead of leaving it to each reviewer's judgment.

## How to fix it

Split the method into smaller methods that each do one thing, for example by extracting a block that has a clear purpose into a method with a descriptive name. No code fix is offered, because how to split a method is a design decision.

## Configuration

Add a `reihitsu.json` file to your project and set the largest number of lines of code a method body may hold:

```json
{
  "design": {
    "maximumMethodLines": 50
  }
}
```

A method with exactly that many lines is accepted.

## Examples

### Violation

```cs
// "maximumMethodLines": 3 in reihitsu.json
public void Process(Order order)
{
    Validate(order);

    // Apply the discount.
    order.Total -= order.Discount;
    order.Status = OrderStatus.Processed;
    _repository.Save(order);
}
```

### Correction

```cs
public void Process(Order order)
{
    Validate(order);
    ApplyDiscount(order);
    _repository.Save(order);
}

private static void ApplyDiscount(Order order)
{
    order.Total -= order.Discount;
    order.Status = OrderStatus.Processed;
}
```
