# RH2008 — Methods should not exceed the line limit

| Property | Value |
|----------|-------|
| **ID** | RH2008 |
| **Category** | Design |
| **Severity** | Warning |
| **Code Fix** | ❌ |

## Description

Reports a method whose body holds more lines of code than its limit allows. Constructors, finalizers, operators, local functions, and property, indexer, and event accessors are checked in the same way.

Only lines that hold code are counted, every line of a multi-line string literal included. The signature, the braces around the body, blank lines, comment-only lines, and preprocessor directive lines are not. Local functions and lambdas count toward the method that contains them, and a local function is also checked on its own.

By default, a method body may hold 60 lines of code in production code and 120 lines of code in test code. Code in a test project — a project that references `Microsoft.NET.Test.Sdk`, runs its tests on Microsoft.Testing.Platform (such as an `MSTest.Sdk` or xUnit v3 project), or sets the MSBuild property `IsTestProject` to `true` — counts as test code.

## Why is this a problem?

A long method usually does more than one thing. It is harder to read, to test, and to change safely, and it tends to keep growing once it has passed a certain size. A limit makes that size visible in every build instead of leaving it to each reviewer's judgment.

## How to fix it

Split the method into smaller methods that each do one thing, for example by extracting a block that has a clear purpose into a method with a descriptive name. No code fix is offered, because how to split a method is a design decision.

## Configuration

To use other limits, add a `reihitsu.json` file to your project and set the largest number of lines of code a method body may hold, in production code and in test code:

```json
{
  "design": {
    "maximumMethodLines": 60,
    "maximumTestMethodLines": 120
  }
}
```

Each setting is optional and stands on its own: a setting you leave out, or one that RH0001 reports as invalid, keeps its default, also when you set the other one. A method with exactly that many lines is accepted.

## Examples

### Violation

```cs
// "maximumMethodLines": 3 in reihitsu.json
public void Process(Order order)
{
    Validate(order);

    // Apply the discount.
    order.Total -= order.Discount;
    order.Status = OrderStatus.Processed;
    _repository.Save(order);
}
```

### Correction

```cs
public void Process(Order order)
{
    Validate(order);
    ApplyDiscount(order);
    _repository.Save(order);
}

private static void ApplyDiscount(Order order)
{
    order.Total -= order.Discount;
    order.Status = OrderStatus.Processed;
}
```
