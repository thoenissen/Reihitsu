# RH5032 — Region directives should be followed by a blank line

| Property | Value |
|----------|-------|
| **ID** | RH5032 |
| **Category** | Layout |
| **Severity** | Warning |
| **Code Fix** | ✓ |

## Description

A `#region` or `#endregion` directive should have a blank line after it, so the directive is visually separated from the following code.

## Why is this a problem?

Without a blank line behind it, a region marker merges with the following member and the grouping is harder to see at a glance.

## How to fix it

Insert a blank line below the directive. The code fix does this for you.

## Exceptions

Nothing is reported, and no blank line is needed, when the directive:

- is an `#endregion` sitting directly above a closing brace, which keeps this rule consistent with RH5024. A `#region` in that position is still reported, because it opens a region rather than closing one;
- is on the very last line of the file;
- is inside code that a `#if` directive currently excludes from the build.

## Examples

### Violation

```cs
internal class TestClass
{
    private int _a;

    #region Helpers
    private int _b;

    #endregion
}
```

### Correction

```cs
internal class TestClass
{
    private int _a;

    #region Helpers

    private int _b;

    #endregion
}
```
