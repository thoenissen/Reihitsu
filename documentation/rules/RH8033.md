# RH8033 — Extension declaration type parameters must be documented

| Property | Value |
|----------|-------|
| **ID** | RH8033 |
| **Category** | Documentation |
| **Severity** | Warning |
| **Code Fix** | ❌ |

## Description

This rule requires each generic type parameter declared on an `extension<T>(...)` declaration to have matching `<typeparam>` documentation. A type parameter counts as documented when a `<typeparam>` tag carries its exact name.

## Why is this a problem?

A single-letter type parameter such as `T` says nothing about what may be substituted for it, and on an extension declaration that answer governs every member inside the block. Without a description, a caller who guesses wrong learns it from a compiler error rather than from the documentation.

## How to fix it

Add a `<typeparam>` tag for each type parameter of the extension declaration and spell the name exactly as it appears in the declaration — a `<typeparam>` whose name does not match is the same to this rule as a missing one.

## Exceptions

An extension declaration with no documentation at all is not reported here. RH8031 asks for the summary first, and the type parameters come into scope for this rule once documentation exists.

A declaration documented with `<inheritdoc/>` is not reported either, because its type parameter descriptions are taken from the member it inherits from.

## Examples

### Violation

```cs
using System.Collections.Generic;

/// <summary>
/// Provides collection helpers
/// </summary>
public static class Extensions
{
    /// <summary>
    /// Adds aggregation helpers to a sequence
    /// </summary>
    /// <param name="values">Sequence the helpers are applied to</param>
    extension<T>(IEnumerable<T> values)
    {
    }
}
```

### Correction

```cs
using System.Collections.Generic;

/// <summary>
/// Provides collection helpers
/// </summary>
public static class Extensions
{
    /// <summary>
    /// Adds aggregation helpers to a sequence
    /// </summary>
    /// <typeparam name="T">Type of the elements in the sequence</typeparam>
    /// <param name="values">Sequence the helpers are applied to</param>
    extension<T>(IEnumerable<T> values)
    {
    }
}
```
