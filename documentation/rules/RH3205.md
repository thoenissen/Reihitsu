# RH3205 — Expression style operators should not be used

| Property | Value |
|----------|-------|
| **ID** | RH3205 |
| **Category** | Clarity |
| **Severity** | Warning |
| **Code Fix** | ✓ |

## Description

This rule disallows expression-bodied operators (operators using `=>`). All user-defined operators should use block bodies for consistency and clarity.

## Why is this a problem?

Expression-bodied operators create inconsistency when some members use block bodies and others use expression bodies. Requiring block bodies keeps operators in line with methods and constructors and gives every member a uniform shape.

## How to fix it

Replace the expression-bodied operator with a block body containing a `return` statement. A `void` operator, such as a compound assignment or an instance increment operator, gets the expression as a plain statement instead.

## Exceptions

The rule is not reported when a preprocessor directive sits between the arrow and the expression:

```cs
public static Money operator +(Money left, Money right) =>
#pragma warning disable CS0618
    new Money(left.Amount + right.Amount);
#pragma warning restore CS0618
```

The conversion to a block body would have to move that directive into the generated block, which the
formatter refuses to do, so the operator keeps its expression body. The same applies to a
conditional group whose partner directive lies outside the operator, and to any `#region` or
`#endregion` directive between the arrow and the semicolon. A `#pragma` or a complete `#if` group
written *after* the expression is unaffected, and such an operator is still reported.

## Examples

### Violation

```cs
internal class Money
{
    public Money(decimal amount)
    {
        Amount = amount;
    }

    public decimal Amount { get; }

    public static Money operator +(Money left, Money right) => new Money(left.Amount + right.Amount);
}
```

### Correction

```cs
internal class Money
{
    public Money(decimal amount)
    {
        Amount = amount;
    }

    public decimal Amount { get; }

    public static Money operator +(Money left, Money right)
    {
        return new Money(left.Amount + right.Amount);
    }
}
```
