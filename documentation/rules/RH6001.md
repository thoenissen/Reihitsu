# RH6001 — Keywords must be spaced correctly

| Property | Value |
|----------|-------|
| **ID** | RH6001 |
| **Category** | Spacing |
| **Severity** | Warning |
| **Code Fix** | ✓ |

## Description

A space is required between a keyword and the opening parenthesis that follows it. The rule covers `if`, `while`, `for`, `foreach`, `switch`, `catch`, `fixed`, `lock`, `using`, `return`, and `throw`.

## Why is this a problem?

Without the space, `if(condition)` and `return(value)` look like calls to methods named `if` and `return`. The parenthesis belongs to the statement, not to a call, and the space is what says so.

## How to fix it

Insert a space between the keyword and the opening parenthesis. The code fix applies this change automatically.

## Examples

### Violation

```cs
internal class TestClass
{
    void Method()
    {
        if(true)
        {
        }
    }
}
```

### Correction

```cs
internal class TestClass
{
    void Method()
    {
        if (true)
        {
        }
    }
}
```
