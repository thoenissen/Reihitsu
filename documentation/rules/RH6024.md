# RH6024 — Binary operators must be spaced correctly

| Property | Value |
|----------|-------|
| **ID** | RH6024 |
| **Category** | Spacing |
| **Severity** | Warning |
| **Code Fix** | ✓ |

## Description

A binary operator must be separated from the token before it and the token after it by exactly one space. This covers the arithmetic (`+`, `-`, `*`, `/`, `%`), comparison (`==`, `!=`, `<`, `>`, `<=`, `>=`), logical (`&&`, `||`), bitwise (`&`, `|`, `^`), shift (`<<`, `>>`, `>>>`), null-coalescing (`??`), and keyword (`is`, `as`) operators. The pattern forms of `is`, such as `value is null` or `value is Stream stream`, are a different shape and are not reported here.

Operators that wrap to a new line are left untouched.

## Why is this a problem?

Missing spaces (`a+b`) run the operands together and hurt readability. Extra spaces used to vertically align operators are fragile, produce noisy diffs, and are inconsistent with the single-space spacing enforced everywhere else.

## How to fix it

Use a single space on both sides of the operator. The code fix applies this change automatically.

## Examples

### Violation

```cs
internal class TestClass
{
    int Method(int a, int b)
    {
        return a  +  b;
    }
}
```

`a` and `b` are each separated from the `+` by two spaces; the rule asks for exactly one on each side.

### Correction

```cs
internal class TestClass
{
    int Method(int a, int b)
    {
        return a + b;
    }
}
```
