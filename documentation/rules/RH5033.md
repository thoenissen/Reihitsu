# RH5033 — Comments must not be placed between attributes and the declaration

| Property | Value |
|----------|-------|
| **ID** | RH5033 |
| **Category** | Layout |
| **Severity** | Warning |
| **Code Fix** | ❌ |

## Description

This rule reports a comment placed between the attributes of a declaration and the declaration itself, or between two of its attribute lists. The rule applies whether or not the comment shares a line with code.

## Why is this a problem?

The attributes and the declaration they apply to belong together. A comment between them separates the two and makes it unclear whether it describes an attribute or the declaration.

## How to fix it

Move the comment above the first attribute of the declaration. No code fix is offered, because only you can decide what the comment refers to.

## Examples

### Violation

```cs
using System;

internal class Example
{
    [Obsolete]
    // note
    public void Method()
    {
    }
}
```

### Correction

```cs
using System;

internal class Example
{
    // note
    [Obsolete]
    public void Method()
    {
    }
}
```
