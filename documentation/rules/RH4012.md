# RH4012 — Union names should be in PascalCase

| Property | Value |
|----------|-------|
| **ID** | RH4012 |
| **Category** | Naming |
| **Severity** | Warning |
| **Code Fix** | ✓ |

## Description

Checks that union names follow PascalCase naming conventions. Each word in the name should start with an uppercase letter, with no underscores or other separators.

## Why is this a problem?

PascalCase for type names is a fundamental C# naming convention, and a union is a type like any other. Inconsistent casing reduces readability and makes it harder for developers to identify types at a glance.

## How to fix it

Rename the union to use PascalCase. The code fix renames the union and every reference to it.

If the corrected name would collide with a name that already exists, no code fix is offered and the name has to be changed by hand.

## Examples

### Violation

```cs
public union shapeKind(int, string);
```

### Correction

```cs
public union ShapeKind(int, string);
```
