# RH8106 — Element return value documentation must have text

| Property | Value |
|----------|-------|
| **ID** | RH8106 |
| **Category** | Documentation |
| **Severity** | Warning |
| **Code Fix** | ❌ |

## Description

This rule requires the `<returns>` tag to contain descriptive text on methods, delegates, operators, and conversion operators.

## Why is this a problem?

An empty `<returns>` tag looks like finished documentation while still leaving the return contract unexplained.

## How to fix it

Write a short description of what the member returns.

## Examples

### Violation

```cs
internal class Example
{
    /// <summary>
    /// Gets the customer count
    /// </summary>
    /// <returns></returns>
    internal int GetCustomerCount()
    {
        return 0;
    }
}
```

### Correction

```cs
internal class Example
{
    /// <summary>
    /// Gets the customer count
    /// </summary>
    /// <returns>The number of customers currently loaded</returns>
    internal int GetCustomerCount()
    {
        return 0;
    }
}
```
