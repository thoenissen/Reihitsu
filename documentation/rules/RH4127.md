# RH4127 — Single-letter catch exception variable names should not be used

| Property | Value |
|----------|-------|
| **ID** | RH4127 |
| **Category** | Naming |
| **Severity** | Warning |
| **Code Fix** | ❌ |

## Description

`catch` exception variables should use names longer than one letter. The discard identifier `_` is exempt.

## Why is this a problem?

A descriptive exception name makes error-handling code clearer, especially when the exception is logged, wrapped, or inspected.

## How to fix it

Rename the variable to `exception` or another name that describes the error.

## Examples

### Violation

```cs
using System;

internal class Example
{
    void Run()
    {
        try
        {
        }
        catch (Exception e)
        {
            Log(e);
        }
    }
}
```

### Correction

```cs
using System;

internal class Example
{
    void Run()
    {
        try
        {
        }
        catch (Exception exception)
        {
            Log(exception);
        }
    }
}
```
