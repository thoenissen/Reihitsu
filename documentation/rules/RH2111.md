# RH2111 — Types should not exceed the line limit

| Property | Value |
|----------|-------|
| **ID** | RH2111 |
| **Category** | Design |
| **Severity** | Warning |
| **Code Fix** | ❌ |

## Description

Reports a class, struct, interface, record, or union whose body holds more lines of code than its limit allows.

Only lines that hold code are counted, every line of a multi-line string literal included. The declaration line, the braces around the body, blank lines, comment-only lines, documentation comments, and preprocessor directive lines such as `#region` are not. A nested type counts toward the type that contains it and is also checked on its own. Each part of a `partial` type is checked on its own.

By default, a type body may hold 1500 lines of code in production code and 3000 lines of code in test code. Code in a test project — a project that references `Microsoft.NET.Test.Sdk`, runs its tests on Microsoft.Testing.Platform (such as an `MSTest.Sdk` or xUnit v3 project), or sets the MSBuild property `IsTestProject` to `true` — counts as test code.

## Why is this a problem?

A type that keeps growing usually collects responsibilities that do not belong together. It becomes hard to navigate, hard to test in isolation, and hard to change without side effects. A limit makes that size visible in every build instead of leaving it to each reviewer's judgment.

## How to fix it

Split the type: move a group of members that belongs together into a type of its own, or extract a collaborator that the type uses. No code fix is offered, because how to split a type is a design decision.

## Configuration

To use other limits, add a `reihitsu.json` file to your project and set the largest number of lines of code a type body may hold, in production code and in test code:

```json
{
  "design": {
    "maximumTypeLines": 1500,
    "maximumTestTypeLines": 3000
  }
}
```

Each setting is optional and stands on its own: a setting you leave out, or one that RH0001 reports as invalid, keeps its default, also when you set the other one. A type with exactly that many lines is accepted.

## Examples

### Violation

```cs
// "maximumTypeLines": 4 in reihitsu.json
public class Customer
{
    public string Name { get; set; }

    public string Street { get; set; }

    public string City { get; set; }

    public string PostalCode { get; set; }

    public string Country { get; set; }
}
```

### Correction

```cs
public class Customer
{
    public string Name { get; set; }

    public Address Address { get; set; }
}

public class Address
{
    public string Street { get; set; }

    public string City { get; set; }

    public string PostalCode { get; set; }

    public string Country { get; set; }
}
```
