# RH2111 — Types should not exceed the line limit

| Property | Value |
|----------|-------|
| **ID** | RH2111 |
| **Category** | Design |
| **Severity** | Warning |
| **Code Fix** | ❌ |

## Description

Reports a class, struct, interface, record, or union whose body holds more lines of code than the limit you configure in the `reihitsu.json` configuration file.

Only lines that hold code are counted. The declaration line, the braces around the body, blank lines, comment-only lines, documentation comments, and preprocessor directive lines such as `#region` are not. A nested type counts toward the type that contains it and is also checked on its own. Each part of a `partial` type is checked on its own.

The rule is inactive until you configure it. Without a `reihitsu.json`, or without `maximumTypeLines` in it, nothing is reported.

## Why is this a problem?

A type that keeps growing usually collects responsibilities that do not belong together. It becomes hard to navigate, hard to test in isolation, and hard to change without side effects. A limit makes that size visible in every build instead of leaving it to each reviewer's judgment.

## How to fix it

Split the type: move a group of members that belongs together into a type of its own, or extract a collaborator that the type uses. No code fix is offered, because how to split a type is a design decision.

## Configuration

Add a `reihitsu.json` file to your project and set the largest number of lines of code a type body may hold:

```json
{
  "design": {
    "maximumTypeLines": 500
  }
}
```

A type with exactly that many lines is accepted.

## Examples

### Violation

```cs
// "maximumTypeLines": 4 in reihitsu.json
public class Customer
{
    public string Name { get; set; }

    public string Street { get; set; }

    public string City { get; set; }

    public string PostalCode { get; set; }

    public string Country { get; set; }
}
```

### Correction

```cs
public class Customer
{
    public string Name { get; set; }

    public Address Address { get; set; }
}

public class Address
{
    public string Street { get; set; }

    public string City { get; set; }

    public string PostalCode { get; set; }

    public string Country { get; set; }
}
```
