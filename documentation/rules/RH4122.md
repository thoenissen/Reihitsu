# RH4122 — Single-letter parameter names should not be used

| Property | Value |
|----------|-------|
| **ID** | RH4122 |
| **Category** | Naming |
| **Severity** | Warning |
| **Code Fix** | ❌ |

## Description

Method, constructor, indexer, delegate, operator, and conversion parameters should use names longer than one letter. This rule also applies to class and struct primary constructor parameters.

The discard identifier `_`, override and explicit interface implementation parameters, and record primary constructor parameters are exempt.

## Why is this a problem?

Parameters describe the inputs to an operation. Single-letter names make signatures and call-site behavior harder to understand, especially when several values have the same type.

## How to fix it

Rename the parameter to describe the value or role it represents.

## Examples

### Violation

```cs
public void Process(int c)
{
}
```

### Correction

```cs
public void Process(int count)
{
}
```
