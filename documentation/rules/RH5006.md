# RH5006 — foreach-Statement should be preceded by a blank line

| Property | Value |
|----------|-------|
| **ID** | RH5006 |
| **Category** | Layout |
| **Severity** | Warning |
| **Code Fix** | ✓ |

## Description

A `foreach` statement that follows another statement in the same block or `switch` section should be separated from it by a blank line.

## Why is this a problem?

Separating statements with blank lines improves code readability by visually grouping related logic. A blank line before a `foreach` loop makes it clear where iteration begins and separates it from preceding setup code.

## How to fix it

Insert a blank line between the preceding statement and the `foreach` statement. The code fix does this for you. When a comment sits directly above the statement, the blank line is placed above that comment, so the comment stays attached to the code it describes.

Inside an object initializer or anonymous object, the fix reads the inserted blank line's indentation from whichever switch-section label leads the shared physical line, the same way [RH5103](RH5103.md)'s code fix does — including that fix's documented limitation when the label itself is not first on its own line. Every diagnostic that shares this code-fix base inherits the same behavior.

## Exceptions

Nothing is reported, and no blank line is needed, when the `foreach` statement:

- is the first statement of its block, or the first statement under a `case` or `default` label;
- is the body of a statement that is written without braces — for example the single statement after `while`, `for`, `foreach`, `using`, `lock`, `fixed`, `do`, or `else`;
- directly follows a preprocessor directive such as `#if`, `#endif`, or `#region`;
- is a top-level statement in a file that has no enclosing type.

## Examples

### Violation

```cs
internal class Example
{
    private void Execute()
    {
        var items = GetItems();
        foreach (var item in items)
        {
            Process(item);
        }
    }
}
```

### Correction

```cs
internal class Example
{
    private void Execute()
    {
        var items = GetItems();

        foreach (var item in items)
        {
            Process(item);
        }
    }
}
```
