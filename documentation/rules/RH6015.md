# RH6015 — Nullable type symbols must not be preceded by space

| Property | Value |
|----------|-------|
| **ID** | RH6015 |
| **Category** | Spacing |
| **Severity** | Warning |
| **Code Fix** | ✓ |

## Description

The nullable type operator `?` must not be preceded by same-line horizontal whitespace. Indentation before a nullable type symbol that begins a continuation line is left unchanged.

## Why is this a problem?

A space before `?` visually separates the operator from the base type, making nullable type annotations harder to read.

## How to fix it

Remove the same-line space or tab immediately before the `?` operator. The code fix applies this change
automatically, unless a comment or preprocessor directive shares the token gap the whitespace run sits in —
for example a block comment on the line above a continuation-line `?`. Deleting the whitespace in that case
would glue the comment to the operator or drop the directive, so the diagnostic is still reported but no fix
is offered.

## Examples

### Violation

```cs
internal class TestClass
{
    void Method(int ? value)
    {
    }
}
```

### Correction

```cs
internal class TestClass
{
    void Method(int? value)
    {
    }
}
```
