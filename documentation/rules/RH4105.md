# RH4105 — Method parameter names should be in camelCase

| Property | Value |
|----------|-------|
| **ID** | RH4105 |
| **Category** | Naming |
| **Severity** | Warning |
| **Code Fix** | ✓ |

## Description

Checks that parameter names follow camelCase naming conventions. The first word should start with a lowercase letter, and each subsequent word should start with an uppercase letter. Besides methods, this covers constructors, indexers, delegates, local functions, and lambdas.

The discard identifier `_` is exempt. Record primary-constructor parameters are named in PascalCase, because they become public properties, and are handled by RH4120 instead.

## Why is this a problem?

camelCase for parameters is a fundamental C# naming convention. Inconsistent parameter naming reduces readability and makes it harder to distinguish parameters from types and properties.

## How to fix it

Rename the parameter to use camelCase.

If the required casing target conflicts with an existing identifier, the automatic fix is unavailable and the name must be corrected manually.

## Examples

### Violation

```cs
public void Method(int MyParam)
{
}
```

### Correction

```cs
public void Method(int myParam)
{
}
```
