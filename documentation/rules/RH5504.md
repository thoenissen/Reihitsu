# RH5504 — Module attribute lists must use one attribute per list

| Property | Value |
|----------|-------|
| **ID** | RH5504 |
| **Category** | Layout |
| **Severity** | Warning |
| **Code Fix** | ✓ |

## Description

Module attribute lists must contain exactly one attribute.

## Why is this a problem?

Module attributes have nothing to do with one another, and `[module: First, Second]` is the syntax that says they do.
It also forces a change to any one of them to edit the line that carries all the others. One attribute per list gives
each its own line, so the block reads as a list and a change that names one attribute changes exactly one line.

## How to fix it

Give each attribute a list of its own: replace `[First, Second]` with `[First]` on one line and `[Second]` on the
next. A code fix is offered and performs the split for you.

## Examples

### Violation

```cs
[module: First, Second]
internal class Example;
```

### Correction

```cs
[module: First]
[module: Second]
internal class Example;
```
