# RH5111 — Assignments must have proper line breaks

| Property | Value |
|----------|-------|
| **ID** | RH5111 |
| **Category** | Layout |
| **Severity** | Warning |
| **Code Fix** | ✔ |

## Description

This rule requires the end of the assignment target and the `=` operator to stay on the same line, and it requires the assigned value to begin on that same line as `=`. It covers assignments, variable and property initializers, parameter defaults, and enum-member equals values. For a property initializer with an accessor list, the accessor-list closing brace is the end of the assignment target.

## Why is this a problem?

Splitting the end of the target, `=`, and the start of the value across separate lines makes assignments harder to scan. Keeping those parts together makes declarations, assignments, property initializers, member initializers, and index assignments easier to read consistently.

## How to fix it

Move the `=` operator onto the line containing the end of the assignment target and move the start of the assigned value onto the `=` line. For a property initializer with an accessor list, place `=` on the line containing the accessor-list closing brace. Multiline values are still allowed as long as they begin on the `=` line. Raw multiline string opening quotes must also begin on the `=` line. Object-initializer member values that are themselves a nested initializer (`Member = { ... }`) are exempt from the value-placement requirement, because the formatter keeps that brace on its own line.

The diagnostic is still reported when comments, directives, or disabled text make an automatic join unsafe. In those protected-trivia cases no code action is offered and the assignment must be corrected manually.

## Examples

### Violation

```cs
var result
    = 42;

settings.Name =
    "demo";

values[0]
    = GetValue();

string Name { get; set; }
    = "demo";
```

### Correction

```cs
var result = 42;

settings.Name = "demo";

values[0] = GetValue();

string Name { get; set; } = "demo";

var text = """
           Hello
           World
           """;
```
