# RH4128 — Local constant names should be in camelCase

| Property | Value |
|----------|-------|
| **ID** | RH4128 |
| **Category** | Naming |
| **Severity** | Warning |
| **Code Fix** | ✓ |

## Description

Checks that the names of local constants follow camelCase naming conventions. The first word should start with a lowercase letter, and each subsequent word should start with an uppercase letter.

Local variables that are not constants are handled by RH4115.

## Why is this a problem?

A local constant is a local: it is only visible in its block. Naming it in camelCase, like every other local, tells a reader at each use that the name belongs to the current block and not to the type, and the name stays the same when a variable becomes a constant or a constant a variable.

## How to fix it

Rename the local constant to use camelCase.

If the corrected name would collide with a name that already exists, no code fix is offered and the name has to be changed by hand.

## Examples

### Violation

```cs
const int MaxRetries = 3;
```

### Correction

```cs
const int maxRetries = 3;
```
