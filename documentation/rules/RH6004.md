# RH6004 — Preprocessor keywords must not be preceded by space

| Property | Value |
|----------|-------|
| **ID** | RH6004 |
| **Category** | Spacing |
| **Severity** | Warning |
| **Code Fix** | ✓ |

## Description

A preprocessor directive such as `#pragma`, `#if`, `#else`, or `#define` must start at the very beginning of its line, with no space or tab in front of the `#`.

## Why is this a problem?

An indented directive looks like it belongs to the block it sits in, but directives are not scoped by braces — they take effect from the point in the file where they appear. Keeping them flush with the left margin makes that difference visible at a glance and keeps them easy to find while scanning a file.

## How to fix it

Remove all leading whitespace before the `#` character. The code fix applies this change automatically.

## Exceptions

- `#region` and `#endregion` are indented together with the code they surround and are not reported.
- A directive inside a branch that the current build excludes is left exactly as written.

## Examples

### Violation

```cs
    #pragma warning disable CS0168
internal class TestClass
{
}
```

### Correction

```cs
#pragma warning disable CS0168
internal class TestClass
{
}
```
