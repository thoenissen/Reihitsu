# RH4120 — Record primary constructor parameter names should be in PascalCase

| Property | Value |
|----------|-------|
| **ID** | RH4120 |
| **Category** | Naming |
| **Severity** | Warning |
| **Code Fix** | ✓ |

## Description

Ensures primary-constructor parameters on `record` and `record struct` declarations use PascalCase.

## Why is this a problem?

A record's primary-constructor parameters are not just parameters: the compiler turns each one into a public property, and the name is what every consumer sees in `product.ProductCode`, in `with` expressions, in deconstruction, and in the generated `ToString`. A camelCase parameter name therefore produces a camelCase public property, which reads as an accident on the type's API surface.

## How to fix it

Rename each primary-constructor parameter so each word starts with an uppercase letter.

## Examples

### Violation

```cs
public record Product(string productCode);
```

### Correction

```cs
public record Product(string ProductCode);
```
