# RH5031 — Region directives should be preceded by a blank line

| Property | Value |
|----------|-------|
| **ID** | RH5031 |
| **Category** | Layout |
| **Severity** | Warning |
| **Code Fix** | ✓ |

## Description

A `#region` or `#endregion` directive should have a blank line before it, so the directive is visually separated from the preceding code.

## Why is this a problem?

Without a blank line in front of it, a region marker merges with the preceding member and the grouping is harder to see at a glance.

## How to fix it

Insert a blank line above the directive. The code fix does this for you.

## Exceptions

Nothing is reported, and no blank line is needed, when the directive:

- sits directly under an opening brace, which keeps this rule consistent with RH5022;
- is on the very first line of the file;
- is inside code that a `#if` directive currently excludes from the build.

## Examples

### Violation

```cs
internal class TestClass
{
    private int _a;
    #region Helpers

    private int _b;

    #endregion
}
```

### Correction

```cs
internal class TestClass
{
    private int _a;

    #region Helpers

    private int _b;

    #endregion
}
```
