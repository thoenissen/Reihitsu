# RH6010 — Closing braces must be spaced correctly

| Property | Value |
|----------|-------|
| **ID** | RH6010 |
| **Category** | Spacing |
| **Severity** | Warning |
| **Code Fix** | ✓ |

## Description

A closing brace `}` must be separated by a space from whatever precedes it on the same line. A brace that starts its own line is already separated and is not reported, and braces that belong to an interpolated string — the `{value}` in `$"{value}"` — are left alone.

## Why is this a problem?

A closing brace written directly against the preceding token, as in `set;}`, runs the end of the block into the last thing inside it, so the block boundary is harder to spot on a single-line member.

## How to fix it

Insert a single space before the closing brace. The code fix applies this change automatically.

## Examples

### Violation

```cs
internal class TestClass
{
    int Property { get; set;}
}
```

### Correction

```cs
internal class TestClass
{
    int Property { get; set; }
}
```
