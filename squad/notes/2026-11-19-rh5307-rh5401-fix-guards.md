## Suggestions

- When an output question asks for a layout guarantee inside a code fix (answer 3: "the fix must not insert a blank line"), ask in the same message whether the fix may be withheld where the formatter cannot give that guarantee. `lead.md` section 5 already says so for fixes that lay out code; this run asked it only after the implementer had built a 200-line write-back (question 6).
- A refusal derived from "what the formatter would change" was found incomplete twice. Stating it from the start as "anything but code, spaces and line breaks between the brackets" would have saved two architecture loops; `README.md`, *Refuse by the cause, not by the cells*, already demands this, so the lesson is to apply it at the first finding.
