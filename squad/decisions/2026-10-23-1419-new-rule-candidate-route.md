## Question

The narrowed skeptic check 3 sent a new-rule candidate (P11) to "the run report", but `squad/lead.md` §7 step 5 gives the run report no slot for it, and `sdd/work/` is deleted before publishing, so the candidate would be lost. Options: 1A widen the run to `squad/lead.md` so the candidate reaches the maintainer; 1B keep the candidate in the skeptic's handover only; 1C ship as is and track `lead.md` in a follow-up issue. Asked back on 1A: list the candidate in the run report only (1A-i), or have the lead present it to the maintainer, who decides whether it becomes an issue (1A-ii).

## Answer

1A-ii. The lead presents each new-rule candidate to the maintainer, who decides whether it becomes an issue; the maintainer named this the normal follow-up route, so a new-rule candidate is handled as an ordinary follow-up candidate (`squad/lead.md`, *Follow-ups*), and no issue is created without the maintainer's approval of its exact text. The run's scope widens to `squad/lead.md` as far as that needs.
