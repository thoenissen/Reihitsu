# Which rules the documentation-mode gate covers under P30 (#1331)

| | |
|---|---|
| Date | 2026-10-22 |
| Escalation | 1 |
| Run | issue #1331 |

## Question

P30 limits the documentation-mode gate to rules that read documentation elements. RH8301–RH8303 judge the lines and position of a `///` comment and read no XML element; each has a test tagged SHARED-DOC-008 that expects no report in `DocumentationMode.None`. Options: they stay gated; they check in every mode.

## Answer

They stay gated, as today. The gate covers every rule about documentation comments; only rules about ordinary comments or file text (RH8401, RH8402, and RH8501) check in every documentation mode. SHARED-DOC-008 is worded accordingly.
