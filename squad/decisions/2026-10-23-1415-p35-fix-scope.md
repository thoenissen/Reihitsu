# Which line breaks the clarified SHARED-FIX-008 covers (#1415)

| | |
|---|---|
| Date | 2026-10-23 |
| Escalation | 1 |
| Run | issue #1415 |

## Question

The draft of SHARED-FIX-008 counted "the line break that ends its last line" as part of the code a fix changes. Input: a mostly-CRLF document with `Nullable<int> _a;` ending in a stray LF; the RH3103 fix replaces only the type. Options: (a) as drafted, the fix turns that LF into CRLF; (b) only the line breaks in the span the fix replaces, rewrites, or moves count, its trailing trivia included, so the LF stays.

## Answer

(b).

## Reason

In that example the line break is not in the scope of the fix.
