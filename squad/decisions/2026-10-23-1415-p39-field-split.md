# Whether P39 reaches a fix that splits a documented declaration (#1415)

| | |
|---|---|
| Date | 2026-10-23 |
| Escalation | 1 |
| Run | issue #1415 |

## Question

The fifth condition of SHARED-FIX-003 (P39) withholds a fix that would separate a declaration from its documentation. Mode `Parse`, input `/// <summary>The coordinates</summary>` above `public int X, Y;`: the compiler documents both fields, while the RH7101 fix keeps the comment on `X` only (RH7101-004, FMT-STRUCT-022). Options: (a) no, the condition covers moves only and the split stays offered; (b) yes, the RH7101 fix is withheld for such a declaration.

## Answer

(b): the fix does not split such a declaration. As a general principle, no code fix may lose documentation; the user rearranges the code by hand.

## Reason

No documentation may be lost through a fix.
